# The Qu Book (mdBook site)

This directory is an [mdBook](https://rust-lang.github.io/mdBook/) project:
the Getting Started tutorials, the language specification, and a standard
library reference table, assembled into one browsable site. Source content
lives under `src/`; `book.toml` configures the build.

Most of `src/` is imported (not rewritten) from existing documentation
elsewhere in this repository — see each chapter's own framing sentence for
where its content actually comes from. The Standard Library Reference
chapters under `src/stdlib/` are the one genuinely new piece of content:
tables generated by surveying `engine/crates/qu-interp/src/lib.rs`'s builtin
dispatch table directly, so they describe what the interpreter actually runs
today.

## Prerequisites

```bash
cargo install mdbook
```

This is a one-time local dev-tool install (like installing `cargo-watch` or
`ripgrep`) — `mdbook` is a standalone CLI that turns Markdown into a static
site. It is **not** a Rust crate dependency of any `Cargo.toml` in this
workspace and is never compiled into the `qu` binary.

## Build

From this directory:

```bash
mdbook build
```

Output goes to `book/book/` (an mdBook convention — the build directory
shares the project directory's name). Open `book/book/index.html` in a
browser to read it.

## Serve locally with live reload

```bash
mdbook serve
```

Serves the book at `http://localhost:3000` by default and rebuilds on save.

## Publishing

This repository has no existing GitHub Actions / CI or GitHub Pages
configuration to hook into (checked as of this book's creation — there is no
`.github/workflows/` directory). Rather than inventing a deploy pipeline that
doesn't connect to anything else in the project, this book is left as a
buildable-on-demand static site: run `mdbook build` and publish
`book/book/`'s contents wherever is convenient (GitHub Pages, a plain static
host, or just committing the built output) if and when that becomes useful.

## Relationship to `docs/`

The `docs/` directory at the repository root has its own, separate
JavaScript-based interactive playground (`docs/ide.html`, `docs/app.html`)
and a handful of standalone HTML reference pages. Those are intentionally
**not** absorbed into this mdBook site — the playground is a live runtime,
not documentation — but this book cross-links to them (see
`src/playground.md`) rather than duplicating them.
