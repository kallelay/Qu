Twenty minutes, start to finish

If you would rather just see it, this is the whole shape of the language.

  1. Open the prompt

    qu repl

  2. Numbers have names, and many numbers are one value

    fs = 1000
t  = (0 to 999) / fs        # a thousand time points
x  = sin(2 * pi * 50 * t)   # every one of them, at once

  3. Ask the data a question

    spectrum = abs(rfft(x))
peak     = argmax(spectrum)
print("largest component at {peak * fs / len(x):.1f} Hz")

  4. Fit a model to it

    function resid(p)
    return p[0] * exp(0 - t / p[1]) - decay
end function

fit = least_squares("resid", [1.0, 1.0], lower = [0.0, 0.01])

  5. Make the figure

    theme("publication")
plot(t, x, color = "#0072BD", lw = pt(1.2))
xlabel("time $t$ [s]")
savefig("figure.pdf")

Every example in the documentation is executed before it is published. tools/check_docs.sh extracts each block and runs it, so a snippet that does not work is a build failure rather than something you find out about.
