kaiser

Builtin index · Signal processing

result = kaiser(n, beta)

Input: n, beta · Output: result

What it is

n: a number (integer window length); beta: a number, required second positional argument (no default — it fundamentally changes the main-lobe-width/side-lobe-level tradeoff).

Overloads

One call shape — this function is not overloaded.

Returns a length-n real vector, w[i] = I0(beta*sqrt(1-((2i/(n-1))-1)^2)) / I0(beta). Center sample is always 1.0 for any beta.

Examples

f = logspace(0, 3, 4)               # 1, 10, 100, 1000 -- a log-spaced frequency axis

print("logspace(0,3,4) = {f}")

How it works

kaiser(n, beta) — w[i] = I0(beta*sqrt(1-((2i/(n-1))-1)^2)) I0(beta), beta a required second positional argument (not an optional style knob: it fundamentally changes the main-lobe-width/side-lobe-level tradeoff, there's no sane silent default the way duty/carrier are optional elsewhere in this file). Same symmetric (n-1) convention. beta=0 makes I0(0)/I0(0) = 1 at every sample (a flat all-ones window); the center sample of an odd-length window always has (2i/(n-1))-1 == 0, so its numerator is exactly I0(beta), giving w[center] == 1.0 for any beta.
