bessely

Builtin index · Core maths

bessely(nu, x)

Input: nu, x · Output: no output

What it is

Bessel function of the second kind Y_nu(x) for real order nu (|nu| <= 1e6) and x > 0, same argument shapes, methods and accuracy as besselj (median 2e-16 and 99% within 1e-12 over 3400 random points, measured against the envelope sqrt(2/(pi x)); the worst difference from scipy, 1e-11, is at a point where mpmath sides with Qu). Y_nu(0) = -inf, Y_nu(inf) = 0; overflow for large order and small x gives -inf; x < 0, where Y is complex, gives NaN. Errors: missing arguments, mismatched shapes, complex input.

Overloads

One call shape — this function is not overloaded.
