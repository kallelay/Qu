read_csv

Builtin index · File I/O

result = read_csv(path, [headers=true], [sep=","], [decimal="."])

Input: path, headers, sep, decimal · Output: result

What it is

Reads a CSV file into a Table. path (string) is the file to read. headers (boolean, optional, default true) — false treats the first line as data instead of column names (columns are then auto-named col1, col2, ...). sep (string, optional, default ",") is the field delimiter. decimal (string, optional, default ".") is the decimal-point marker (e.g. sep=";", decimal="," for the European convention).

Overloads

One call shape — this function is not overloaded.

How it works

read_csv(path, [headers=], [sep=], [decimal=]) — headers (default true) treats the first line as data instead of column names when false (columns auto-named col1, col2, ...); sep (default ",") is the field delimiter; decimal (default ".") is the decimal-point marker ("," for the European convention). See Table::from_csv_opts's own doc comment for the motivating sep=";" + decimal="," case and why there's no implicit per-field decimal auto-detection.
