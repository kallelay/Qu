printtex

Builtin index · Plotting

printtex(x)

Input: x · Output: no output

What it is

Same conversion as tex(x) on value x (number, Vec, Mat, or complex), but prints it directly instead of returning a string.

Overloads

One call shape — this function is not overloaded.
