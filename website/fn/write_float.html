write_float

Builtin index · File I/O

write_float(f, n, [endian=])

Input: f, n, endian · Output: no output

What it is

Writes n (number) to f (file handle, opened writable/appendable) as a 32-bit IEEE-754 float. endian (string, optional, default "little", or "big") selects byte order.

Overloads

One call shape — this function is not overloaded.

From the documentation, and run by the build -- the output and the figure below are what the engine actually produced. Simplest first.

g = fopen("record.bin", "rb")
n = read_int32(g)
x = read_float(g)
close(g)
