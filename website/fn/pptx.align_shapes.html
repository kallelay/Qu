pptx.align_shapes

Builtin index · File I/O

pptx.align_shapes(p, i, shapes, how, [to="selection"])

Input: p, i, shapes, how, to · Output: no output

What it is

Lines shapes (a list of ids and/or names) up: how is "left", "right", "top", "bottom", "center" (horizontally) or "middle" (vertically). to="selection" aligns to the bounding box of the shapes themselves (two or more needed, as PowerPoint's "Align Selected Objects"); to="slide" aligns each to the slide. A rotated shape is aligned by the box it fills on the page; shapes already in place are not rewritten. *Added in v0.4.7*

Overloads

One call shape — this function is not overloaded.
