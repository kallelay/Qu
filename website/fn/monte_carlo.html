monte_carlo

Builtin index · Signal processing

result = monte_carlo(f, n, [seed=])

Input: f, n, seed · Output: result

What it is

f: a string naming a zero-argument user-defined function (typically drawing its own randomness via randn/rand) returning a number; n: a number (integer), how many times to call it; seed (optional number).

Overloads

One call shape — this function is not overloaded.

How it works

monte_carlo(f, n, [seed=]) — repeatedly calls the zero-argument user function f (typically drawing its own randomness via randn/rand) n times and collects every result into a vector — the general pattern most Monte Carlo simulations need, without prescribing what f computes.
