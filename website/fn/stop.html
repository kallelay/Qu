stop

Builtin index · REPL & diagnostics

stop(t)

Input: t · Output: no output

What it is

Takes one argument, t (a timer object). Freezes the timer and resets the count to zero (unlike pause, which keeps it); returns none. Also stops any on elapsed(t)/on elapsedOnce(t) registration from firing until started again. The handle remains valid and reusable.

Overloads

One call shape — this function is not overloaded.

How it works

stop(t) — freeze AND reset the count to zero (unlike pause, which keeps it). The handle stays valid and reusable: start(t) after stop begins a fresh count from zero. Also stops any on elapsed(t)/on elapsedOnce(t) registration from firing (checked live by run_for) until started again.
