transform

Builtin index · Statistics & ML

result = scaler.transform(newX)

Input: newX · Output: result

What it is

Applies a fitted scaler Record scaler's stored parameters to a new matrix/vector/table newX with the same columns it was fitted on. Never refits, even if newX's own statistics differ.

Overloads

One call shape — this function is not overloaded.

Examples

From the documentation, and run by the build -- the output and the figure below are what the engine actually produced. Simplest first.

split = train_test_split(X, y, test_size = 0.25, seed = 1)
scaler = fit_scaler(split.X_train, method = "standard")
print("training column means: {round(scaler.mean, 3)}")

Xtr = scaler.transform(split.X_train)
Xte = scaler.transform(split.X_test)
print("train columns after scaling: {round(mean(Xtr, axis = 0), 3)}")
print("test columns after scaling:  {round(mean(Xte, axis = 0), 3)}")

How it works

scaler.transform(newX) — applies the *fitted* parameters to newX (never re-fits on it). newX's feature-column count must match what the scaler was fit on.
