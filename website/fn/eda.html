eda

Builtin index · Plotting

eda(table)

Input: table · Output: no output

What it is

table is a Table. One-call exploratory overview: a correlation heatmap in the first grid cell, plus one histogram per numeric column in the remaining cells, auto-gridded (ceil(sqrt(n)) columns for n numeric columns).

Overloads

One call shape — this function is not overloaded.

From the documentation, and run by the build -- the output and the figure below are what the engine actually produced. Simplest first.

df = table(a = randn(30, seed = 3), b = randn(30, seed = 4), c = randn(30, seed = 5))
eda(df)   # correlation heatmap + one histogram per numeric column, auto-gridded

print("columns: " + str(cols(df)))

How it works

eda(df) — a one-call exploratory-data-analysis overview: a correlation heatmap (reusing corr_heatmap's own build_corr_heatmap computation, not a second copy of it) in the first grid cell, plus one histogram per numeric column (reusing the same histogram_bins helper hist itself calls) in the remaining cells — the same figure.select_grid(rows, cols, index) multi-panel-in-one- call mechanism fvtool already established for "lay out several related panels from one builtin", just with a panel count computed from the table's own column count instead of fvtool's fixed 2x2.

From the note above this builtin in the interpreter, where the reasoning was written down as it was built.
