asin

Builtin index · Core maths

result = asin(x)

Input: x · Output: result

What it is

Inverse trigonometric functions, single-argument only (there is no two-argument atan2 in this table). x is a scalar, Vec, or Mat/Signal; asin/acos expect values in [-1, 1] and return radians in [-π/2, π/2]/[0, π] (an out-of-domain element gives NaN), while atan accepts any real value and returns radians in (-π/2, π/2). Return shape always matches x.

Overloads

One call shape — this function is not overloaded.
