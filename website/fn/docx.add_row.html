docx.add_row

Builtin index · File I/O

docx.add_row(doc, table, [values], [at=])

Input: doc, table, values, at · Output: no output

What it is

Inserts a row into body table table (0-based) so it becomes row at (default: appended). values is a list with one item per cell, the rest left blank. The new row copies its neighbour's layout -- cell widths, borders, shading, merges, and the first run's formatting -- but never a header row's "repeat on every page" flag or bold; a row inserted inside a vertically merged block joins the merge. *Added in v0.4.7*

Overloads

One call shape — this function is not overloaded.
