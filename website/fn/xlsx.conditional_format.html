xlsx.conditional_format

Builtin index · File I/O

xlsx.conditional_format(wb, sheet, range, rule, value, [value2], [fill=], [color=], [bold=])

Input: wb, sheet, range, rule, value, value2, fill, color, bold · Output: no output

What it is

Highlights the cells of range that satisfy rule: "greater_than", "less_than", "greater_equal", "less_equal", "equal", "not_equal", "between"/"not_between" (two values, inclusive), or "contains" (text, case-insensitive). A value is a number, a string (compared as text), or a string starting with = (an Excel formula, e.g. "=$B$1"). fill= is the background, color= the font colour (names or #rrggbb); with none of fill/color/bold given it uses Excel's default light-red fill with dark-red text.

Overloads

One call shape — this function is not overloaded.
