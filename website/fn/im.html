im

Builtin index · Core maths

result = im(x)

Input: x · Output: result

What it is

Imaginary component of a Complex/CVec/CMat (0 elementwise when x is real). x is a scalar, Vec, or Mat (real or complex).

Overloads

x can be scalar, Vec, Mat, or Complex.
