describe

Builtin index · Collections & strings

result = describe(df)

Input: df · Output: result

What it is

df is a Table. Pandas-style describe(): returns a Table with one row per summary statistic (count, mean, std, min, 25%, 50%, 75%, max) and one column per NUMERIC column of df (text columns are skipped).

Overloads

One call shape — this function is not overloaded.

How it works

describe(df) — pandas' DataFrame.describe(): one row per summary statistic (count, mean, std, min, 25%, 50%, 75%, max), one column per NUMERIC column of df (text columns are skipped, same filter corr_heatmap already applies — a mean/quantile of a text column isn't meaningful). Returned as a genuine Value::Table (not a Model handle): a table-of-stats reads and prints naturally with the existing table machinery (head, select, print, ...) and keeps the per-column layout pandas users expect, whereas a Model handle's flat named fields would force one field per column instead of one row-labeled table. Every number is computed via the existing free std_dev/quantile_of helpers (the same ones std/quantile themselves call) — no separate statistics implementation.
