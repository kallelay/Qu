xticklabels

Builtin index · Plotting

xticklabels("a", "b", ...)

Input: "a", "b", ... · Output: no output

What it is

Sets categorical x tick labels from the given strings (variadic positional arguments); without an xticks(...) call, spread evenly across the current x-extent.

Overloads

One call shape — this function is not overloaded.

How it works

xticklabels("low", "mid", "high") — categorical x-axis labels; without xticks, spread evenly across the current x-extent (the common case: category series already sit at evenly-spaced x positions spanning it).
