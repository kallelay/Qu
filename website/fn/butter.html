butter

Builtin index · Signal processing

result = butter(order, kind, cutoff, fs)

Input: order, kind, cutoff, fs · Output: result

What it is

order: number (filter order); kind: string; cutoff: number or length-2 vector (Hz); fs: number (Hz).

Overloads

cutoff can be number or vector.

How it works

butter(order, kind, cutoff, fs) — designs a digital Butterworth filter as a cascade of second-order sections (SOS), the numerically stable representation used no matter the order. kind is "low"/"high"/"band"/ "stop" ("bandpass"/"lowpass"/"highpass"/ "bandstop"/"notch" all accepted as more readable aliases). cutoff is one frequency in Hz for low/high, or [low, high] for band/stop. Model kind "filter", field sos (a matrix, one section per row: [b0,b1,b2,a1,a2]).
