sine

Builtin index · Signal processing

result = sine(freq, fs, n, [phase=0], [amplitude=1])

Input: freq, fs, n, phase, amplitude · Output: result

What it is

freq, fs: numbers (Hz); n: number (integer sample count); phase (optional number, radians); amplitude (optional number).

Overloads

One call shape — this function is not overloaded.

How it works

pwm, plus DIBS excitation signals via composition with the already-real elementwise sign and the new sigma_delta primitive rather than dedicated _signum/_dibs builtins — chirp(...) |> sign is a signum chirp, multisine(...) |> sigma_delta is a DIBS-ΔΣ excitation, with no new surface area needed for either. sine(freq, fs, n, [phase=], [amplitude=]) — a single-tone generator built on the exact same synthesis kernel multisine uses (a sine is a one-tone multisine); returns a Signal (carries Fs, like signal(...)/randn don't but arguably should — this generator family is where Fs metadata earns its keep).
