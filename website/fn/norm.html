norm

Builtin index · Core maths

result = norm(x)

Input: x · Output: result

What it is

Euclidean (L2) norm; for a matrix this is the Frobenius norm (every element treated as one long vector), not a matrix operator norm. x is a scalar, Vec, or Mat (real, or CVec/CMat, which norm by magnitude).

Overloads

One call shape — this function is not overloaded.
