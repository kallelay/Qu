builtins

Builtin index · REPL & diagnostics

result = builtins()

Input: no input · Output: result

What it is

Takes no arguments.

Overloads

One call shape — this function is not overloaded.

CodeInputOutputDescription
result = builtins()no input
result List or string
Returns a List of strings: every name the engine answers to (hundreds of entries; the exact count grows as builtins are added). The builtin index is this list joined against the chapters.

Examples

From the documentation, and run by the build -- the output and the figure below are what the engine actually produced. Simplest first.

names = builtins()
print("total builtins: {len(names)}")
hits = apropos("filter")
print("filter-related: {hits}")
help("curve_fit")

from repl-diagnostics

How it works

--- finding things --------------------------------------- Qu has 650 builtins and, until these, no index from inside the language: no help, no apropos, no way to list them. The only route was guessing or opening catalog/. builtins() -- every name, sorted.

From the note above this builtin in the interpreter, where the reasoning was written down as it was built.
