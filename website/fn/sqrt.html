sqrt

Builtin index · Core maths

result = sqrt(x)

Input: x · Output: result

What it is

Elementwise square root. x is a scalar, Vec, or Mat/Signal; a negative element gives NaN (there is no automatic promotion to a complex result).

Overloads

One call shape — this function is not overloaded.

CodeInputOutputDescription
result = sqrt(x)
x scalar, Vec, Mat, or Signalnot documented yet
result —
Returns the same shape as x.
