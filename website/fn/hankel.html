hankel

Builtin index · Core maths

hankel(c, [r])

Input: c, r · Output: no output

What it is

Hankel matrix (constant anti-diagonals) with first column c; with r (the last row, whose first element is ignored in favour of c's last) it is length(c)×length(r), without it entries below the anti-diagonal are 0. Real Vecs. Errors: an empty vector, complex input.

Overloads

One call shape — this function is not overloaded.
