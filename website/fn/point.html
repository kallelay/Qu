point

Builtin index · Plotting

point(x, y)

Input: x, y · Output: no output

What it is

Marks a single position (x, y) (numbers, data units) with a dot.

Overloads

One call shape — this function is not overloaded.

From the documentation, and run by the build -- the output and the figure below are what the engine actually produced. Simplest first.

# A square canvas, so that equal ranges really are equal scales and the

figure_size(560, 560)

How it works

A "radioactive" callout point: a highlighted marker at (x, y) labeled with its own coordinates, for calling out a specific sample without a separate text() call.

From the note above this builtin in the interpreter, where the reasoning was written down as it was built.
