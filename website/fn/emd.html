emd

Builtin index · Signal processing

result = emd(x, [max_imfs=])

Input: x, max_imfs · Output: result

What it is

x: a length-N real vector. max_imfs (optional number): caps the number of IMFs extracted. Empirical Mode Decomposition: splits x into oscillatory intrinsic mode functions (IMFs, highest frequency first) plus a residual trend, via the standard sifting algorithm.

Overloads

One call shape — this function is not overloaded.

How it works

emd(x, [max_imfs=]) — Empirical Mode Decomposition: splits x into a small number of oscillatory intrinsic mode functions (IMFs, highest frequency first) plus a residual trend, via the standard sifting algorithm. Model kind "emd", fields imfs (a matrix, one IMF per row — e.imfs has zero rows if x had no oscillation to extract at all), residual (a Vec), and count (the number of IMFs). sum(e.imfs, axis=0) + e.residual reconstructs x exactly.
