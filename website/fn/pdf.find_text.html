pdf.find_text

Builtin index · File I/O

result = pdf.find_text(src, query, [case_sensitive=])

Input: src, query, case_sensitive · Output: result

What it is

Searches every page's pdf.extract_text output for query (built on that function, not a separate reconstruction — the same warning below applies: a page extract_text cannot read is a page this cannot search either, and errors the same way). case_sensitive defaults to true; passing false case-folds character-by-character rather than via a byte comparison.

Overloads

One call shape — this function is not overloaded.
