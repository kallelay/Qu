groupbar

Builtin index · Plotting

groupbar(x, y)

Input: x, y · Output: no output

What it is

Grouped (side-by-side) bar chart: x (Vec, category positions) and y (Mat or list of Vecs, one series per group of bars).

Overloads

One call shape — this function is not overloaded.

How it works

stair is the only callable spelling: step is already a reserved keyword (to ... step ... ranges), so step(...) can't be a function call — it lexes as a keyword, not an identifier. The rendered marker is internally still "step".

From the note above this builtin in the interpreter, where the reasoning was written down as it was built.
