write

Builtin index · REPL & diagnostics

write(v1, v2, ...) or write(fileHandle, s)

Input: v1, v2, ... · Output: no output

What it is

Dispatches on the type of the first argument. With ordinary values v1, v2, ... (any printable type): prints them space-joined, without a trailing newline (unlike print/echo). With a fileHandle (the handle object returned by fopen) as the first argument and a string s as the second: instead writes the raw string s to that open file, with no newline added and no console output.
