cheby1

Builtin index · Signal processing

result = cheby1(order, ripple_db, kind, cutoff, fs)

Input: order, ripple_db, kind, cutoff, fs · Output: result

What it is

order: number; ripple_db: number (dB); kind: string; cutoff: number or length-2 vector (Hz); fs: number (Hz).

Overloads

cutoff can be number or vector.

How it works

cheby1(order, ripple_db, kind, cutoff, fs) — designs a digital Chebyshev Type I filter: equiripple in the passband (bounded by ripple_db dB), monotonic in the stopband, steeper rolloff than Butterworth at the same order. Same kind/cutoff/fs conventions as butter; cutoff is the point in the transition band where the gain first drops below -ripple_db (matching MATLAB's/SciPy's own cheby1(n, Rp, Wn)), not Butterworth's -3dB point. Model kind "filter", field sos — same shape as butter/ellip, so every generic filter function works on a cheby1 design with no changes at all.
