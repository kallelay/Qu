xlsx.add_nyquist_chart

Builtin index · File I/O

xlsx.add_nyquist_chart(wb, sheet, re, im, [negate=true], [helper=], [name=], [color=], [title=], [x_title="Z' / Ω"], [y_title="-Z'' / Ω"], [at=], [width=150], [height=110], [lines=false], [markers=], [legend=])

Input: wb, sheet, re, im, negate, helper, name, color, title, x_title, y_title, at, width, height, lines, markers, legend · Output: no output

What it is

A Nyquist plot for impedance spectroscopy: Z' (range re) along x, -Z'' up, the axes on the SAME scale with square gridlines, so a semicircle stays round. With negate=true (Z'' stored with its sign, negative for a capacitive arc) a helper column of =-Z'' formulas is written -- in column helper= (a letter), default the first free column right of the used range, with a -<header> label above it when there is a header row -- and its range is returned, e.g. "D2:D40"; with negate=false im is plotted as it is, no cell changes, and none is returned. The axis limits follow the data at save time. *Added in v0.4.5*

Overloads

One call shape — this function is not overloaded.
