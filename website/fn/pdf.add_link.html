pdf.add_link

Builtin index · File I/O

result = pdf.add_link(src, page_index, rect=, target_page=)

Input: src, page_index, rect, target_page · Output: result

What it is

Adds a /Link annotation over rect= that jumps to target_page= (one-based) of the SAME document.

Overloads

One call shape — this function is not overloaded.
