argmean

Builtin index · Core maths

result = argmean(x)

Input: x · Output: result

What it is

Index into x (a Vec or flattened Mat/Signal) of the element closest to mean(x) (ties broken by first occurrence) — not a true order-statistic index like the others above, since the mean generally isn't any actual data point.

Overloads

One call shape — this function is not overloaded.

CodeInputOutputDescription

Returns a scalar Num index (0-based); errors on an empty x.

How it works

argmean(x) — the index of the element closest to mean(x) (ties broken by first occurrence). Not a standard order- statistic index like the others above (the mean generally isn't any actual data point) — a nearest-neighbor-to-the- mean index instead, which is the only way "argmean" can mean anything concrete.
