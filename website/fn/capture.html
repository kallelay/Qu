capture

Builtin index · Plotting

result = capture("fn", [args...])

Input: "fn", args... · Output: result

What it is

Runs the named drawing function "fn" (string, a function you defined) into a scratch panel, passing along any further positional args..., and keeps what it drew as a value (a "layer"). See Layers, near the top of this chapter.

Overloads

One call shape — this function is not overloaded.

How it works

── layers ────────────────────────────────────────────────── capture("draw_leaf") runs your function into a scratch panel and keeps what it drew, as a VALUE. stamp(l, x, y) puts a transformed copy on the real panel. A value rather than a mode, deliberately: a layer can be passed, returned, held in a list, and duplicated by ordinary assignment, where a stateful recorder with a begin and an end is one more thing to forget to close. It separates WHAT is drawn from WHERE, which is the whole point -- a sensor symbol, a leaf, a bolt described once and placed forty times.
