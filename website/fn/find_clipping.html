find_clipping

Builtin index · Signal processing

result = find_clipping(x, [threshold=], [full_scale=], [tol=], [min_run=3])

Input: x, threshold, full_scale, tol, min_run · Output: result

What it is

Same detection as is_clipped, same keywords, but returns *where*.

How it works

Returns a Value::Model, the named-field multi-return this engine already uses for findpeaks/qr/svd -- Qu has no tuple unpacking, and clipping is never one number. threshold/tol/min_run are echoed back on purpose: when the threshold was inferred from the record, a caller reading only starts has no way to know what level the answer is relative to.

From the note above this builtin in the interpreter, where the reasoning was written down as it was built.
