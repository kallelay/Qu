docx.add_list_item

Builtin index · File I/O

docx.add_list_item(doc, text, [kind="bullet"], [level=0], [restart=false])

Input: doc, text, kind, level, restart · Output: no output

What it is

Appends a bulleted (kind="bullet") or numbered (kind="number") list paragraph at nesting level 0-8, creating the document's numbering definitions when it has none. Consecutive numbered items continue one list; restart=true starts again from 1. Numbered levels go 1. / a. / i.; bullets •, ◦, ▪. *Added in v0.4.5*

Overloads

One call shape — this function is not overloaded.
