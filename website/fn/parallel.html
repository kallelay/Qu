parallel

Builtin index · Signal processing

parallel(a, b, ...)

Input: a, b, ... · Output: no output

What it is

Two or more circuits in parallel; admittances add. An ideal short in any branch shorts the block.

Overloads

One call shape — this function is not overloaded.

From the documentation, and run by the build -- the output and the figure below are what the engine actually produced. Simplest first.

nyquist(Z)

How it works

Composition. Variadic, because series(a, b, c) is one node and series(series(a, b), c) is two that mean the same thing -- and the flat form is what a spec string round-trips to.
