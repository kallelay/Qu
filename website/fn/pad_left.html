pad_left

Builtin index · Collections & strings

result = pad_left(s, width, [fill=" "])

Input: s, width, fill · Output: result

What it is

s is a Str; width (number, target character count); optional fill (single-character Str, default " "). Pads on the left to width characters; a string already that wide is returned unchanged, never truncated.

Overloads

One call shape — this function is not overloaded.

How it works

pad_left(s, width, [fill]) / pad_right(...) — pad to a width in CHARACTERS. A string already at or past the width is returned unchanged rather than truncated: padding is for lining columns up, and silently losing text to make a column fit is never what was meant.
