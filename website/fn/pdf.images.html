pdf.images

Builtin index · File I/O

pdf.images(src, [pages], [page=])

Input: src, pages, page · Output: no output

What it is

Lists the embedded images (image XObjects) of the pages asked for, default every page, as a List of Records: page (Num), index (Num, from 1 within the page -- the number pdf.extract_image takes), name (Str, the resource name; an image inside a Form XObject, searched one level deep, is Form/Image), width, height, bits (Num; 1 for an image mask), colorspace (Str, e.g. DeviceRGB, ICCBased, Indexed, ImageMask, or none), filter (Str, the filters joined by ,, or none) and bytes (Num, the size of the stored, still-encoded stream). Inline images (BI ... EI) are not listed. An empty List, not an error, for a page with none.

Overloads

One call shape — this function is not overloaded.
