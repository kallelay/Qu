viterbi

Builtin index · Statistics & ML

result = hmm.viterbi(obs)

Input: obs · Output: result

What it is

Runs the Viterbi algorithm on an hmm model hmm for a length-T integer observation sequence obs (same encoding as forward).

Overloads

One call shape — this function is not overloaded.

CodeInputOutputDescription
result = hmm.viterbi(obs)
obs vectornot documented yet
result vector
Returns a length-T vector of integer hidden-state indices: the single most likely path, not a distribution over paths.

How it works

viterbi(model, obs) — callable as model.viterbi(obs). The HMM's most likely hidden-state path given the 0-based observation-symbol sequence obs (Viterbi decoding). See hmm_viterbi's own doc comment for the dynamic program.
