write_byte

Builtin index · File I/O

write_byte(f, b)

Input: f, b · Output: no output

What it is

Writes one raw byte to f (file handle, opened writable/appendable). b (number) must be in 0..=255, or the call errors.

Overloads

One call shape — this function is not overloaded.
