raincloud

Builtin index · Plotting

raincloud(data) / raincloud(data1, ...)

Input: data · Output: no output

What it is

Allen et al. (2019) raincloud plot: one group per argument (each a Vec of numbers) at x = 0, 1, 2, ..., each rendered as a Gaussian KDE "cloud" + boxplot + jittered raw points ("rain").

Overloads

One call shape — this function is not overloaded.
