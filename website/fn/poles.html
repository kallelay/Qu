Returns each biquad section's z^2 + a1*z + a2 = 0 roots as a CVec — genuine, generally complex, poles.

An FIR filter has no feedback at all, so every pole sits at the origin regardless of the design — the same fact is_stable's "an FIR filter is always stable" relies on.

Examples

Written for this form and run by the build -- the output below is what the engine actually produced.

fs = 1000

# FIR poles: [0, 0, 0, 0, 0, 0]
output

How it works

poles(filt) — for an IIR (sos) filter, each biquad section's z^2 + a1*z + a2 = 0 roots; for an FIR (b) filter, all poles sit at the origin (no feedback at all — see numeric::filter::fir_poles's doc comment for the exact convention). Collected across sections/taps into one CVec.
