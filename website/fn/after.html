after

Builtin index · Collections & strings

result = after(s, mark)

Input: s, mark · Output: result

What it is

s and mark are Strs. after returns the piece of s past the first mark; before returns the piece up to it. after_last/before_last search from the other end. A mark that is not present leaves s whole (returned unchanged), never empty.

Overloads

One call shape — this function is not overloaded.

How it works

after(s, mark) / before(s, mark) — the piece past, or up to, a marker. Written as a pair because they chain: s.after("BEGIN").before("END") is the whole idiom, and it reads in the order the text does. A marker that is not there yields the WHOLE string rather than an error or an empty one. before on a line with no comment marker should be the line; after on a header that never appeared should be the body you were handed. An empty result would silently discard the text.
