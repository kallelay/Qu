tree_model

Builtin index · Statistics & ML

result = tree_model(X, y, [max_depth=20], [min_samples_split=2], [kind=])

Input: X, y, max_depth, min_samples_split, kind · Output: result

What it is

One CART decision tree on an N-row, D-column matrix X and a length-N target y, with max_depth (integer, default 20) limiting tree depth, min_samples_split (integer, default 2) the minimum node size to keep splitting, and kind a string, "regression" or "classification" (never inferred — must be given explicitly when it matters). Splits by variance reduction for regression, Gini impurity for classification.

Overloads

X can be number, matrix, or string; y can be number, matrix, or string; max_depth can be number, matrix, or string; min_samples_split can be number, matrix, or string; kind can be number, matrix, or string.

How it works

tree_model(X, y, [max_depth=], [min_samples_split=], [kind=]) — a single CART-style tree (see TreeArrays's own doc comment for the flat array representation, and build_tree's for the splitting rule). kind= is explicit, not auto-detected from y ("looks categorical" is genuinely ambiguous — a 0/1 target and a small integer *count* regression target look identical at the type level): kind="regression" (default, variance/SSE reduction) or kind="classification" (Gini impurity).
