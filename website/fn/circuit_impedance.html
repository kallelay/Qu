How it works

circuit_impedance(expr, f, theta) -- spec string straight to spectrum, in one call. This exists as its own builtin rather than as sugar for impedance(circuit(expr, theta), f) because of what it is FOR: papers/ecm-pf's cross-language check runs the same circuits through a Python implementation, a Qu library implementation and this one, and compares. Taking the STRING (not a circuit value built by a shared parser) is what keeps the columns independent -- if two of them shared a parser, a parser bug would cancel out of the comparison and the check would pass with both columns wrong. Argument order and Hz are that suite's, adopted rather than invented.
