sort

Builtin index · Collections & strings

result = sort(list, [descending])

Input: list, descending · Output: result

What it is

list is a List of Str or a numeric Vec; optional descending (bool, default false). A list of strings sorts lexicographically, a numeric vector sorts numerically.

Overloads

list_of_str can be List or Str.

How it works

sort(x, [descending]) — ascending by default, matching sort_by(table, col, [descending])'s own positional-bool convention rather than a desc=/order= kwarg. Uses f64::total_cmp rather than partial_cmp().unwrap_or( Equal) — the latter isn't a valid total order (it treats a NaN as "equal" to everything), which doesn't just leave the NaN in an arbitrary spot but silently corrupts the ordering of the *other*, perfectly sortable elements around it too: sort([5, 3, nan, 1, 4, 2]) used to return [3, 5, NaN, 1, 2, 4] (genuinely unsorted), not merely "sorted except for where NaN landed."
