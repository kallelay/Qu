corrcoef

Builtin index · Statistics & ML

result = corrcoef(M)

Input: M · Output: result

What it is

Called on an N-row, D-column matrix or table M, returns the full (D, D) matrix of pairwise Pearson correlations between its columns. For two length-N vectors x/y, use corr(x, y) instead, which returns their correlation as a single number. corr_heatmap draws the same corrcoef numbers as a plot.

Overloads

One call shape — this function is not overloaded.

How it works

corrcoef(X) — the full pairwise Pearson correlation matrix of a data matrix X (rows = samples, cols = features): an NxN Mat (N = number of columns) whose [i,j] entry is corr(X[:,i], X[:,j]). Symmetric with a diagonal of 1s. Distinct from corr_heatmap/corrplot, which do the same computation over a Table's numeric columns and push a plot Heatmap directly rather than returning the matrix value — heatmap(corrcoef(X)) recombines the two.
