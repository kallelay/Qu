save_model

Builtin index · Statistics & ML

save_model(m, path)

Input: m, path · Output: no output

What it is

Writes a fitted kind="sequential" model Record m (from sequential/compile/quick_mlp/mlp_classifier/etc.) to an HDF5 file at the string path, weights and all, in a Keras-compatible layout.

Overloads

One call shape — this function is not overloaded.
