pdf.add_text

Builtin index · File I/O

result = pdf.add_text(src, page, x, y, text, [size=12], [color=[0,0,0]], [font="Helvetica"])

Input: src, page, x, y, text, size, color, font · Output: result

What it is

Stamps one line of text on a page with its baseline starting at (x, y) in PDF points from the bottom-left of the unrotated page (/Rotate and /CropBox are not compensated). font is one of the 12 standard fonts (Helvetica, Helvetica-Bold, Times-Roman, Courier, ...); text is WinAnsi-encoded, so characters outside Western European + common punctuation, and newlines, are errors. The existing page content is wrapped in q/Q so it cannot affect the stamp.

Overloads

One call shape — this function is not overloaded.
