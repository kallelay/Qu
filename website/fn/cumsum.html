cumsum

Builtin index · Collections & strings

result = cumsum(x)

Input: x · Output: result

What it is

x is a numeric Vec or Signal.

Overloads

One call shape — this function is not overloaded.

CodeInputOutputDescription
result = cumsum(x)
x Vec or Signalnot documented yet
result Signal
Returns the running sum, same type/length as x; a Signal input stays a Signal with the same Fs.

Examples

From the documentation, and run by the build -- the output and the figure below are what the engine actually produced. Simplest first.

ys = [3, 1, 4, 1, 5]
print(contains(ys, 4))     # true

print(indexof(ys, 4))      # 2

print(cumsum(ys))          # [3, 4, 8, 9, 14]

print(numel(ys))           # 5
