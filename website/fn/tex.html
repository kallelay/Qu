tex

Builtin index · Plotting

result = tex(x)

Input: x · Output: result

What it is

Not figure export — converts a single Qu value x (number, Vec, Mat, or complex) to a LaTeX math-mode string (e.g. a matrix becomes a bmatrix environment) and returns it as a string. Pairs with str the way printtex pairs with print.

Overloads

x can be number, Complex, scalar, Vec, or Mat.

3 forms. Each carries its own inputs, outputs and worked example — pick the tab for the one you are calling.
