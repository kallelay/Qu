sign

Builtin index · Core maths

result = sign(x)

Input: x · Output: result

What it is

The sign of each element, using Rust's f64::signum semantics: -1 for a negative value (including -0.0), +1 for a non-negative value (including +0.0 — so sign(0) returns 1, never 0, a real edge case worth knowing about), and NaN for a NaN input. x is a scalar, Vec, or Mat/Signal.

Overloads

One call shape — this function is not overloaded.
