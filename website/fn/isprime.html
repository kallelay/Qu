isprime

Builtin index · Core maths

isprime(n)

Input: n · Output: no output

What it is

Whether the integer n is prime: a Bool for a number, a Mask for a Vec of integers. 0, 1 and negatives are not prime. Exact over the whole range up to 2^53 (deterministic Miller-Rabin). Errors: a non-integer, or a magnitude above 2^53.

Overloads

One call shape — this function is not overloaded.
