add_node

Builtin index · Collections & strings

add_node(g, name)

Input: g, name · Output: no output

What it is

g is a graph handle; name is a Str/number node id; add_edge(g, a, b, [weight=1.0]) also takes a second node id and an optional weight (number, default 1.0). Nodes are named; an edge carries an optional weight, defaulting to 1.

Overloads

One call shape — this function is not overloaded.

Examples

From the documentation, and run by the build -- the output and the figure below are what the engine actually produced. Simplest first.

h = graph()
add_node(h, "X")          # an isolated node, no edges yet

h.add_edge("X", "Y")
print(has_edge(h, "X", "Y"))   # true

print(has_edge(h, "X", "Z"))   # false -- Z isn't even a node

print(neighbors(h, "X"))       # ("Y")
