read_float

Builtin index · File I/O

result = read_float(f, [endian=])

Input: f, endian · Output: result

What it is

Reads a 32-bit IEEE-754 float from f (file handle, opened readable). endian (string, optional, default "little", or "big") selects byte order.

Overloads

One call shape — this function is not overloaded.
