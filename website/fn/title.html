title

Builtin index · Plotting

title(text, [align=])

Input: text, align · Output: no output

What it is

Sets the current panel's title to text (string). align= (string, "left"/"center"/"right", default "center") sets its horizontal alignment.

Overloads

One call shape — this function is not overloaded.
