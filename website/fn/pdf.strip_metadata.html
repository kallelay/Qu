pdf.strip_metadata

Builtin index · File I/O

result = pdf.strip_metadata(src)

Input: src · Output: result

What it is

Removes a PDF's /Info dictionary entirely, and its catalog's /Metadata XMP stream reference if it has one (the XMP stream's own contents are not parsed — only the reference to it is removed, since this module has no XMP reader). A file with no /Info at all is not an error.

Overloads

One call shape — this function is not overloaded.
