imdilate

Builtin index · Images

result = imdilate(img, radius)

Input: img, radius · Output: result

What it is

img is a binary (0/255 mask-style) Image; radius is a positive integer, the half-width of a square structuring element of side 2*radius+1 (a documented choice over a disk element). Performs binary morphological dilation, growing foreground regions.

imdilate/imerode/imopen/imclose/imtophat/imbothat are all implemented as a per-channel MAX (dilate) or MIN (erode) over the structuring window — true grayscale morphology, not "threshold then grow." No threshold/ otsu_threshold builtin existed in this shared working tree when this landed (a sibling agent's own lane) — this is a documented, independent design choice, not a guess at matching code that hadn't landed yet; reconcile if the sibling's own producer ends up using a different convention. imerode(img, radius) / imdilate(img, radius) — a square structuring element of side 2*radius+1 (documented choice over a disk — see image::Image::erode's doc comment).
