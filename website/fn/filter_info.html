filter_info

Builtin index · Signal processing

result = filter_info(filt, [n=2048])

Input: filt, n · Output: result

What it is

filt: a Model (kind "filter"); n (optional number): frequency points.

Overloads

One call shape — this function is not overloaded.

Returns one record of the numbers shown beside a filter's plots: fs, stable, stability_margin (1 minus the largest pole radius), dc_gain, dc_gain_db, delay (group delay at DC, seconds) and delay_samples, impulse_length (samples holding 99.9 % of the impulse energy), cutoff_3db (Hz, NaN if it never crosses), tau (step response, 63.2 %), tau_pole (from the slowest pole, NaN for FIR), rise_time, settling_time, overshoot_pct. Times are in seconds when the filter carries fs, else samples.

How it works

filter_info(filt, [n=2048]) -- the numbers next to a filter's plots, in one record: delay (DC group delay), impulse length, step timing, tau (step 63.2 % and dominant pole), -3 dB cutoff, DC gain, stability distance. Times in seconds (samples if no fs).
