sosfilt

Builtin index · Signal processing

result = sosfilt(filt, x)

Input: filt, x · Output: result

What it is

filt: a Model (kind "filter", field sos or b); x: a length-N vector or Signal.

Overloads

x can be vector or Signal.

2 forms. Each carries its own inputs, outputs and worked example — pick the tab for the one you are calling.

Examples

Written for this form and run by the build -- the output below is what the engine actually produced.

fs = 100
t = (0 to 19) / fs
x = sin(2*pi*10*t)
iir = butter(2, "low", 20, fs)
y_iir = sosfilt(iir, x)
print("IIR-filtered length: {length(y_iir)}")   # IIR-filtered length: 20
