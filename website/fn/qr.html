qr

Builtin index · Core maths

result = qr(A)

Input: A · Output: result

What it is

Thin QR decomposition of A (r×c Mat), A = Q·R.

Overloads

One call shape — this function is not overloaded.

CodeInputOutputDescription
result = qr(A)
A Matnot documented yet
Model —kind "qr"
q Matr×k Mat, orthonormal columns
r Matk×c Mat, upper triangular
Returns a Model (kind "qr") with fields q (r×k Mat, orthonormal columns) and r (k×c Mat, upper triangular), k = min(r,c).

res = qr(M)

print("r = {res.r}")

    return "qr: q is {rows(m.q)}x{cols(m.q)}, r is {rows(m.r)}x{cols(m.r)}"

How it works

qr(A) — the thin QR decomposition A = Q * R. Model kind "qr", fields q/r.
