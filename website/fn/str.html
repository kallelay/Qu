str

Builtin index · Collections & strings

result = str(x)

Input: x · Output: result

What it is

Renders x (any value/type) the same way print/disp would.

Overloads

One call shape — this function is not overloaded.

How it works

str(x) — render any value the same way print/disp would, as a string. Exists mainly so loop bodies can build per-iteration labels ("s" + str(i+1)) — see the + string-concat case in binop below, which this pairs with.

From the note above this builtin in the interpreter, where the reasoning was written down as it was built.
