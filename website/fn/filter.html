filter

Builtin index · Collections & strings

result = filter(df, mask)

Input: df, mask · Output: result

What it is

df is a Table; mask is a boolean Vec/Mask the same length as df's rows (typically built from a comparison, e.g. df.x > 0).

Overloads

One call shape — this function is not overloaded.
