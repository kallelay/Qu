kmeans_model

Builtin index · Statistics & ML

result = kmeans_model(X, k, [seed=])

Input: X, k, seed · Output: result

What it is

k-means as a reusable handle: fits on an N-row, D-column matrix X into k clusters (optional integer seed=), so .predict(Xnew) later assigns new rows to the nearest centroid rather than only labelling the fitting data.

Overloads

One call shape — this function is not overloaded.

How it works

kmeans_model(X, k, seed=) — wraps kmeans_fit's labels/centers in a handle so .predict(Xnew) (nearest- centroid assignment) and .score(X) (negative inertia, sklearn's convention: higher/less-negative is better) work on new data, which the flat kmeans/kmeans_centers can't do — those only ever describe the training set they were called on.
