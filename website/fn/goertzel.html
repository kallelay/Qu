goertzel

Builtin index · Signal processing

result = goertzel(x, k)

Input: x, k · Output: result

What it is

x is a length-N real vector; k (number) is the bin index to evaluate — need not be an integer (evaluates the DFT at an arbitrary point between the FFT's grid bins, a "K-point DFT").

Overloads

One call shape — this function is not overloaded.

Examples

From the documentation, and run by the build -- the output and the figure below are what the engine actually produced. Simplest first.

fs = 1000
n = 0:1:63
t = n / fs
x = sin(2*pi*100*t)

X = fft(x)
xr = idft(X)
print("idft roundtrip max err: {max(abs(xr - x))}")

k100 = 100 * length(x) / fs        # bin index equivalent to 100 Hz

bin100 = goertzel(x, k100)
print("goertzel magnitude at bin {k100}: {abs(bin100)}")
same = goertzel_freq(x, fs, 100)   # the Hz-parameterized convenience form

print("goertzel_freq agrees: {abs(same - bin100) < 1e-9}")

half = rfft(x)
back = irfft(half, 64)
print("rfft/irfft roundtrip max err: {max(abs(back - x))}")

How it works

goertzel(x, k) -- the DFT value at a single "bin" k in O(n), the standard tool for checking a handful of specific frequencies without paying for a whole FFT. k need not be an integer: this evaluates the DFT at an arbitrary frequency point between the FFT's own grid bins (a "K-point DFT"), not just a fast way to recover an on-grid one.
