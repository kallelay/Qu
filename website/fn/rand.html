rand

Builtin index · Statistics & ML

result = rand([rows], [cols], [seed=])

Input: rows, cols, seed · Output: result

What it is

Draws from the uniform distribution on [0, 1). rows/cols are integers, both defaulting to 1, giving the output shape (a number if both are 1, otherwise a vector or (rows, cols) matrix); an optional integer seed= starts a fresh reproducible stream, otherwise the shared stream advances.

Overloads

One call shape — this function is not overloaded.

How it works

rand/randn draw rows*cols samples. An explicit seed= gives a fresh reproducible local stream; otherwise the persistent stream advances so successive draws differ.
