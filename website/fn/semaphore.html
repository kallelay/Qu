semaphore

Builtin index · Concurrency

result = semaphore(n)

Input: n · Output: result

What it is

Creates a counting semaphore with n (integer, must be non-negative) initial permits.

Overloads

One call shape — this function is not overloaded.

CodeInputOutputDescription
result = semaphore(n)
n Semaphore, Mutex, or Channelnot documented yet
result Semaphore, Mutex, or Channel
Returns a Semaphore handle (type(s) == "semaphore"); cloning it shares the same counter, the same convention Mutex/Channel use.

Examples

How it works

semaphore(n) — a counting semaphore with n initial permits, for bounding concurrent access to a limited shared resource across spawn/parallel for workers (a hardware port, a connection pool, or just an explicit concurrency cap).
