pwm

Builtin index · Plotting

result = pwm(modulator, carrier_freq, fs, [carrier=])

Input: modulator, carrier_freq, fs, carrier · Output: result

What it is

Natural-sampling pulse-width modulation: modulator is a Vec of numbers (any signal, conventionally in [-1, 1]), carrier_freq and fs are numbers (Hz). Emits +1 where the modulator exceeds a carrier wave oscillating in [-1, 1] at carrier_freq, else -1. carrier= (string, "triangle" default or "sawtooth"/"saw") picks the carrier shape.

Overloads

One call shape — this function is not overloaded.

How it works

pwm(modulator, carrier_freq, fs, [carrier=]) — natural- sampling pulse-width modulation: +1 where modulator (any signal, conventionally in [-1, 1]) exceeds a carrier wave oscillating in [-1, 1] at carrier_freq, else -1. carrier="triangle" (default, the standard choice — see pwm_wave's own doc comment for why) or "sawtooth".
