group_by_agg

Builtin index · Collections & strings

result = group_by_agg(df, "group_col", "value_col", "agg")

Input: df, "group_col", "value_col", "agg" · Output: result

What it is

df is a Table; "group_col"/"value_col" are Str column names; agg is a Str naming the aggregate ("mean" by default, plus "sum", "min", "max", "count", etc.).

Overloads

One call shape — this function is not overloaded.

How it works

group_by_agg(table, "group_col", "value_col", "agg") — the original single-(col,agg) form, unchanged — OR group_by_agg(table, "group_col", [(col1,"agg1"), (col2,"agg2"), ...]) — a single call computing every listed (column, aggregate) pair in one pass over the table (Table::group_by_agg_multi; see its doc comment for why that's genuinely one pass, not the single-spec reduction called once per spec). The spec-list argument is a parenthesized Value::List of 2-element Value::List pairs, matching drop's own "single list argument for several at once" convention ([...] is always a numeric literal in Qu, so a bracketed pair list isn't an option — see drop's doc comment above).
