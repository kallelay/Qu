adaptive_threshold

Builtin index · Images

result = adaptive_threshold(image, block_size=, [method="mean"], [offset=0])

Input: image, block_size, method, offset · Output: result

What it is

image is an Image; block_size is a required odd positive integer, the side length of the per-pixel neighborhood. Locally adaptive, unlike threshold/otsu above: each pixel's own threshold is mean(neighborhood) - offset, where the neighborhood mean is a uniform box average (method="mean") or a Gaussian-weighted one (method="gaussian"). Binarized with the same >= convention as threshold.

Overloads

One call shape — this function is not overloaded.

How it works

These three compute a per-pixel threshold (or, for clahe, a per-pixel remapping) from each pixel's own local neighborhood instead. See image::Image::adaptive_threshold/ for the algorithms; these arms are just the argument parsing. adaptive_threshold(image, block_size=, [method="mean"], [offset=0]) — OpenCV-style adaptive threshold: local mean(neighborhood) - offset per pixel (method="mean": uniform box mean; "gaussian": Gaussian-weighted mean). block_size is a required keyword (must be odd) — no positional form, since "the 2nd argument is a block size" is easy to confuse with otsu-family builtins whose 2nd argument is a threshold LEVEL, not a window size.
