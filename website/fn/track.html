track

Builtin index · Statistics & ML

result = param(v) / track(v)

Input: v · Output: result

What it is

Wraps a plain number, vector, or matrix v as a fresh, differentiable Tensor — a new leaf node on the autodiff tape with no inputs of its own, so grad treats it as something to differentiate *with respect to* rather than something computed. param and track do exactly the same thing; the two names exist so a program can say which values are trainable weights (param) versus intermediate values you also want a gradient through (track) — a note to the reader, not a mechanical difference.

Overloads

One call shape — this function is not overloaded.

How it works

param(v)/track(v) (§38 autodiff): wraps a plain Num/ Mat (or promotes a Vec, matching to_matrix's own Vec-as-column convention, so a param's shape is always matmul-ready) as a fresh, untracked-yet root Value::Tensor — a new tape node with no inputs, so grad treats it as a leaf. param and track are the same operation; two names because the spec uses param for trainable weights and track for "differentiate through this too" on an ordinary intermediate value — the distinction is documentation, not mechanism, until optimizers exist to actually read it.
