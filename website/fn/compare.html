compare

Builtin index · Collections & strings

result = compare(a, b, [ignore_case])

Input: a, b, ignore_case · Output: result

What it is

a and b are Strs; optional ignore_case (bool, default false).

Overloads

One call shape — this function is not overloaded.

Returns a number: −1, 0 or 1, so it can drive a sort directly.

How it works

compare(a, b, [ignore_case]) — -1, 0 or 1, so it can drive a sort directly. Case-insensitive comparison is the reason this exists: lower(a) == lower(b) allocates two strings to answer a question that needs none.
