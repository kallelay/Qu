pptx.delete_slide

Builtin index · File I/O

pptx.delete_slide(p, i)

Input: p, i · Output: no output

What it is

Deletes a slide with its notes, and removes it from any section. pptx.move_slide(p, from, to) reorders; pptx.duplicate_slide(p, i) copies a slide (without its notes) right after itself and returns the copy's index; pptx.hide_slide/pptx.unhide_slide(p, i) skip it in the slide show.

Overloads

One call shape — this function is not overloaded.
