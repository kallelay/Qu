xlsx.get_cell

Builtin index · File I/O

result = xlsx.get_cell(wb, sheet, cell)

Input: wb, sheet, cell · Output: result

What it is

The value of one cell, cell as Excel shows it ("B3"); sheet is a name or a 0-based index.

Overloads

One call shape — this function is not overloaded.

CodeInputOutputDescription
result = xlsx.get_cell(wb, sheet, cell)
wb —not documented yet
sheet —sheet is a name or a 0-based index.
cell —The value of one cell, cell as Excel shows it ("B3").
result number, string, or boolean
Returns a number, string, boolean, or none for an empty cell. A formula cell returns the value last cached in the file, if any -- formulas are stored, not evaluated.
