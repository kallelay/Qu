mutex

Builtin index · Concurrency

result = mutex(initial)

Input: initial · Output: result

What it is

Creates a shared mutable cell holding initial (any value, of any type — the mutex has no fixed element type).

Overloads

One call shape — this function is not overloaded.

CodeInputOutputDescription
result = mutex(initial)
initial Mutexnot documented yet
result Mutex
Returns a Mutex handle (type(m) == "mutex"); cloning that handle (assigning it, capturing it into a worker's snapshot) shares the same underlying cell rather than copying the value inside it.

How it works

mutex(initial) — genuinely SHARED mutable state, the deliberate opt-in exception to spawn/parallel for's default share-nothing design: pass the same mutex variable into multiple workers (it survives an env-snapshot clone because cloning Value::Mutex clones the Arc, not the data — every clone still points at the same cell) when you genuinely need a shared counter, accumulator, or cache.

From the note above this builtin in the interpreter, where the reasoning was written down as it was built.
