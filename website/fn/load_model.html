load_model

Builtin index · Statistics & ML

result = load_model(path)

Input: path · Output: result

What it is

Reads a model previously written by save_model back from the HDF5 file at the string path.

Overloads

One call shape — this function is not overloaded.

CodeInputOutputDescription
result = load_model(path)
path stringnot documented yet
result Record
Returns a fitted kind="sequential" model Record with .predict ready to use immediately, so a fit does not have to be repeated.
