goertzel_freq

Builtin index · Signal processing

result = goertzel_freq(x, fs, freq)

Input: x, fs, freq · Output: result

What it is

x is a length-N real vector; fs (number, Hz) is the sample rate; freq is the frequency to evaluate (a number, Hz) or a length-K vector of frequencies.

Overloads

One call shape — this function is not overloaded.

Examples

  fs = 8000

from numerics-dsp

fs = 1000
n = 0:1:63
t = n / fs
x = sin(2*pi*100*t)

X = fft(x)
xr = idft(X)
print("idft roundtrip max err: {max(abs(xr - x))}")

k100 = 100 * length(x) / fs        # bin index equivalent to 100 Hz

bin100 = goertzel(x, k100)
print("goertzel magnitude at bin {k100}: {abs(bin100)}")
same = goertzel_freq(x, fs, 100)   # the Hz-parameterized convenience form

print("goertzel_freq agrees: {abs(same - bin100) < 1e-9}")

half = rfft(x)
back = irfft(half, 64)
print("rfft/irfft roundtrip max err: {max(abs(back - x))}")
output

goertzel magnitude at bin 6.4: 32.158025
goertzel_freq agrees: true
rfft/irfft roundtrip max err: 3.330669e-16

How it works

goertzel_freq(x, fs, freq) -- goertzel parameterized by a real frequency in Hz rather than a raw bin index, the common case (a known tone frequency at a fixed sample rate). freq may also be a vector of frequencies, same K-point-DFT batching as goertzel above, returning a CVec.
