hilb

Builtin index · Core maths

hilb(n)

Input: n · Output: no output

What it is

The n×n Hilbert matrix, H(i,j) = 1/(i+j-1) (1-based): symmetric, positive definite and famously ill-conditioned (cond(hilb(8)) is about 1.5e10). n is a whole number from 1 to 5000. Errors: a non-integer, zero or negative n, n above 5000.

Overloads

One call shape — this function is not overloaded.
