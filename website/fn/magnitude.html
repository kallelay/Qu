magnitude

Builtin index · Signal processing

result = magnitude(x)

Input: x · Output: result

What it is

An exact alias of abs — the same match arm, so the two names cannot drift apart. x: any real or complex number, vector or matrix, or an frf/impedance model (whose complex data it reads through).

Overloads

One call shape — this function is not overloaded.

CodeInputOutputDescription
result = magnitude(x)
x number, vector, or matrixnot documented yet
result —
Returns sqrt(re^2+im^2) elementwise for complex input and the absolute value for real input. Exists because toolkit-signal.md §11 spells the accessor Z.magnitude()/H.magnitude(), which method sugar rewrites to magnitude(Z). Added in v0.3.0.
