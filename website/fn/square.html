square

Builtin index · Plotting

result = square(freq, fs, n, [duty=])

Input: freq, fs, n, duty · Output: result

What it is

A bipolar (±1) periodic pulse train. freq (number, Hz) is the repetition rate; fs (number, Hz) is the sample rate the train is generated at; n (number) is how many samples to produce; duty= (number, 0–1, default 0.5) is the fraction of each period spent at +1 rather than -1.

Overloads

One call shape — this function is not overloaded.
