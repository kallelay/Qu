docx.track_insert

Builtin index · File I/O

docx.track_insert(doc, i, text, [after=], [before=], [author="Qu"], [date=])

Input: doc, i, text, after, before, author, date · Output: no output

What it is

Inserts text into body paragraph i as a tracked insertion (w:ins by author, ISO 8601 date, default now): directly after the first occurrence of after, directly before the first occurrence of before, or at the end. The text takes the formatting of the run next to it. docx.accept_changes keeps it, docx.reject_changes removes it. Refused inside a field or another tracked insertion. *Added in v0.4.7*

Overloads

One call shape — this function is not overloaded.
