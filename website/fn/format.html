format

Builtin index · Collections & strings

result = format(x, pattern)

Input: x, pattern · Output: result

What it is

x is a number; pattern is a Str picture: "0.00", "#,##0.0", "0.0%", "0.00e0". Interpolation ({x:.2f}) reads better inline; format is for a pattern held in a variable.

Overloads

One call shape — this function is not overloaded.

How it works

format(x, pattern) — a number rendered to a picture, BASIC's and Excel's. String interpolation ({x:.2f}) covers most of this and reads better inline; format is for the case interpolation cannot reach, where the pattern is in a variable. "0.00" two decimals, always "#,##0.0" thousands separators "0.0%" as a percentage "0.00e0" scientific
