cat

Builtin index · Core maths

result = cat(dim, a, b, ...)

Input: dim, a, b, ... · Output: result

What it is

MATLAB-style concatenation: dim (a scalar, 1 or 2) selects the axis, then the 2+ remaining arguments (same shape rules as hstack/vstack) are joined along it — dim=1 vertical (same as vstack), dim=2 horizontal (same as hstack).

Overloads

One call shape — this function is not overloaded.

How it works

cat(dim, a, b, ...) — MATLAB's own general concatenation form, matched exactly (dim=1 vertical, dim=2 horizontal): a direct, checkable spec to match rather than a Qu-specific convention.
