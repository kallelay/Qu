apply

Builtin index · Signal processing

result = apply(x, f)

Input: x, f · Output: result

What it is

x: a number, boolean, vector, matrix, or Signal; f: a one-argument function of a number returning a number — the function itself, or a Str naming one you defined.

Overloads

x can be number, boolean, Vec, Mat, or Signal; f can be number, boolean, Vec, Mat, Signal, or List.

Applies fnName elementwise and re-wraps the result at the SAME Fs — the one case map can't reproduce, since map always returns a plain List and drops the sample rate.

Examples

Written for this form and run by the build -- the output below is what the engine actually produced.

double(v) := v * 2
sig = signal([1, 2, 3, 4], 8)
s = sig.apply("double")
print("signal: {s}")   # signal: signal(Fs=8) [2, 4, 6, 8]
output
signal: signal(Fs=8) [2, 4, 6, 8]

apply is the one to reach for when you have your own user-defined transform and need it applied elementwise while KEEPING whatever container you started with — a Signal's sample rate in particular, which map would silently drop. The example below defines a trivial doubling function and applies it to a Signal, printing the result to show the Fs survives the round trip.

double(v) := v * 2
sig = signal([1, 2, 3, 4], 8)
out = sig.apply("double")     # same Fs, genuinely transformed

print("apply(double): {out}")
output
apply(double): signal(Fs=8) [2, 4, 6, 8]
