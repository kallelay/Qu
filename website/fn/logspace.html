logspace

Builtin index · Signal processing

result = logspace([a=0], [b=1], [n=50])

Input: a, b, n · Output: result

What it is

a, b (optional numbers, decade exponents); n (optional number, integer count).

Overloads

One call shape — this function is not overloaded.

CodeInputOutputDescription
result = logspace([a=0], [b=1], [n=50])
a number, optional (default 0)a, b (optional numbers, decade exponents).
b number, optional (default 1)a, b (optional numbers, decade exponents).
n number, optional (default 50)n (optional number, integer count).
result vector
Returns a length-n real vector, n logarithmically spaced points, 10^linspace(a, b, n) — used for frequency axes in Bode-style plots and rLKK's default DRT grid.

Examples

From the documentation, and run by the build -- the output and the figure below are what the engine actually produced. Simplest first.

freqs = logspace(0, 4, 20)
R = 100
C = 1e-6
w = 2 * pi * freqs
Z = R / (1 + 1j * w * R * C)         # a simple RC impedance, as measured data


target = logspace(-1, 5, 10)         # extends past the measured band on both sides

Z_ext = rlkk_extrapolate(Z, freqs, target, lambda=1e-4)
print("extrapolated {length(Z_ext)} points, first = {Z_ext[0]}, last = {Z_ext[9]}")

fit = rlkk_reconstruct(Z, freqs, lambda=1e-4)     # fit.z, fit.gamma

v = rlkk_validate(Z, freqs, lambda=1e-3, threshold=2.0)
if v.valid
    print("measurement is causal/linear/stable within {v.max_residual}%")
else
    print("bad points: {where(abs(v.residuals) > 2.0)}")
end
