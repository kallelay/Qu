xbreak

Builtin index · Plotting

xbreak(lo, hi)

Input: lo, hi · Output: no output

What it is

Reshapes the *main* x-axis's coordinate mapping with a fixed-width "//" jag that squeezes out the skipped range [lo, hi] (numbers, data units) — linear-scale axes only. Not a sub-panel (unlike zoom_inset).

Overloads

One call shape — this function is not overloaded.

How it works

xbreak(lo, hi)/ybreak(lo, hi) — a sibling of zoom_inset, not the same feature: this reshapes the *main* axis's own coordinate mapping (a fixed-width "//" jag squeezes the skipped (lo, hi) range instead of giving it pixel space proportional to its span), it doesn't add a sub-panel. See plotting::Panel.x_break's doc comment for the linear-scale- only scope limit.
