factorial

Builtin index · Core maths

factorial(n)

Input: n · Output: no output

What it is

n! for a non-negative integer number or Vec of them. Exact up to 18!; from 19! to 170! the result is the correctly rounded f64 product, not an exact integer. Errors: a negative or non-integer n, or n > 170 (the result overflows f64).

Overloads

One call shape — this function is not overloaded.
