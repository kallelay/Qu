vander

Builtin index · Core maths

vander(v, [n])

Input: v, n · Output: no output

What it is

Vandermonde matrix: row i is [v[i]^(n-1), ..., v[i], 1], a length(v)×n Mat (n defaults to length(v); 0^0 is 1). vander(x, k+1) * c evaluates the polynomial with coefficients c at x. Errors: an empty v, n < 1.

Overloads

One call shape — this function is not overloaded.
