find_peaks

Builtin index · Signal processing

result = find_peaks(x, [min_height=], [min_distance=], [min_prominence=])

Input: x, min_height, min_distance, min_prominence · Output: result

What it is

x is a length-N vector. min_height (optional number): minimum peak value; min_distance (optional number, samples): minimum separation, enforced greedily by height so a close cluster keeps its tallest member; min_prominence (optional number): minimum rise above surrounding terrain, not just absolute height.

Overloads

One call shape — this function is not overloaded.

below = find_peaks(-abs(r - 1/e))

from signal-processing

Fs = 1000
n = 0:1:1023
t = n / Fs
x = sin(2*pi*80*t) + 0.5*sin(2*pi*300*t)

X = fftc(x)
mag = abs(X)[0:512]                 # positive-frequency half

freqs = linspace(0, Fs/2, 512)
peaks = find_peaks(mag, min_height=max(mag)*0.2, min_distance=5)
print("tones at: {freqs[peaks]} Hz")
plot(freqs, mag)
xlabel("frequency (Hz)")

How it works

find_peaks(x, [min_height=], [min_distance=], [min_prominence=]) — indices of x's local maxima, optionally filtered by height, minimum separation (samples — enforced greedily by height, so a close cluster keeps its tallest member), and prominence (how much a peak rises above its own surrounding terrain, not just its absolute height).
