cos

Builtin index · Core maths

result = sin(x)

Input: x · Output: result

What it is

Standard trigonometric functions, computed elementwise. x is the input angle in radians — a scalar, a Vec of any length, or a Mat/Signal of any shape.

Overloads

One call shape — this function is not overloaded.

CodeInputOutputDescription
result = sin(x)
x scalar, Vec, Mat, or Signalnot documented yet
result —
Returns exactly the same type and shape as x, one trig value per element.

Examples

From the documentation, and run by the build -- the output and the figure below are what the engine actually produced. Simplest first.

# `grid` does not depend on `p`, so building it per call is waste.

grid   = outer(f, t)            # K x N, built ONCE

shape(p) := sum(A .* cos(grid + p), axis = 0)

from numerics-dsp

N = 8
n = 0 to N - 1
x = cos(2 * pi * 2 * n / N)     # a pure tone at bin 2

X = fft(x, N)
print("mag = {abs(X)}")

from numerics-dsp

K = 4
N = 64
Fs = 64
bins = [2, 5, 11, 17]
f = bins * (Fs / N)
t = 0 to (N - 1) / Fs step 1/Fs

f as vector(K, 1)      # frequency column (K,1)

t as vector(1, N)      # time row        (1,N)


phase = 2 * pi * f * t             # (K,1)*(1,N) -> (K,N), one row per tone

A = ones(K, 1) / sqrt(K)           # unit-RMS amplitude per tone

x = sum(A .* cos(phase), axis=0)   # sum the tones down the rows
