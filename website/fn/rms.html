rms

Builtin index · Core maths

result = rms(x)

Input: x · Output: result

What it is

Root-mean-square, sqrt(mean(x.^2)), of every element of x — a scalar, Vec, or Mat/Signal, flattened.

Overloads

One call shape — this function is not overloaded.

CodeInputOutputDescription
result = rms(x)
x scalar, Vec, Mat, or Signalnot documented yet
result scalar, Num, or vector
Returns a scalar Num. Errors on an empty vector.

from signal-processing

x = sin(2 * pi * 50 * t)          # 50 Hz, one value per sample

y = x + 0.2 * randn(1000, seed = 1)   # the same signal, with noise on it

print("clean rms {rms(x):.4f}, noisy rms {rms(y):.4f}")
output

from from-zero
