rk4

Builtin index · Signal processing

result = rk4(f, tspan, y0, h)

Input: f, tspan, y0, h · Output: result

What it is

Classical fixed-step Runge-Kutta of order 4 with step h > 0; the last step is shortened to land exactly on tf, and every step is reported.

Overloads

One call shape — this function is not overloaded.

Returns {t, y, steps, nfev, status} like ode45 (no rejected; no error control and no events, so rtol=/events= are errors). status is "nonfinite" if the state overflows. Use it when you need a fixed grid or a known cost; there is no check that h is small enough for stability.
