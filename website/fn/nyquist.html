nyquist

Builtin index · Signal processing

nyquist(Z, [color=], [label=], [marker="o"])

Input: Z, color, label, marker · Output: no output

What it is

Z: a length-N complex vector (CVec, the impedance spectrum). color/label/marker (optional strings): plot styling. The standard EIS plot: Re(Z) on x, -Im(Z) on y (the impedance-spectroscopy sign convention every EIS instrument uses, so capacitive/inductive behavior plots in the upper half-plane).

Overloads

One call shape — this function is not overloaded.

Examples

From the documentation, and run by the build -- the output and the figure below are what the engine actually produced. Simplest first.

freqs = logspace(0, 4, 20)
R = 100
C = 1e-6
w = 2 * pi * freqs
Z = R / (1 + 1j * w * R * C)         # a simple RC impedance, as measured data


fit = rlkk_reconstruct(Z, freqs, lambda=1e-4)     # fit.z, fit.gamma

v = rlkk_validate(Z, freqs, lambda=1e-3, threshold=2.0)
if v.valid
    print("measurement is causal/linear/stable within {v.max_residual}%")
else
    print("bad points: {where(abs(v.residuals) > 2.0)}")
end

nyquist(Z)   # Re(Z) vs -Im(Z), the standard EIS view

from signal-processing

randles = series(resistor(0.2), parallel(resistor(0.01), capacitor(100e-6)))
Z = impedance(randles, logspace(-2, 5, 200))     # frequencies in Hz

nyquist(Z)

How it works

nyquist(Z) — the standard EIS plot: Re(Z) on x, -Im(Z) on y (impedance-spectroscopy convention — capacitive/inductive behavior then plots in the upper half-plane, matching every EIS instrument's own default).
