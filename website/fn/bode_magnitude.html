bode_magnitude

Builtin index · Signal processing

bode_magnitude(Z, freqs, [color=], [label=], [marker="line"])

Input: Z, freqs, color, label, marker · Output: no output

What it is

Z: a length-N complex vector (CVec); freqs: the matching length-N real vector (Hz). color/label/marker (optional strings). Magnitude half of a Bode plot: 20*log10(|Z|) vs. log-scaled frequency.

Overloads

One call shape — this function is not overloaded.

How it works

bode_magnitude(Z, freqs) / bode_phase(Z, freqs) — the two halves of a Bode plot, kept as separate calls (rather than one builtin silently creating a 2-panel figure) so a script stays in control of its own subplot layout: panel(2, 1, 1); bode_magnitude(Z, freqs) panel(2, 1, 2); bode_phase(Z, freqs)
