imnoise

Builtin index · Images

result = imnoise(img, type, [mean=0.0], [sigma=0.05], [density=0.05], [seed=])

Input: img, type, mean, sigma, density, seed · Output: result

What it is

img is an Image; type is a required string, "gaussian" or "salt_pepper". For "gaussian": mean/sigma are optional named numbers (defaults 0.0/0.05), the additive per-channel Gaussian noise's mean/standard-deviation in normalized [0,1] intensity units. For "salt_pepper": density is an optional named number (default 0.05), the fraction of pixels (not channel samples) flipped to pure black/white. seed is an optional named integer for reproducibility (same convention as randn/uniform); omitted, a fresh random seed is used. Adds synthetic noise for testing other CV algorithms.

Overloads

One call shape — this function is not overloaded.

How it works

imnoise(img, type, [params...], [seed=]) — synthetic noise for testing other CV algorithms against. type="gaussian": mean=0.0, sigma=0.05 (normalized [0,1] intensity units), additive and independent per channel. type="salt_pepper": density=0.05, the fraction of PIXELS (not channel samples) flipped to pure black/white. seed= follows this codebase's shared stochastic-builtin convention (randn/uniform/kmeans_model/...) for reproducibility — see image::Image::add_gaussian_noise/add_salt_pepper_noise's doc comments for why the RNG itself is injected as a closure
