simple_rnn_classifier

Builtin index · Statistics & ML

result = simple_rnn_classifier(input_size, hidden_size, n_classes, [seed=])

Input: input_size, hidden_size, n_classes, seed · Output: result

What it is

Builds an untrained GRU-backed sequence classifier: input_size/hidden_size/n_classes positive integers (features per timestep, hidden width, and number of classes), plus an optional integer seed=.

Overloads

One call shape — this function is not overloaded.

How it works

simple_rnn_classifier(input_size, hidden_size, n_classes, [seed=]) — gru_init's own weights plus a softmax-ready dense readout on the LAST hidden state (gru_forward(...)'s final list entry). out_w is (hidden_size, n_classes) — the standard dense(x, w, b) orientation — applied to the transposed (row-shaped) last hidden state via tt, since gru_forward's own hidden state is column-shaped (see gru_cell_compute's doc comment): dense(tt(h_last), out_w, out_b). Reuses gru_init directly (reseeding self.rng once up front so seed= covers both the GRU weights and the readout layer, not just the former).
