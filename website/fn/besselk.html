besselk

Builtin index · Core maths

besselk(nu, x)

Input: nu, x · Output: no output

What it is

Modified Bessel function of the second kind K_nu(x) of real order nu (|nu| <= 1e6, K_{-nu} = K_nu) and x > 0, same argument shapes and methods as besselj (computed scaled by e^x, so underflow to 0 happens only where the true value is below 1e-308). Median error 2e-16, worst 1e-13 relative over 2700 random points; K_nu(0) = inf, K_nu(inf) = 0; x < 0, where K is complex, gives NaN. Errors: missing arguments, mismatched shapes, complex input.

Overloads

One call shape — this function is not overloaded.
