pca_model

Builtin index · Statistics & ML

result = pca_model(X, k)

Input: X, k · Output: result

What it is

PCA as a reusable handle: fits the top k principal components on an N-row, D-column matrix X, so .predict(Xnew) projects new rows onto the same fitted components instead of refitting.

Overloads

One call shape — this function is not overloaded.

How it works

pca_model(X, k) — wraps pca_fit's components/mean so .predict(Xnew) (project new rows onto the same k components) works on data the model wasn't fit on, unlike the flat pca/pca_components.

From the note above this builtin in the interpreter, where the reasoning was written down as it was built.
