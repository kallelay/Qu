maxpool2d

Builtin index · Statistics & ML

result = maxpool2d(x, size, [stride=])

Input: x, size, stride · Output: result

What it is

Downsamples an (H, W) matrix x by taking the largest value in each size x size window (integer size), moving stride positions at a time (integer, defaults to size — non-overlapping windows).

Overloads

One call shape — this function is not overloaded.

How it works

maxpool2d(x, pool_size, [stride]) — 2-D max pooling, "valid" only (see maxpool2d_forward_single's own doc comment for why padding is out of scope for a max). stride defaults to pool_size (non-overlapping windows, the ordinary convention every real framework defaults to as well) when omitted. Backward routes each upstream gradient element to the exact argmax position the forward pass used — gradient-checked against central finite differences before this shipped.
