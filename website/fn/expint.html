expint

Builtin index · Core maths

expint(x)

Input: x · Output: no output

What it is

The exponential integral E1(x) = ∫ₓ^∞ e^-t / t dt for x > 0, elementwise (real scalar, Vec, Mat or Signal). Series for x <= 1, continued fraction beyond; about 1e-15 relative from x = 1e-5 to x = 300 (worst 1.4e-15 against mpmath), and 0 for x large enough that e^-x underflows. expint(0) = inf; x < 0, where E1 is complex, and NaN give NaN. Complex input is an error.

Overloads

One call shape — this function is not overloaded.
