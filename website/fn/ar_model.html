ar_model

Builtin index · Statistics & ML

result = ar_model(x, order)

Input: x, order · Output: result

What it is

Fits an autoregressive AR(p) model by Yule-Walker to a length-N numeric vector x, using the integer lag order order (this is p).

Overloads

One call shape — this function is not overloaded.

Examples

From the documentation, and run by the build -- the output and the figure below are what the engine actually produced. Simplest first.

x = zeros(500)
x[0] = randn(seed = 21)
x[1] = randn(seed = 22)
for t = 2 to 499
    x[t] = 0.6 * x[t - 1] - 0.3 * x[t - 2] + 0.1 * randn()
end for
m = ar_model(x, 2)
print("generating: [0.6, -0.3]")
print("recovered:  {round(m.coef, 3)}")

future = m.predict(30)
plot(460 to 499, x[460:499], color = "#0f172a", label = "measured")
plot(500 to 529, future, color = "#e11d48", width = 2, label = "forecast")
legend()
title("AR(2), 30 steps ahead")

How it works

ar_model(x, order) — classical AR(p) autoregressive time-series model, fit via the Yule-Walker equations rather than a fresh lagged-design-matrix least-squares fit: solves the (order, order) symmetric Toeplitz system built directly from x's own autocorrelation (reusing the existing acf free function — acf's already-normalized rho[k] values are exactly what the Yule-Walker normal equations are stated in terms of, so there was real solver code here to reuse rather than reinvent, per this task's own framing). Returns a kind="ar" model — see ar_fit_model's own doc comment for the fitted fields and the equations themselves, and the "predict" builtin arm below for .predict(n_ahead) (a forecast horizon, NOT a regression Xnew — an AR model forecasts its own future from its own fitted history, it has no "new X" to evaluate against, so this is special-cased there exactly like q_learning/ kalman's own non-regression predict meanings are).
