predict

Builtin index · Statistics & ML

result = model.predict(Xnew)

Input: Xnew · Output: result

What it is

Applies a fitted model Record model to a new M-row (same D columns as it was fitted on) matrix or vector Xnew.

Overloads

Xnew can be vector or Record.

How it works

predict(model, Xnew) — callable as model.predict(Xnew) via the existing recv.method(args) sugar. Dispatches on ModelHandle.kind; see each _model constructor's own doc comment for what each kind's prediction means. For the estimation-theory family ("kalman"/"particle_filter" model kinds), predict means the filter's own time update instead of the regression-style predict(model, Xnew) below — see estimation_predict's own doc comment for the full state.predict(...) contract (linear/EKF/UKF/particle filter, all reached through this one name).
