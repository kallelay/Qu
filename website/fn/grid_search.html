grid_search

Builtin index · Statistics & ML

result = grid_search(fit, X, y, grid, [folds=5], [shuffle=true], [seed=], [metric="auto"])

Input: fit, X, y, grid, folds, shuffle, seed, metric · Output: result

What it is

Cross-validates fit(X, y, params) over every combination of grid, a record of lists such as {k = [1, 3, 5], tag = [10, 20]} (a single value counts as a one-point list; the last name varies fastest; at most 10000 combinations). params is the record of one combination. Every combination is scored on the SAME folds, and error metrics (rmse, mae, mse, brier) are minimized while the others are maximized.

One call shape — this function is not overloaded.

How it works

grid_search(fit, X, y, grid, [folds=5], [shuffle=true], [seed=], [metric=]) -- cross-validate fit(X, y, params) over every combination of a record of lists, e.g. {k = [1, 3, 5], p = [1, 2]}, all on the same folds, and report the best.
