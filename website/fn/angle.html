angle

Builtin index · Core maths

result = angle(x)

Input: x · Output: result

What it is

Complex argument — the angle from the positive real axis, in radians (atan2(im, re)) — on a Complex/CVec/CMat; on a signed real scalar or real Vec/Mat it degrades to 0 for a non-negative value or π for a negative one. x is the value(s) to measure.

Overloads

x can be number, scalar, Vec, Mat, or Complex.
