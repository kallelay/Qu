ucase

Builtin index · Collections & strings

result = ucase(s)

Input: s · Output: result

What it is

s is a Str. BASIC's names for upper/lower; toupper/tolower are C's names for the same thing.

Overloads

One call shape — this function is not overloaded.

CodeInputOutputDescription

result Str
Returns a Str.

Examples

From the documentation, and run by the build -- the output and the figure below are what the engine actually produced. Simplest first.

s = "Hello, Qu World!"
print(mid(s, 7, 2))          # "Qu"

print(left(s, 5))            # "Hello"

print(right(s, 6))           # "World!"

print(reverse("abc"))        # "cba"

print(lower("SHOUT"))        # "shout"

print(ucase("shout"))        # "SHOUT"

print(lcase("SHOUT"))        # "shout"

print(toupper("mix"))        # "MIX"

print(tolower("MIX"))        # "mix"

print(capitalize("ada lovelace"))  # "Ada lovelace"

print(ltrim("   padded"))    # "padded"

print(rtrim("padded   ") + "|")   # "padded|"

print(pad_right("ab", 5, "."))    # "ab..."

print(compare("apple", "banana")) # -1

print(asc("A"))              # 65

How it works

ucase/lcase are BASIC's names and toupper/tolower are C's. Both are what a hand reaches for before it reaches for the documentation, and an alias costs a line.
