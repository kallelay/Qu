ylabel

Builtin index · Plotting

ylabel(text, [align=])

Input: text, align · Output: no output

What it is

Labels the current panel's y-axis with text (string). align= (string, "left"/"center"/"right", plus "bottom"/"top" for the rotated text, default "center") sets alignment. While yyaxis right is active, labels the *right* axis instead of the left one.

Overloads

One call shape — this function is not overloaded.
