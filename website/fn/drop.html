drop

Builtin index · Collections & strings

result = take(xs, n)

Input: xs, n · Output: result

What it is

xs is a Vec/List; n is a number of elements.

Overloads

One call shape — this function is not overloaded.

CodeInputOutputDescription
result = take(xs, n)
xs Vec or Listxs is a Vec/List.
n numbern is a number of elements.
result —
Returns the same type as xs: the first n elements (take) or everything after them (drop). n beyond the length is clamped, not an error.

How it works

data.drop("col") / data.drop(("col1", "col2")) — a new Table with the named column(s) removed (see Table::drop's own doc comment). Accepts either shape for the "which columns" argument: select's own convention of N trailing positional args (select(df, "a", "b")), or a single list value for "drop several at once" — column_names_arg below expands that one case, everything else stays identical to select's display_value-per-arg collection. The list form is a parenthesized tuple (("a", "b"), Qu's existing Value::List literal), NOT a bracketed [...] — [...] is always a numeric Vec/Mat literal here (eval_matrix_literal calls .as_num() on every cell), so ["a", "b"] with string cells already errors before reaching this builtin at all; there is no bracketed string-list literal to accept.

From the note above this builtin in the interpreter, where the reasoning was written down as it was built.
