join

Builtin index · Concurrency

result = join(w) or join(list[, delimiter])

Input: w · Output: result

What it is

Two unrelated forms selected by the argument's type. On a Worker handle w (from spawn): blocks the calling thread until that worker finishes, then returns its function's return value (whatever type that function produces), or re-raises whatever error the worker's body raised as an ordinary runtime error here on the caller. Consumes the handle — joining the same worker twice is an error. On a List of strings list (with an optional string delimiter, default ""): the unrelated collection form, concatenating every element into one string with delimiter inserted between each pair — the inverse of split.

Overloads

w can be Worker, List, or string.

How it works

join(w) blocks until worker w finishes and returns its result — or re-raises whatever error the worker's function body raised, exactly as if it had been called directly (never silently swallowed). Consumes the handle: joining the same worker twice is a clear error, not a second wait. join(list[, delimiter]) — collection form (§ collections, 2026-08-24): the natural inverse of split, concatenating a List of strings with delimiter between each ("" if omitted). Dispatches on arg0's type, same "one name, arg-type decides" pattern remove above also uses.
