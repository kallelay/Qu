insert

Builtin index · Collections & strings

result = insert(s, i, text)

Input: s, i, text · Output: result

What it is

s and text are Strs; i (number, 0-based character position) is where text is spliced in.

Overloads

One call shape — this function is not overloaded.

How it works

insert(collection, index, value) — returns a NEW list/vector with value inserted before position index (so index == length appends at the end); same immutable- return convention as remove/append. Dispatches on arg0's type: a Vec insert must itself be numeric (it stays a plain numeric vector, never silently promoted to a heterogeneous List), a List insert accepts anything.
