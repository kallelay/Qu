regex_find_all

Builtin index · Collections & strings

result = regex_find_all(s, pattern)

Input: s, pattern · Output: result

What it is

s and pattern are Strs.

Overloads

One call shape — this function is not overloaded.

CodeInputOutputDescription
result = regex_find_all(s, pattern)
s Strnot documented yet
pattern Strnot documented yet
result List or Str
Returns a List of Str — every match, in order.

Examples

From the documentation, and run by the build -- the output and the figure below are what the engine actually produced. Simplest first.

print(regex_find_all("a1b22c333", "[0-9]+"))                                          # ("1", "22", "333")

print(regex_replace("2026-09-07", "([0-9]+)-([0-9]+)-([0-9]+)", "$3/$2/$1"))          # "07/09/2026"

print(regex_groups("v1.2.3", "v([0-9]+)\.([0-9]+)"))                                  # ("1", "2")

print(like("hello.txt", "*.txt"))                                                      # true
