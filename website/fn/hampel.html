hampel

Builtin index · Noise

result = hampel(x, [window=7], [n_sigma=3])

Input: x, window, n_sigma · Output: result

What it is

Outlier removal: replaces a sample by the local median only when it is more than n_sigma robust deviations (1.4826 × MAD) from it. x is a length-N number vector; window is an optional positional odd integer, default 7; n_sigma is an optional positional number, default 3.

Overloads

One call shape — this function is not overloaded.

Examples

From the documentation, and run by the build -- the output and the figure below are what the engine actually produced. Simplest first.

spiky = sin(2 * pi * (0 to 499) / 100)
spiky[120] = 6.0

r = hampel(spiky, 7, 3)

How it works

hampel(x, window, n_sigma) — replace a sample by the local median only when it lies more than n_sigma robust deviations from it. An outlier remover rather than a smoother: everything the test does not flag is left exactly as it was, which is the difference from medfilt. Returns the cleaned signal and how many samples it touched, because "it removed 3 outliers" and "it rewrote 400 samples" are very different results and should not look the same.
