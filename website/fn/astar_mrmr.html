astar_mrmr

Builtin index · Statistics & ML

result = astar_mrmr(X, y, n_features, ...)

Input: X, y, n_features, ... · Output: result

What it is

A guided (A*) search on an N-row, D-column X and length-N y for a feature subset of size n_features (integer) that is relevant to the target and not redundant with itself (minimum-redundancy-maximum-relevance).

Overloads

One call shape — this function is not overloaded.

How it works

astar_mrmr(X, y, n_features, [beam_width=15], [redundancy_weight=1.0], [cv_folds=3], [max_depth=3], [seed=], [kind="classification"]) — the literal A*-mRMR feature selector; see astar_mrmr_search's own doc comment for the full algorithm (ported from Ahmed's own novel_methods.py::AStarMRMRHybrid). Returns the selected 0-based column indices as a Value::Vec, sklearn's get_support(indices=True) convention — slice X yourself with them (X[:, idx]-style) rather than getting a pre-sliced matrix back, so this composes with whatever you do next instead of assuming it.

From the note above this builtin in the interpreter, where the reasoning was written down as it was built.
