zeta

Builtin index · Core maths

zeta(s)

Input: s · Output: no output

What it is

The Riemann zeta function for real s, elementwise (number, Vec or Mat): zeta(2) = pi²/6, zeta(4) = pi⁴/90, zeta(0) = -1/2, zeta(-1) = -1/12, the trivial zeros zeta(-2k) = 0, and zeta(inf) = 1. Euler-Maclaurin summation for s >= 0, the functional equation for s < 0; worst relative error 5e-15 against mpmath over s from -100.3 to 30.5, but for very negative s the factor Γ(1 - s) overflows (zeta(-170) and beyond is ±inf). Errors: s = 1 anywhere in the input (the pole, an error like gamma's poles), complex input. NaN gives NaN.

Overloads

One call shape — this function is not overloaded.
