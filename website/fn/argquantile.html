argquantile

Builtin index · Core maths

result = argquantile(x, q)

Input: x, q · Output: result

What it is

Index into x (a Vec or flattened Mat/Signal) nearest the q-quantile rank, computed as round(q*(n-1)) where n = len(x); q is a scalar in [0, 1]. Unlike quantile, which may interpolate between two elements, this always lands on a real element of x.

Overloads

One call shape — this function is not overloaded.

How it works

argquantile(x, q) — the index (into x) of the element at the nearest-rank quantile position (round(q*(n-1))) — unlike quantile itself, this must land on an actual element, so it can't interpolate between two.
