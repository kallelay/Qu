codec.decode_flac

Builtin index · File I/O

result = codec.decode_flac(src, [channel=])

Input: src, channel · Output: result

What it is

Decodes a FLAC file to samples. src (string path, or Vec of bytes) is the stream. channel (number, optional, named only) picks one channel out of a multi-channel file, numbered from 0.

Overloads

What comes back depends on how many series the call produces, because there is no one type that fits both without lying about one of them.

src can be string or Vec.

2 forms. Each carries its own inputs, outputs and worked example — pick the tab for the one you are calling.

Returns a Record with fields: fs (Num, the sample rate in Hz), bits (Num, bits per sample), frames (Num, samples per channel), channels (List of Signal, one per channel, each already carrying the rate — so a.channels[0] goes straight into anything that takes a signal, with no reassembly needed). A Signal is one series and a Mat has nowhere to put the sample rate, which is why this form cannot hand back either of them.

How it works

One body for all three. They differ only in which decoder runs, because qu_codec gives them a common Audio -- so the shape a script gets back cannot drift between formats, which is the thing that would actually hurt.
