kmedoids_model

Builtin index · Statistics & ML

result = kmedoids_model(X, k, [seed=])

Input: X, k, seed · Output: result

What it is

PAM clustering on the same X/k/seed= shape as kmeans_model — every one of the k centres is an actual row of X, never an average.

Overloads

One call shape — this function is not overloaded.

How it works

kmedoids_model(X, k, [seed=]) — PAM (Partitioning Around Medoids). The property that actually distinguishes this from kmeans_model/kmedians_model above: every cluster center (medoid) is an ACTUAL row of X, never a computed average or median — see kmedoids_fit's own doc comment for the swap procedure. centers holds those real rows (so .predict works exactly like kmeans_model's nearest-centroid assignment, unchanged, since the "real point" property only matters at fit time); medoid_indices additionally exposes which row of the original X each medoid came from, for scripts (and this pass's own tests) that want to check that property directly rather than re-deriving it.

From the note above this builtin in the interpreter, where the reasoning was written down as it was built.
