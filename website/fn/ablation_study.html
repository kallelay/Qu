ablation_study

Builtin index · Statistics & ML

result = ablation_study(X, y, [cv_folds=3])

Input: X, y, cv_folds · Output: result

What it is

Computes one importance score per feature column of an N-row, D-column X and length-N y, using cv_folds folds (integer, default 3): the full model's cross-validated score minus the score of the same model refit without that column.

How it works

ablation_study(X, y, [cv_folds=3], [max_depth=3], [seed=], [kind="classification"]) — see ablation_study_scores's own doc comment. Returns one importance score per feature column (full-model CV score minus that feature's own ablated score) — a report, not a selection (unlike rfe, which removes features and keeps going).
