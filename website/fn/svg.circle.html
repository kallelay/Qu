svg.circle

Builtin index · Images

result = svg.circle(cx, cy, r, [fill="#000000"], [stroke="none"], [stroke_width=1], [opacity=1])

Input: cx, cy, r, fill, stroke, stroke_width, opacity · Output: result

What it is

A circle of radius r centred on (cx, cy); r must be 0 or more. Styling as for svg.rect.

Overloads

One call shape — this function is not overloaded.

How it works

Same shape again for svg, minus the cfg -- this module is always compiled in (see native_module). These names are reachable ONLY qualified as svg.rect(...) etc.: three of the five (rect, text, and circle via plotting) already exist as unrelated top-level drawing builtins, so import svg + a bare rect(...) is deliberately the "ambiguous, qualify it" error open_module_name raises -- exactly as image already collides on regions/blur.
