svg.circle

Builtin index · Images

result = svg.circle(cx, cy, r, [fill="#000000"], [stroke="none"], [stroke_width=1], [opacity=1])

Input: cx, cy, r, fill, stroke, stroke_width, opacity · Output: result

What it is

A circle of radius r centred on (cx, cy); r must be 0 or more. Styling as for svg.rect.

Overloads

One call shape — this function is not overloaded.

Examples

From the documentation, and run by the build -- the output and the figure below are what the engine actually produced. Simplest first.

import svg

shapes = [
  svg.rect(10, 10, 100, 50, fill = "#e74c3c"),
  svg.circle(200, 60, 40, fill = "#3498db", stroke = "#000000", stroke_width = 2),
  svg.line(0, 0, 300, 120, stroke = "#333333", stroke_width = 1.5),
  svg.path("M 10 100 L 60 40 L 110 100 Z", stroke = "#2ecc71", stroke_width = 2),
  svg.text(20, 150, "R&D output", font_size = 16, fill = "#111111")
]

save_svg("drawing.svg", shapes, width = 320, height = 180)

doc = load_svg("drawing.svg")
print(doc.width)             # 320

print(len(doc.shapes))       # 5

print(doc.shapes[1].kind)    # circle

print(doc.shapes[1].r)       # 40
