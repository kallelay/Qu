write_csv

Builtin index · File I/O

write_csv(df, path)

Input: df, path · Output: no output

What it is

Writes a Table to a CSV file. df (Table) is the data to write. path (string) is the destination file.

Overloads

One call shape — this function is not overloaded.

CodeInputOutputDescription
write_csv(df, path)
df Tabledf (Table) is the data to write.
path stringpath (string) is the destination file.
no outputWrites a Table to a CSV file.
