diff_lines

Builtin index · Collections & strings

result = diff_lines(a, b, [changed_only=false])

Input: a, b, changed_only · Output: result

What it is

A line diff of two texts. a and b are each a List of strings, or one string that is split into lines (CRLF or LF).

Overloads

One call shape — this function is not overloaded.

Returns a List of Records, one per line of the merged result, in order: op ("equal", "insert" or "delete"), old (the 1-based line number in a, or none for an insert), new (the 1-based line number in b, or none for a delete) and text. changed_only=true leaves out the "equal" lines. A longest-common-subsequence diff after trimming the shared head and tail, so a few edits in a long file are cheap; a huge, wholly different pair is refused with a clear error rather than exhausting memory. pdf.text_diff is the page-by-page version for PDFs, and diff is the numeric one.
