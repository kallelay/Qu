zoom_inset

Builtin index · Plotting

zoom_inset(x0, x1, y0, y1, [position=], [outside=], [clip=])

Input: x0, x1, y0, y1, position, outside, clip · Output: no output

What it is

Magnifies the data region x in [x0, x1], y in [y0, y1] (numbers, data units) into an auto-placed inset panel, with a dashed zoom-box drawn over the source region and connector lines back to it. position= (string, reuses the legend's keyword vocabulary: "top right", "best", ...) chooses where the inset sits; outside=true (bool, default false) reserves margin and places the inset entirely outside the plot area instead of overlapping it; clip= (bool) controls whether the inset's own contents are clipped to its box.

Overloads

One call shape — this function is not overloaded.

Examples

From the documentation, and run by the build -- the output and the figure below are what the engine actually produced. Simplest first.

xs = linspace(0, 5, 400)
ys = sin(2 * pi * 1.2 * xs) .* exp(-0.3 * xs)
y_at_3 = sin(2 * pi * 1.2 * 3) * exp(-0.3 * 3)
plot(xs, ys)
vline(3, color="red")
annotate(3, y_at_3, "transient")
zoom_inset(2.8, 3.2, -0.1, 0.1, position="top right", outside=true)
print(y_at_3)

How it works

zoom_inset(x0, x1, y0, y1) — magnifies that data region into an auto-placed inset panel with a dashed zoom-box + connector lines back to it (see plotting::Panel.inset's doc comment for what does/doesn't replay into the inset). position reuses the legend's own keyword vocabulary ("top right", "best", ...); outside=true reserves margin and places the inset entirely outside the plot, guaranteeing no overlap — the honest escape hatch when best's zero-overlap interior search can't find a clear spot (see InsetZoom's own doc comment for why that isn't auto-detected).
