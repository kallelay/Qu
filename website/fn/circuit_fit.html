circuit_fit

Builtin index · Signal processing

result = circuit_fit(freqs, z, model, [initial_guess=], [bounds=], [lower=], [upper=], [sigma=], [weight=], [n_starts=], [seed=], [max_iter=], [tol=])

Input: freqs, z, model, initial_guess, bounds, lower, upper, sigma, weight, n_starts, seed, max_iter, tol · Output: result

What it is

Nonlinear least-squares fit of a circuit's parameters to measured impedance. freqs is in Hz and comes FIRST; z is the measured complex impedance; model is a spec string like "R-p(R,C)" or a circuit value (whose own numbers are then the starting point).

Overloads

One call shape — this function is not overloaded.
