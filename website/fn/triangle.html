triangle

Builtin index · Plotting

result = triangle(freq, fs, n) / sawtooth(freq, fs, n)

Input: freq, fs, n · Output: result

What it is

Each generates one period-repeating waveform: freq (number, Hz), fs (number, sample rate in Hz), n (integer, sample count) are all scalars, in that order. sawtooth ramps linearly from -1 up to (but not including) +1 each period then drops back to -1; triangle rises and falls symmetrically. Both are band-unlimited — they carry every harmonic, which is the point when testing a filter.

Overloads

One call shape — this function is not overloaded.

How it works

triangle(freq, fs, n) — a periodic, continuous triangle wave: linearly rising from -1 to +1 over the first half of each period, then linearly falling from +1 back to -1 over the second half. Unlike sawtooth, there's no discontinuous jump anywhere in the waveform.
