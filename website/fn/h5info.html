h5info

Builtin index · File I/O

result = h5info(path)

Input: path · Output: result

What it is

Lists what is inside an HDF5 file.

Overloads

One call shape — this function is not overloaded.

CodeInputOutputDescription
result = h5info(path)
path Listnot documented yet
kind —"group", "dataset", "datatype", "softlink", "externallink"
dtype stringe.g. "float64", "int32", "string[8]"
shape vector or scalara vector; empty for a scalar
Returns a list of records, one per group, dataset or link, depth-first, each with path, kind ("group", "dataset", "datatype", "softlink", "externallink"), dtype (e.g. "float64", "int32", "string[8]") and shape (a vector; empty for a scalar). *Added in v0.4.7*
