sns_scatter

Builtin index · Plotting

sns_scatter(df, xcol, ycol, [huecol])

Input: df, xcol, ycol, huecol · Output: no output

What it is

Seaborn-style scatter pulling columns from Table df: xcol, ycol (strings, column names) give the coordinates; optional huecol (string, column name) draws one series per distinct hue value (first-seen order) and turns the legend on.

Overloads

One call shape — this function is not overloaded.

df = table(x = randn(30, seed = 1), y = randn(30, seed = 2),
           grp = ["a","b","a","b","a","b","a","b","a","b",

                  "a","b","a","b","a","b","a","b","a","b"])

figure()
sns_box(df, "grp", "y")
figure()
sns_bar(df, "grp", "y")
print("rows: " + str(rows(df)))

How it works

a table and drive the existing scatter/boxplot/bar machinery, auto-grouping by a categorical column where relevant. sns_scatter(df, xcol, ycol, [huecol]) — one scatter series per distinct huecol value (first-seen order) if given, else a single series.
