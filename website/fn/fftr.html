fftr

Builtin index · Signal processing

result = fftr(X, n)

Input: X, n · Output: result

What it is

Deprecated — use irfft. The same function under a name that reads as rfft's forward partner; it is actually rfft's inverse, so the pair reads backwards. Still works, and warns once per run.

Overloads

One call shape — this function is not overloaded.

CodeInputOutputDescription
result = fftr(X, n)

Returns a length-n real Vec — the inverse transform of the half-spectrum X, exactly what irfft(X, n) returns.

Examples

No documentation example calls this form yet. The Signal processing chapter is where one belongs.

How it works

irfft(half_spectrum, n) -- n (the real output length) is required since it can't be recovered from the half-spectrum's length alone (both even and odd n can share a half-length). fftr is an alias ("the real-valued inverse fft").

From the note above this builtin in the interpreter, where the reasoning was written down as it was built.
