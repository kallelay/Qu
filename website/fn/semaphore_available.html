semaphore_available

Builtin index · Concurrency

result = semaphore_available(s)

Input: s · Output: result

What it is

Non-blocking snapshot of how many permits are free right now on semaphore handle s.

Overloads

One call shape — this function is not overloaded.

CodeInputOutputDescription
result = semaphore_available(s)
s —not documented yet
result —
Returns an integer — a diagnostic, not a guarantee, since it can change the instant after it's read.

Examples

From the documentation, and run by the build -- the output and the figure below are what the engine actually produced. Simplest first.

s = semaphore(2)                       # 2 permits available

print(semaphore_available(s))          # 2

semaphore_acquire(s)                   # take one

print(semaphore_available(s))          # 1

semaphore_release(s)                   # give it back

print(semaphore_available(s))          # 2

How it works

semaphore_available(s) — non-blocking: how many permits are free right now (a diagnostic snapshot, not a guarantee — it can change the instant after you read it).
