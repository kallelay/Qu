touch

Builtin index · File I/O

touch(path)

Input: path · Output: no output

What it is

Unix touch semantics. path (string) is the filesystem path: creates an empty file if it doesn't exist; if it already exists, updates its modification time WITHOUT altering its content.

Overloads

One call shape — this function is not overloaded.
