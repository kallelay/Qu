metadata

Builtin index · Signal processing

result = metadata(s)

Input: s · Output: result

What it is

Added in v0.2.4.

Overloads

One call shape — this function is not overloaded.

CodeInputOutputDescription
result = metadata(s)
s Recordnot documented yet
result Record
Returns a Record of the signal's metadata. sampling_rate, start_time and unit are read through from the value itself rather than from stored copies, alongside duration, n, calibrated and the calibration's source/slope/offset/reference when present, marker and region counts, and whichever free-form fields were set.

Examples

No documentation example calls this form yet. The Signal processing chapter is where one belongs.

How it works

metadata(s) -- the §10 named field set, as a Record. sampling_rate, start_time and unit are READ THROUGH from the signal itself rather than from stored copies, and set_metadata refuses to write them (see DERIVED_FIELDS). A stored unit field saying "Pa" beside samples in volts is not metadata, it is a second answer competing with the real one, and whichever the reader happens to look at is the one they believe.
