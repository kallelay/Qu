sizeof

Builtin index · Collections & strings

result = sizeof(x)

Input: x · Output: result

What it is

Deprecated — use shape. The same function under a name that means a byte count in every language it could have come from. Still works, and warns once per run.

Overloads

One call shape — this function is not overloaded.

CodeInputOutputDescription
result = sizeof(x)

result Vec
Returns a 2-element Vec, [rows, cols] — the same value shape gives.
