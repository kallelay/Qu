pdf.render

Builtin index · File I/O

pdf.render(src, [page=1], [dpi=150])

Input: src, page, dpi · Output: no output

What it is

Renders one page (numbered from 1) to an Image -- text, vector graphics, images and annotations, composited onto white -- at dpi dots per inch (a page is width_in_points * dpi / 72 pixels wide). src is a path or a Vec of bytes. Rasterising PDF needs a real PDF engine, so this uses Google's PDFium (the one inside Chrome), loaded when first called rather than compiled in: download pdfium.dll / libpdfium.so / libpdfium.dylib for your platform from github.com/bblanchon/pdfium-binaries and put it next to the qu program, or set QU_PDFIUM to its path (a file or its folder); the system library path is searched last. Without it the call is an error saying exactly that. Pair with save_image(path, img) to write a PNG.

Overloads

One call shape — this function is not overloaded.
