transformer_block

Builtin index · Statistics & ML

result = transformer_block(x, weights)

Input: x, weights · Output: result

What it is

One transformer block on an (N, D) input x: multi-head self-attention plus a two-layer feed-forward network, each wrapped in a residual connection and a layer_norm. weights is a Record with fields heads (the tuple multi_head_attention expects), ln1_gamma/ln1_beta and ln2_gamma/ln2_beta (length-D layer-norm parameters for the two sublayers), and w1/b1/w2/b2 (the feed-forward layer's weights and biases).

Overloads

One call shape — this function is not overloaded.

print("layer_norm (scale-invariant per row): {normed}")

How it works

transformer_block(x, weights) — one post-norm Transformer encoder block (Vaswani et al. 2017, §3.1): multi-head self- attention, a residual add + layer_norm, a two-layer ReLU feedforward (reusing the EXISTING dense/relu builtins — no new layer primitive needed here either), then a second residual add + layer_norm: text a = multi_head_attention(x, weights.heads, len(weights.heads)) h1 = layer_norm(x + a, weights.ln1_gamma, weights.ln1_beta) f = dense(relu(dense(h1, weights.w1, weights.b1)), weights.w2, weights.b2) h2 = layer_norm(h1 + f, weights.ln2_gamma, weights.ln2_beta) weights is a Value::Record with fields heads (the multi_head_attention weights list — n_heads is read straight off its length, never a separate argument), ln1_gamma/ln1_beta/ln2_gamma/ln2_beta, and w1/b1/ w2/b2 (the feedforward's two dense layers). Not its own tape op: every step below calls an already-tracked builtin, so backprop through the whole block falls out of the tape's ordinary reverse walk with no bespoke tensor_vjp rule — the same "compose, don't reimplement" argument dense/ gru_cell_compute already make.
