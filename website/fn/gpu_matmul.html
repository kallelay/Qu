gpu_matmul

Builtin index · Core maths

result = gpu_matmul(A, B)

Input: A, B · Output: result

What it is

WebGPU-accelerated matmul via qu-gpu, same A/B shape requirements and r×c Mat return as matmul; only present in builds compiled with --features gpu. f32 precision (~7 significant digits), not f64 — a real, documented tradeoff, not a bug.

Overloads

One call shape — this function is not overloaded.
