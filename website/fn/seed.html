seed

Builtin index · Statistics & ML

seed(n)

Input: n · Output: no output

What it is

Reseeds the shared random stream with integer n, so subsequent calls to rand/randn/etc. without their own seed= become reproducible from this point on.

Overloads

One call shape — this function is not overloaded.
