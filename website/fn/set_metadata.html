set_metadata

Builtin index · Signal processing

set_metadata(s, key, value)

Input: s, key, value · Output: no output

What it is

Added in v0.2.4. Writes one field of the named schema: channel, comment, experiment, gain, instrument, offset, operator, sample, sampling_rate, sensor, start_time, temperature, unit. Keys match ignoring case and underscores, so the spec's samplingRate/startTime resolve too. An off-schema key is an error listing the schema — a typo that silently became its own field would be one nobody ever reads back. sampling_rate, start_time and unit are derived from the signal and are refused with a pointer at their real setter, so a stored copy can never contradict the value. Values must be a number, string or boolean.
