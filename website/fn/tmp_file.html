tmp_file

Builtin index · File I/O

result = tmp_file()

Input: no input · Output: result

What it is

Takes no arguments. Creates a new empty file under the OS temp directory with a name nothing else will collide with (process id, nanosecond clock, and a counter — any one alone has a plausible collision window).

Overloads

One call shape — this function is not overloaded.

CodeInputOutputDescription
result = tmp_file()no input
result Str
Returns a Str: its path, not an open handle, so it composes with fopen like any other path.
