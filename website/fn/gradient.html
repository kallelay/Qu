gradient

Builtin index · Core maths

result = gradient(v, [h])

Input: v, h · Output: result

What it is

Numerical derivative of the samples in the Vec v (at least two): central differences in the interior, (v[i+1]-v[i-1])/(x[i+1]-x[i-1]), which is exact for a quadratic on a uniform grid, and one-sided differences at the two ends. h is a uniform spacing (number, default 1; a Signal's sample rate is not used) or a coordinate Vec of the same length as v with distinct consecutive values.

Overloads

One call shape — this function is not overloaded.
