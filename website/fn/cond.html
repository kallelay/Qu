cond

Builtin index · Core maths

result = cond(A)

Input: A · Output: result

What it is

The 2-norm condition number of A (an r×c Mat or CMat) — the ratio of its largest to smallest singular value.

Overloads

One call shape — this function is not overloaded.

CodeInputOutputDescription
result = cond(A)
A number, Mat, or CMatnot documented yet
result scalar, Num, or matrix
Returns a scalar Num, +inf for a singular matrix rather than an error (conditioning is routinely measured on matrices that turn out to be singular, and infinity *is* the answer there). Roughly how many digits a solve can lose, so 1e12 on a double means about four digits survive.

from core-math

A = [4, 1, 1, 3] as matrix(2, 2)
print("cond(A) = {round(cond(A), 3)}")

angles = linspace(0, 2 * pi, 200)
unit_x = cos(angles)
unit_y = sin(angles)
out_x = zeros(200)
out_y = zeros(200)
for i in 0 to 199
    v = A * [unit_x[i], unit_y[i]]
    out_x[i] = v[0]
    out_y[i] = v[1]
end for

plot(unit_x, unit_y, color = "#94a3b8", label = "unit circle")
plot(out_x, out_y, color = "#4169e1", width = 2, label = "A applied to it")
legend()
title("what a 2x2 matrix does to a circle")

How it works

cond(A) — the 2-norm condition number, the ratio of the largest singular value to the smallest. Infinite for a singular matrix rather than an error: conditioning is routinely *measured* on matrices that turn out to be singular, and that is the answer, not a failure.
