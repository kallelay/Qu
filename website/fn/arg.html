arg

Builtin index · Core maths

result = angle(x)

Input: x · Output: result

What it is

Complex argument — the angle from the positive real axis, in radians (atan2(im, re)) — on a Complex/CVec/CMat; on a signed real scalar or real Vec/Mat it degrades to 0 for a non-negative value or π for a negative one. x is the value(s) to measure.

Overloads

One call shape — this function is not overloaded.

CodeInputOutputDescription
result = angle(x)
x Complex, CVec, Vec, CMat, Mat, or scalarnot documented yet
result CVec, Vec, Complex, scalar, or Num
Returns the same shape as x but always real-valued — a length-N CVec in gives a length-N real Vec out, and a Complex scalar gives a Num.
