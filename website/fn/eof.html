eof

Builtin index · File I/O

result = eof(f)

Input: f · Output: result

What it is

Checks whether f (file handle, opened readable) has any bytes left to read from the current position.

Overloads

One call shape — this function is not overloaded.

CodeInputOutputDescription
result = eof(f)
f booleannot documented yet
result boolean
Returns a boolean: true iff none remain.

function drain(s)
    total = ""
    while not eof(s)
        total = total + read_line(s) + "|"
    end while
    close(s)
    return total
end function

How it works

§ file/directory I/O extensions + type casts (2026-08-26, keep this already-large match's diff footprint small while another pass concurrently edits this same file. See fs_ops::call's own doc comment for what each name does. eof(f) on a Value::UrlStream (from StreamURL) — see net_ops::stream_eof's own doc comment. Pulled out of the combined fs_ops arm just below (which only knows about Value::File) so eof dispatches across both stream kinds, the same "same method name, same behavior" polymorphism read_line/read_all/close above already give.
