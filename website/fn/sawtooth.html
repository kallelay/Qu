sawtooth

Builtin index · Plotting

result = triangle(freq, fs, n) / sawtooth(freq, fs, n)

Input: freq, fs, n · Output: result

What it is

Each generates one period-repeating waveform: freq (number, Hz), fs (number, sample rate in Hz), n (integer, sample count) are all scalars, in that order. sawtooth ramps linearly from -1 up to (but not including) +1 each period then drops back to -1; triangle rises and falls symmetrically. Both are band-unlimited — they carry every harmonic, which is the point when testing a filter.

Overloads

One call shape — this function is not overloaded.

How it works

sawtooth(freq, fs, n) — a periodic linear ramp from -1 up to (but not including) +1 over each period, then an instant drop back to -1, matching the standard/MATLAB sawtooth convention (sawtooth's default width=1 variant specifically — MATLAB also supports a triangular variant via width, which this codebase already exposes separately as its own triangle builtin rather than as a sawtooth(..., width=) kwarg).
