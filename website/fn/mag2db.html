mag2db

Builtin index · Signal processing

result = mag2db(x)

Input: x · Output: result

What it is

x: a number or vector (amplitude/voltage ratio).

Overloads

One call shape — this function is not overloaded.

CodeInputOutputDescription
result = mag2db(x)
x number or vectornot documented yet
result —
Returns the same shape: 20*log10(x). AMPLITUDE/field-quantity convention.

How it works

dB conversions — MATLAB's own naming (mag2db/db2mag for amplitude/voltage ratios, pow2db/db2pow for power ratios), chosen deliberately over a single ambiguous db(x) — whether a ratio is a power or an amplitude changes the factor of 10 vs. 20, and a bare db() would hide which one it picked.

From the note above this builtin in the interpreter, where the reasoning was written down as it was built.
