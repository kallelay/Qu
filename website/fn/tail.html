tail

Builtin index · Collections & strings

result = head(s, n)

Input: s, n · Output: result

What it is

s is a Str, List, Vec, or Table; n (number, default 5 when used on a table).

Overloads

One call shape — this function is not overloaded.

CodeInputOutputDescription

Returns the first (head) or last (tail) n elements/rows, same type as s.
