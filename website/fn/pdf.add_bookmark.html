pdf.add_bookmark

Builtin index · File I/O

result = pdf.add_bookmark(src, title, page_index, parent=)

Input: src, title, page_index, parent · Output: result

What it is

Adds a new outline entry titled title, pointing at page_index (one-based). parent= (optional Num) nests it under an existing entry, named by the index column of a prior pdf.outlines(src) call on THIS document — the one stable handle to an existing entry this module exposes. Omitted, the new entry is top-level.

Overloads

One call shape — this function is not overloaded.
