spectrum_at

Builtin index · Signal processing

result = spectrum_at(X, freq)

Input: X, freq · Output: result

What it is

X: a spectrum; freq: a number (Hz).

Overloads

One call shape — this function is not overloaded.

CodeInputOutputDescription
result = spectrum_at(X, freq)
X —X: a spectrum.
freq numberfreq: a number (Hz).
result —
Returns the single complex bin nearest that physical frequency (round(freq/df), clamped to the available bins) — addressing the spectrum in Hz instead of by index.
