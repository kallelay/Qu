md2html

Builtin index · Collections & strings

result = md2html(s)

Input: s · Output: result

What it is

s is a Str of Markdown source. Converts headings, paragraphs, lists, fenced code with its language, blockquotes, pipe tables, rules, and inline code/bold/italic/links/images.

Overloads

One call shape — this function is not overloaded.

CodeInputOutputDescription
result = md2html(s)
s Strnot documented yet
result Str
Returns a Str of HTML.

Examples

From the documentation, and run by the build -- the output and the figure below are what the engine actually produced. Simplest first.

md = "# Title\n\nSome **bold** text."
html = md2html(md)
print(html)
print(html2md(html))

<p>Some <strong>bold</strong> text.</p>
