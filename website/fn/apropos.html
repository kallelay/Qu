apropos

Builtin index · REPL & diagnostics

result = apropos("filter")

Input: "filter" · Output: result

What it is

Takes one argument, a search substring (a string, e.g. "filter"). Returns a List of strings: every builtin name containing that substring, in engine-registration order.

Overloads

One call shape — this function is not overloaded.
