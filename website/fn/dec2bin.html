dec2bin

Builtin index · Collections & strings

result = dec2bin(n)

Input: n · Output: result

What it is

n is a number holding an integer value.

Overloads

One call shape — this function is not overloaded.

CodeInputOutputDescription
result = dec2bin(n)
n numbernot documented yet
result Str
Returns a Str of 0/1 digits, no prefix.

Examples

From the documentation, and run by the build -- the output and the figure below are what the engine actually produced. Simplest first.

flags = bitand(12, 10)          # 8   -- bits common to both

print(flags)
print(bitor(12, 10))            # 14

print(bitxor(12, 10))           # 6

print(bitcmp(0))                # -1

print(bitshift(1, 4))           # 16  -- left shift

print(bitshift(16, -2))         # 4   -- right shift

print(xor(true, false))         # true

print(nand(true, true))         # false

print(nor(false, false))        # true

print(hex2dec("FF"))            # 255

print(dec2hex(255))             # "FF"

print(bin2dec("1010"))          # 10

print(dec2bin(10))              # "1010"
