idwt

Builtin index · Signal processing

result = idwt(m)

Input: m · Output: result

What it is

m is a (2, N) matrix of [approx; detail] rows (each row length N).

Overloads

One call shape — this function is not overloaded.

CodeInputOutputDescription
result = idwt(m)
m matrixnot documented yet
result vector
Returns a length-2N real vector, reconstructing the original signal. Inverse of dwt.

Examples

From the documentation, and run by the build -- the output and the figure below are what the engine actually produced. Simplest first.

  D = dwt(x)
  approx = D[0, :]
  detail = D[1, :]
  xr = idwt(D)                 # reconstructs x exactly
