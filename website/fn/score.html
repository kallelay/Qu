score

Builtin index · Statistics & ML

result = model.score(X, [y])

Input: X, y · Output: result

What it is

Scores a fitted model Record model against an N-row feature matrix X and, for a supervised kind, the matching length-N target vector y.

Overloads

X can be Record, matrix, or vector.

How it works

score(model, X, [y]) — callable as model.score(X) / model.score(X, y). A supervised model (ols/ridge) needs y and returns R²; kmeans takes just X and returns negative inertia; pca ignores both and returns its fitted explained-variance-ratio sum (not sklearn's probabilistic log-likelihood score — a deliberately simpler metric).
