skewness

Builtin index · Statistics & ML

result = skewness(x)

Input: x · Output: result

What it is

Third standardized moment, population form, of a length-N numeric vector x.

Overloads

One call shape — this function is not overloaded.

CodeInputOutputDescription
result = skewness(x)
x vectornot documented yet
result number
Returns a single number: zero if symmetric, positive for a long upper tail.

Examples

From the documentation, and run by the build -- the output and the figure below are what the engine actually produced. Simplest first.

scores = [3, 5, 5, 5, 6, 7, 7, 9, 20]
print("mode: {mode(scores)}")
print("skewness: {round(skewness(scores), 3)}")
print("kurtosis: {round(kurtosis(scores), 3)}")
output
mode: 5
skewness: 1.957

from statistics-ml

How it works

skewness(x) — Fisher-Pearson third standardized moment (population/"biased" form, matching SciPy's default bias=True): 0 for a symmetric distribution, positive for a right (long upper) tail.
