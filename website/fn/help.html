help

Builtin index · REPL & diagnostics

help("curve_fit")

Input: "curve_fit" · Output: no output

What it is

Takes one argument, a builtin name (a string, e.g. "curve_fit"). Prints what is known about that name directly to the console and returns none — that it exists, near matches when it does not (e.g. help("not_a_real_fn") suggests close spellings), and where the worked examples live. Honest about its limits — the engine carries no per-builtin prose.

Overloads

One call shape — this function is not overloaded.

How it works

help("curve_fit") -- prints what is known about a name. Honest about its limits: there is no per-builtin documentation in the engine, so this confirms a name exists, offers near matches when it does not, and points at where the worked examples actually live. That is strictly more than "unknown function" and it does not pretend to be a manual it isn't.
