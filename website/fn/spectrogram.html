spectrogram

Builtin index · Signal processing

result = spectrogram(x, [nfft=256], [hop=nfft/2], [fs=1])

Input: x, nfft, hop, fs · Output: result

What it is

x: a length-N real vector or Signal. nfft/hop (optional numbers): STFT frame size and hop, as in stft. fs (optional number, Hz): scales row ticks to Hz and column ticks to seconds. If x is a Signal, its own Fs is used and fs need not be passed; passing one that disagrees with the signal's rate is an error rather than a silent relabelling (see *Which rate is used*, below). The default of 1 applies only to a plain vector, which carries no rate. Renders a heatmap of stft(x, nfft, hop)'s magnitude, restricted to the positive-frequency half (nfft/2+1 rows), in dB (floored at -120dB); frequency increases upward (row 0 = Nyquist). Draws and returns: the surface would otherwise be unreachable, with no way to read a level off it or hand it to Qu Studio's Interactive Mode.

Overloads

One call shape — this function is not overloaded.

How it works

spectrogram(x, [nfft], [hop], [fs]) — heatmap-style render of stft(x, nfft, hop)'s magnitude, restricted to the positive-frequency half (a real input's spectrum mirrors around Nyquist, so the other half is redundant) and shown in dB (20*log10, floored at -120dB) since a handful of loud low-frequency bins would otherwise wash out everything else on a linear color scale. fs (default 1, i.e. normalized frequency) scales the row ticks to Hz and column ticks to seconds; frequency increases upward (row 0 = Nyquist), the usual spectrogram reading convention.
