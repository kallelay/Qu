ln

Builtin index · Core maths

result = ln(x)

Input: x · Output: result

What it is

Natural logarithm, elementwise (log is an alias for ln — it is not base-10; see log10 for that). x is a scalar, Vec, or Mat/Signal; a non-positive element gives NaN/-inf rather than an error.

Overloads

One call shape — this function is not overloaded.

How it works

log(x) is natural; log(x, base) is to that base. The second form existed in every language people arrive from and was silently discarded here -- log(8, 2) answered 2.08.

From the note above this builtin in the interpreter, where the reasoning was written down as it was built.
