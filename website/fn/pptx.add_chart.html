pptx.add_chart

Builtin index · File I/O

pptx.add_chart(p, i, kind, y, [x=], [names=], [colors=], [title=], [x_title=], [y_title=], [at=], [width=160], [height=90], [lines=], [markers=], [legend=], [x_min=], [x_max=], [y_min=], [y_max=], [x_log=false], [y_log=false], [equal_axes=false], [shape_name=])

Input: p, i, kind, y, x, names, colors, title, x_title, y_title, at, width, height, lines, markers, legend, x_min, x_max, y_min, y_max, x_log, y_log, equal_axes, shape_name · Output: no output

What it is

Adds a native, scalable PowerPoint chart to slide i from numbers given directly (a vector or a table column such as data.z); returns the new shape's id. kind is "scatter" (XY, both axes numeric), "line", "bar" (vertical) or "barh" (horizontal). y is a vector for one series, or several series as a parenthesised list (a, b) of vectors or a matrix with one column per series (a bracketed [[..], [..]] is flattened by Qu itself into one vector, so give names= to catch that). x= is one vector shared by all series (x values for scatter, categories for line/bar -- a list of strings gives text labels) or a list with one per series. names=/colors= go one per series (colours by name or #rrggbb, default Qu's plot palette). at=[x, y] is the top-left corner (millimetres or lengths; default: centred on the slide); width/height in millimetres or lengths. Scatter draws markers only (lines=true joins them), line charts lines only. Axis limits, log scales and equal_axes=true (one unit the same length along both axes) are scatter-only. A legend appears when there are several series or names. The numbers are stored in the chart as cached literals, not in an embedded workbook: it renders everywhere with exactly the data given, but PowerPoint's "Edit Data" has no sheet to open -- build a chart that must stay editable with xlsx.add_chart. Only the slide, its relationships, [Content_Types].xml and the new chart part change. *Added in v0.4.7*

Overloads

One call shape — this function is not overloaded.
