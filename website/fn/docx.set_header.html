docx.set_header

Builtin index · File I/O

docx.set_header(doc, text, [section=], [kind="default"], [align=])

Input: doc, text, section, kind, align · Output: no output

What it is

Sets a header's text, replacing its content (creating the header part if there is none). #page and #pages in text become page-number and page-count fields ("Page #page of #pages") -- not {page}, which a Qu string would interpolate. kind is default, first (first page of the section; turns on "different first page") or even (turns on different odd/even pages). Without section every header of that kind is set (section 0 gets one if the document has none); with it, only that section's, which gets its own if it was inheriting one. docx.set_footer is the same for footers. *Added in v0.4.5*

Overloads

One call shape — this function is not overloaded.
