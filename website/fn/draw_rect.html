draw_rect

Builtin index · Images

result = draw_rect(img, x, y, width, height, color=, [thickness=1], [filled=false])

Input: img, x, y, width, height, color, thickness, filled · Output: result

What it is

img is an Image; x, y are the top-left corner (pixel coordinates); width, height are positive numbers. filled=true paints the whole interior (thickness is ignored — a fill has no stroke width); filled=false (default) strokes the four edges with the given thickness. At thickness=1 the outline is exactly 2*(width+height-2) pixels for width, height >= 2 — the same formula image.regions's own perimeter column documents for a solid rectangle's boundary walk.

How it works

draw_rect(img, x, y, width, height, color=, [thickness=1], [filled=false]) -- axis-aligned rectangle, top-left corner (x, y). filled=true ignores thickness (a fill has no stroke width — see Image::draw_rect's own doc comment).
