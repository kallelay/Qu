layer_norm

Builtin index · Statistics & ML

result = layer_norm(x, gamma, beta, [eps=])

Input: x, gamma, beta, eps · Output: result

What it is

Normalizes each row of an N-row, D-column matrix x independently to zero mean and unit variance, then applies a learned length-D per-feature scale gamma and shift beta, with eps (a small positive number, default a tiny constant) added inside the variance's square root for numerical stability.

Overloads

One call shape — this function is not overloaded.

How it works

layer_norm(x, gamma, beta, [eps=1e-5]) — normalizes each ROW of x (one row = one token/sample's feature vector, (n, d) overall) to zero mean / unit variance, then rescales with a learned per-feature gamma and shifts by beta (both length-d, broadcasting as a (1, d) row against x exactly the way dense's own X*W + b bias already broadcasts). Composed ENTIRELY from already-tracked primitives (tb's "-"/".*"/"+"/".*", trr's new "row_mean", tm1's "sqrt") — no bespoke tensor_vjp rule for layer_norm itself, only for the two small row-reduction primitives it (and softmax) both build on. Layer norm's mean/variance backward terms are a well-known place autodiff implementations get subtly wrong, so this was gradient- checked against finite differences before shipping (see the acceptance tests) rather than just visually reasoned through.
