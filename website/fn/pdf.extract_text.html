pdf.extract_text

Builtin index · File I/O

result = pdf.extract_text(src, [pages], [page=], [normalize=false], [lines=false])

Input: src, pages, page, normalize, lines · Output: result

What it is

Text reconstructed from a PDF's content streams. src (string path, or Vec of bytes) is the document; pages (optional, positional or page=) is a page number or a Vec/List of them, defaulting to every page.

Overloads

One call shape — this function is not overloaded.

With normalize=true (added in v0.4.7) ligatures are expanded (fi fl ff ffi ffl and the presentation forms U+FB00 to U+FB06), no-break spaces become spaces, runs of whitespace collapse to one space, empty lines are dropped, and a word split by a line-end hyphen is re-joined (Fi- then nally gives Finally, the two lines becoming one) -- only when the hyphen follows a letter and the next line starts lowercase, so well- / Known is left alone. With lines=true (added in v0.4.7) the result is a List of Str, one per text line, instead of one Str: lines are rebuilt from where each text-showing operator starts (text matrix and cm are followed), grouped by baseline and ordered top to bottom, left to right within a line. There are no glyph widths, so a piece of text is placed by its start only; /Rotate is ignored; a multi-column page comes out interleaved row by row; and a page whose text is inside a Form XObject, or whose fonts have no usable encoding, is an error saying lines could not be recovered, never a faked answer. Both options default to false, which leaves the result byte-identical to earlier versions; both accept only true or false.

import pdf

    t = pdf.extract_text("paper.pdf", page = 1)
