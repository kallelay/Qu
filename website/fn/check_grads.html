check_grads

Builtin index · REPL & diagnostics

result = check_grads(f, x, [step=], [tol=])

Input: f, x, step, tol · Output: result

What it is

Verifies the analytic reverse-mode gradient of scalar-valued f at x against central finite differences of f itself — an independent route to the same number, which is the point: a wrong backward rule would corrupt both an analytic and a tape-derived check together.

Overloads

One call shape — this function is not overloaded.
