pdf.structural_diff

Builtin index · File I/O

result = pdf.structural_diff(src_a, src_b)

Input: src_a, src_b · Output: result

What it is

A coarse, non-content comparison: page count, per-page /MediaBox size, whether each document has an outline (/Outlines) and each document's total annotation count.

Overloads

One call shape — this function is not overloaded.

Returns a Record: pages_a, pages_b (Num), differing_dimensions (List of Records only for pages whose size differs or that exist on only one side, each with page (Num) and a/b — a Record {width, height} in PDF points, or none when that side lacks the page), bookmarks_a/bookmarks_b (Bool) and annotations_a/annotations_b (Num). Deliberately shallow — bookmark-by-bookmark or annotation-by-annotation comparison is a larger feature this does not attempt.
