imscale

Builtin index · Images

result = imscale(img, sx, [sy], [method=], [bbox="loose"], [fill=0])

Input: img, sx, sy, method, bbox, fill · Output: result

What it is

img is an Image; sx is a number, the scale factor (imscale(img, 2) doubles both dimensions); sy is an optional number, the vertical scale factor, defaulting to sx (uniform scale) when omitted. method/fill as in imtranslate. bbox is an optional named string, defaulting to "loose" so the output canvas grows/shrinks to fit the scaled content — the opposite default from imtranslate. Implemented as imwarp + affine_scale. Different from resize, which takes absolute output dimensions rather than a factor.

Overloads

One call shape — this function is not overloaded.

How it works

imscale(img, sx, [sy], [method=]) — pure scale via imwarp + affine_scale. Different from resize(img, width, height): resize takes absolute output dimensions, imscale takes a scale FACTOR (imscale(img, 2) doubles both dimensions; resize(img, 2*img.width, 2*img.height) is the resize-flavored way to say the same thing). Defaults to bbox="loose" (the output canvas grows/shrinks to fit the scaled content, matching resize/MATLAB imresize's own "output IS the new size" semantics) — the sensible default here, unlike imtranslate's "crop".
