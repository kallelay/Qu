basin_hopping

Builtin index · Signal processing

result = basin_hopping(f, x0, [grad=], [n_iter=100], [step_size=1.0], [temperature=1.0], [seed=])

Input: f, x0, grad, n_iter, step_size, temperature, seed · Output: result

What it is

f: a string naming f(params) as in minimize; x0: a length-P vector; grad (optional string); n_iter (optional number, number of hops); step_size/temperature (optional numbers); seed (optional number, RNG seed).

How it works

basin_hopping(f, x0, [grad=], [n_iter=100], [step_size=1.0], [temperature=1.0], [seed=]) — global optimization: repeats random perturbation + local minimize from there, accepting a worse local minimum with Metropolis probability exp(-(new-old)/temperature) instead of always rejecting it, so the search can escape the first local minimum it finds. grad=, same convention as minimize, is forwarded to every local search in place of the default finite-difference gradient. Model kind "minimize" (same fields as minimize, since it's the same underlying result shape).
