rfe

Builtin index · Statistics & ML

result = rfe(X, y, n_features)

Input: X, y, n_features · Output: result

What it is

Recursive feature elimination on an N-row, D-column X and length-N y, down to an integer target n_features: repeatedly drops the weakest-scoring remaining column and refits.

Overloads

One call shape — this function is not overloaded.

How it works

rfe(X, y, n_features, [cv_folds=3], [max_depth=3], [seed=], [kind="classification"]) — recursive feature elimination, model-agnostic; see rfe_select's own doc comment. Returns the kept 0-based column indices, same convention as astar_mrmr.
