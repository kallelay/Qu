kmedians_model

Builtin index · Statistics & ML

result = kmedians_model(X, k, [seed=])

Input: X, k, seed · Output: result

What it is

The outlier-resistant sibling of kmeans_model, same X/k/seed= shape: clusters by L1 distance around coordinate-wise median centres instead of means.

Overloads

One call shape — this function is not overloaded.

How it works

kmedians_model(X, k, [seed=]) — kmeans_model's robust-to- outliers sibling: reuses kmeans_fit's overall assign/update/ repeat-to-convergence loop shape (see kmedians_fit's own doc comment), but swaps BOTH the pieces that actually make it "k-medians" rather than a relabeled k-means — L1 (Manhattan) distance for cluster assignment instead of L2, and the coordinate-wise MEDIAN of each cluster's points for the center update instead of the mean. The median being far less sensitive to a single extreme point than the mean is the for a numeric side-by-side against kmeans_model on data with a planted outlier.

From the note above this builtin in the interpreter, where the reasoning was written down as it was built.
