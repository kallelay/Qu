thd

Builtin index · Signal processing

result = thd(x)

Input: x · Output: result

What it is

x: a length-N real vector (the sampled record).

Overloads

One call shape — this function is not overloaded.

CodeInputOutputDescription
result = thd(x)
x vectornot documented yet
result number
Returns a single number, dB below the fundamental. Total harmonic distortion — every non-fundamental component counts, so a two-tone signal reads as distorted. See the full form under [ADC signal-quality metrics](#adc-signal-quality-metrics-thd-snr-sinad-sfdr-enob) above for the tones=/freqs=/bins=/fs=/leak= keyword options shared by this whole family.

How it works

Real-optimized half-spectrum FFT (NumPy/MATLAB rfft/irfft convention: a real signal's spectrum is Hermitian-symmetric, so only the non-negative-frequency half is returned/needed). sinad(x) / sinad(x, fs=, tones=, bins=, leak=) -- signal-to-noise-and-distortion of a sampled record, plus the SNR, THD, SFDR and ENOB that come with it. With no excitation named, the largest non-DC bin is taken as the fundamental: the single-tone case. Name the tones for a multisine, in Hz via tones= (with fs=) or directly as bin indices via bins= -- treating a multisine as one tone counts every other tone as noise and reads tens of dB low, which is the whole reason the excitation set is a parameter. leak= widens each tone by that many bins either side, for a record that is not exactly coherent. It defaults to 0 because widening hides close-in noise inside the signal and flatters the answer; that has to be the caller's decision.
