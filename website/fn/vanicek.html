vanicek

Builtin index · Signal processing

result = vanicek(t, x, freqs)

Input: t, x, freqs · Output: result

What it is

t is a length-N vector of sample times (need not be uniformly spaced); x is the matching length-N vector of samples; freqs is a length-M vector of frequencies (Hz) to evaluate.

Overloads

One call shape — this function is not overloaded.
