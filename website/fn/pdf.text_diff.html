pdf.text_diff

Builtin index · File I/O

result = pdf.text_diff(src_a, src_b)

Input: src_a, src_b · Output: result

What it is

Page-by-page text diff of two documents, built entirely on pdf.extract_text/pdf.page_count.

Overloads

One call shape — this function is not overloaded.

CodeInputOutputDescription

Returns a Record: pages_a, pages_b (Num, each document's page count) and differing_pages — a List of Records, only for pages that differ (a page present on only one side counts as differing too), each with page (Num), only_in_a/only_in_b (Bool) and lines (List of Records with kind — "same", "added" or "removed" — and text, from a line-based LCS diff; empty when the page exists on only one side).
