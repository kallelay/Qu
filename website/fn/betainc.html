betainc

Builtin index · Core maths

betainc(x, a, b)

Input: x, a, b · Output: no output

What it is

Regularized incomplete beta function I_x(a, b) for 0 <= x <= 1, a, b > 0: betainc(x, 1, 1) = x and betainc(x, a, b) = 1 - betainc(1 - x, b, a). Arguments are real numbers or same-shape Vec/Mats. Lentz continued fraction on the faster-converging side, Loader prefactor for a, b >= 10; accuracy: against 1400 random points (a, b from 0.03 to 3000) the median error is 2e-16 and the worst seen is 4e-13; an mpmath table including 1000 by 1500 agrees to 2e-14 (the iteration count grows like sqrt(max(a, b))). betainc(0) = 0, betainc(1) = 1; x outside [0, 1], a <= 0, b <= 0 or NaN give NaN. Errors: missing arguments, mismatched shapes, complex input.

Overloads

One call shape — this function is not overloaded.
