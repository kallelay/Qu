docx.add_paragraph

Builtin index · File I/O

docx.add_paragraph(doc, text, [bold=], [italic=], [underline=], [size=], [font=], [color=], [align=], [style=])

Input: doc, text, bold, italic, underline, size, font, color, align, style · Output: no output

What it is

Appends a paragraph. size in points, color #rrggbb, align left/center/right/justify, style a paragraph style id (Quote). \n in text is a line break, \t a tab.

Overloads

One call shape — this function is not overloaded.
