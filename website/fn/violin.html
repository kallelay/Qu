violin

Builtin index · Plotting

violin(data) / violin(data1, ...)

Input: data · Output: no output

What it is

The same Gaussian KDE and Tukey summary as raincloud, arranged the other way: the density is MIRRORED about the category into the closed symmetric shape, with the box inside it and the raw points omitted. rain=true puts them back. One group per argument at x = 0, 1, 2, .... Shares raincloud's code path, so the two can never disagree about the density of a given sample.

Overloads

One call shape — this function is not overloaded.
