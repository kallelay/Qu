sin

Builtin index · Core maths

result = sin(x)

Input: x · Output: result

What it is

Standard trigonometric functions, computed elementwise. x is the input angle in radians — a scalar, a Vec of any length, or a Mat/Signal of any shape.

Overloads

One call shape — this function is not overloaded.

CodeInputOutputDescription

Returns exactly the same type and shape as x, one trig value per element.

How it works

sin/cos/tan/asin/acos/atan/sinh/cosh are complex-aware, on the same route as tanh/exp/log/sqrt (map1_complex): real input still takes the real function (a real value outside a real domain, e.g. asin(2), stays NaN rather than silently promoting to complex -- same convention as sqrt(-1)), and an explicit Value::Complex/ CVec/CMat argument takes the complex branch. See Complex64::{sin,cos,tan,asin,acos,atan,sinh,cosh} in qu-core for the identities. sin/cos/sinh/cosh are entire (no poles anywhere in the plane); tan's poles are exactly the real-axis ones real tan already has (see Complex64::tan's doc comment for the proof); asin/acos have branch points at z = +-1. None of these error at a pole/branch point -- Complex64::div already yields non-finite components there, matching the float semantics the rest of the runtime uses (sqrt(-1) doesn't error either).
