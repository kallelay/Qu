quick_mlp

Builtin index · Statistics & ML

result = quick_mlp(X, y, [seed=], [epochs=])

Input: X, y, seed, epochs · Output: result

What it is

Fits a single-hidden-layer multilayer perceptron in one call on an N-row, D-column feature matrix X and a length-N target vector y (or an (N, n_classes) one-hot matrix for multi-class y), with an optional integer seed=, epochs (integer, default 200), and an implied hidden width of clamp(2*D, 8, 64).

Overloads

One call shape — this function is not overloaded.

y_true = [2.0, 4.0, 6.0, 8.0]
w = param(0.0)
function loss_fn(w)
    pred = w * x
    diff = pred - y_true
    return mean(diff .^ 2)
end function
opt = sgd(w, 0.01)
losses = train_loop("loss_fn", w, 100, optimizer = "opt")
print("train_loop (sgd): loss {round(losses[0], 3)} -> {round(losses[99], 5)}")
tape_reset()

w2v = 0.0
opt2 = adam(param(w2v), lr = 0.1)
for t = 0 to 19
    tape_reset()
    w2 = param(w2v)
    pred = w2 * x
    loss2 = mean((pred - y_true) .^ 2)
    g = grad(loss2, wrt = w2)
    opt2 = optimizer_step(opt2, g)
    w2v = opt2._params[0]
end for
print("optimizer_step (adam): w -> {round(w2v, 4)} (target 2.0)")
tape_reset()

How it works

quick_mlp(X, Y, [n_classes=], [seed=], [epochs=], [lr=]) — Tier 1 ("super easy") of the 3-tier Sequential API (2026-08-26): one call, sane defaults, ALREADY FITTED on return. Builds a single-hidden-layer mlp_classifier-shaped net (hidden size auto-picked as 2x the input feature count, clamped to [8, 64] — enough capacity for small/medium tabular inputs without an unbounded parameter count on wide X) and trains it with adam (lr 0.01 by default) rather than plain SGD, since Adam converges faster/better in almost all cases — loss numbers measured against the old hardcoded-SGD .fit() on the same task. n_classes is read from Y's own shape when not given explicitly: a Mat's column count (one-hot labels, loss="cross_entropy") or 1 for a Vec/Num (a single continuous regression target, loss="mse"). Epoch count is a FIXED, documented default (200) rather than true loss-plateau early stopping — sequential_fit's epoch loop has no early-exit hook today, and adding one is a bigger, separate change than this task's "one call, sane defaults" scope; 200 is enough for Adam to converge on the small classification tasks this was verified against, and epochs=/lr= are still accepted here to override it.
