pdf.reverse_pages

Builtin index · File I/O

result = pdf.reverse_pages(src)

Input: src · Output: result

What it is

Reverses page order: the last page becomes the first and vice versa.

Overloads

One call shape — this function is not overloaded.

CodeInputOutputDescription

result Vec
