return_loss

Builtin index · Signal processing

result = return_loss(g)

Input: g · Output: result

What it is

g: a reflection coefficient.

Overloads

One call shape — this function is not overloaded.

CodeInputOutputDescription
result = return_loss(g)
g —not documented yet
result —
Returns -20 log10 |Γ| in dB, positive for a passive load — the engineering convention in which "20 dB return loss" means well matched. A perfect match is inf.

Examples

From the documentation, and run by the build -- the output and the figure below are what the engine actually produced. Simplest first.

g = reflection_coefficient(100)         # 100 ohm on a 50 ohm line

print("gamma = {g}")                     # 0.333333

print("VSWR  = {vswr(g)}")                # 2

print("RL    = {return_loss(g)} dB")      # 9.542425


swept = reflection_coefficient([50, 100, 0, 25])
print("VSWR swept = {vswr(swept)}")       # [1, 2, inf, 2]  -- the short is inf
