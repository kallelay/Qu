triu

Builtin index · Core maths

tril(A, k)

Input: A, k · Output: no output

What it is

Lower/upper triangle of A, other entries set to 0. k (default 0) shifts the diagonal: tril(A, -1) is strictly lower, triu(A, 1) strictly upper. A is a Mat (a Vec is a column); k must be a whole number; complex is an error.

Overloads

One call shape — this function is not overloaded.
