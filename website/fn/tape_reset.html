tape_reset

Builtin index · Statistics & ML

tape_reset()

Input: no input · Output: no output

What it is

Discards every entry recorded so far on the autodiff tape, freeing the memory a chain of param/grad calls has built up. Takes no arguments; call it between independent computations, since a program that never calls it keeps every tracked operation alive for as long as it runs.

Overloads

One call shape — this function is not overloaded.

How it works

tape_reset() — frees every recorded TapeEntry (memory hygiene for a long-running script that keeps building new Tensors and never needs to grad() against an old one). Danger: any Value::Tensor created *before* this call has its .node index invalidated — the tape's own numbering starts over from 0, so a stale Tensor's old index can silently collide with a brand-new node created after the reset, corrupting *that* node's gradient rather than erroring (traced down inside train_loop, which used to clear the tape and then keep reusing the same pre-reset Tensor every epoch — fixed there by building a genuinely fresh leaf Tensor each time, right after each reset, never carrying one across the boundary). Safe usage: reset only when nothing you still hold a Value::Tensor reference to will be used in a later grad() call — re-wrap any value you need to keep training through via param()/track() again after resetting.
