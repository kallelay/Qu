rlkk_reconstruct

Builtin index · Signal processing

result = rlkk_reconstruct(Z, freqs, [lambda=1e-4], [fx=])

Input: Z, freqs, lambda, fx · Output: result

What it is

Z: a length-N complex vector (CVec); freqs: a length-N real vector (Hz); lambda (optional number): regularization strength, larger tolerates noisier data at the cost of fitting detail; fx (optional length-M real vector, Hz): overrides the default DRT frequency grid (logspace(-8, 8, 160), i.e. M=160).

Overloads

One call shape — this function is not overloaded.

Examples

From the documentation, and run by the build -- the output and the figure below are what the engine actually produced. Simplest first.

Z = [100 - 20i, 80 - 45i, 50 - 55i, 30 - 35i, 22 - 12i]   # measured impedance

freqs = [0.1, 1, 10, 100, 1000]                          # Hz


fit = rlkk_reconstruct(Z, freqs, lambda = 1e-4) # fit.z, fit.gamma

v = rlkk_validate(Z, freqs, lambda = 1e-3, threshold = 2.0)
if v.valid
    print("consistent within {v.max_residual:.2f}%")
else
    print("bad points: {where(abs(v.residuals) > 2.0)}")
end if

How it works

(rLKK) validation/reconstruction, a port of Ahmed Yousef Kallel's own published method (Kallel & Kanoun, "Regularized linear Kramers-Kronig transform for consistency check of noisy impedance spectra with logarithmic frequency distribution", IWIS 2021) — see qu_core::eis for the algorithm. Z is a complex impedance spectrum (a CVec), freqs its frequency vector in Hz. rlkk_reconstruct/ rlkk_validate return a Value::Model (the same named-field multi-return convention as kalman_init/ols_model) since each call's outputs are one related result, not independent ones. rlkk_reconstruct(Z, freqs, [lambda=1e-4], [fx=]) — model kind "rlkk", fields z (the reconstructed spectrum) and gamma (the fitted DRT coefficients).
