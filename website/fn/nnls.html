nnls

Builtin index · Core maths

result = nnls(A, b, max_iter=)

Input: A, b, max_iter · Output: result

What it is

Non-negative least squares by Lawson-Hanson, for when a negative coefficient would be physically meaningless — a concentration, a mass, a relaxation strength. A is an m×n Mat, b a length-m Vec; max_iter is an optional scalar iteration cap (unset by default, meaning the solver's own internal limit applies).

Overloads

One call shape — this function is not overloaded.
