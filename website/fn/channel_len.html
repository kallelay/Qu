channel_len

Builtin index · Concurrency

result = channel_len(ch)

Input: ch · Output: result

What it is

How many messages are queued right now on channel ch, without consuming any of them.

Overloads

One call shape — this function is not overloaded.

CodeInputOutputDescription
result = channel_len(ch)

result —
Returns an integer — a diagnostic/backpressure-aware-producer helper, not needed for ordinary send/recv.

Examples

From the documentation, and run by the build -- the output and the figure below are what the engine actually produced. Simplest first.

channel_send(ch, 1)
