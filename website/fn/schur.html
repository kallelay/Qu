schur

Builtin index · Core maths

schur(A)

Input: A · Output: no output

What it is

Real Schur decomposition of a dense real square matrix, returned as a record {T, U} with U orthogonal, T real quasi-upper-triangular (1×1 blocks for real eigenvalues, 2×2 blocks for complex-conjugate pairs) and A = U*T*U'. From the QR iteration (nalgebra's Schur), with every 2×2 block that has real eigenvalues split into two 1×1 blocks, so a 2×2 block on the diagonal always means a complex pair. The eigenvalues are on the diagonal, and schur(A).T is exactly upper triangular when all eigenvalues are real. Errors: a non-square, empty or non-finite matrix, a complex matrix, an iteration that does not converge.

Overloads

One call shape — this function is not overloaded.
