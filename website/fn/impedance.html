impedance

Builtin index · Signal processing

result = impedance(c, freqs)

Input: c, freqs · Output: result

What it is

c: a circuit; freqs: frequencies in Hz, not rad/s.

Overloads

One call shape — this function is not overloaded.

CodeInputOutputDescription
result = impedance(c, freqs)
c —c: a circuit.
freqs —freqs: frequencies in Hz, not rad/s.
result vector
Returns a complex vector, one impedance per frequency. A zero or negative frequency is an error rather than an infinity: at DC a capacitor's impedance is unbounded and a Warburg's is undefined, and returning inf/NaN into a spectrum hides the mistake instead of reporting it.

Examples

From the documentation, and run by the build -- the output and the figure below are what the engine actually produced. Simplest first.

randles = series(resistor(0.2), parallel(resistor(0.01), capacitor(100e-6)))
Z = impedance(randles, logspace(-2, 5, 200))     # frequencies in Hz

nyquist(Z)

from signal-processing

How it works

A circuit is a model and carries no frequency axis; this is what turns it into data. Frequencies are in Hz, the axis measured data arrives on.
