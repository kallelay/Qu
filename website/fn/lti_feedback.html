lti_feedback

Builtin index · Signal processing

result = lti_feedback(plant, [controller], [sign=-1])

Input: plant, controller, sign · Output: result

What it is

No chapter describes this one yet. It exists -- the name comes from the interpreter's own table -- but the prose has not been written. That is a gap in the documentation, not in the engine.

Overloads

One call shape — this function is not overloaded.

CodeInputOutputDescription
result = lti_feedback(plant, [controller], [sign=-1])
plant —Returns the closed loop with plant in the forward path and controller in the return path, plant / (1 + plant * controller) for the default negative feedback, as an "lti" model in state-space form.
controller number, optionalcontroller (optional system or number): omitted means unity feedback.
sign optional (default -1)sign (optional, also third positional): -1 for negative feedback, +1 for positive.

sign —optional, also third positional
Returns the closed loop with plant in the forward path and controller in the return path, plant / (1 + plant * controller) for the default negative feedback, as an "lti" model in state-space form. controller (optional system or number): omitted means unity feedback; sign (optional, also third positional): -1 for negative feedback, +1 for positive. To close a loop around a controller in the forward path, pass the cascade: lti_feedback(lti_series(controller, plant)). A loop with no dynamics around it that cannot be solved (an algebraic loop) is an error.

Examples

From the documentation, and run by the build -- the output and the figure below are what the engine actually produced. Simplest first.

plant = lti_tf([1], [1, 3, 2, 0])             # 1 / (s (s+1) (s+2))

m = lti_margin(plant)
print("{m.gm} at {m.w_gm} rad/s")             # 6 at 1.414214 rad/s

closed = lti_feedback(lti_series(2, plant))    # gain 2, unity negative feedback

print(lti_is_stable(closed))                   # true

r = lti_step(closed, 20)
print(r.y[len(r.y) - 1])                       # 1.006126

d = lti_c2d(lti_tf([1], [0.5, 1]), 0.1)        # first-order lag, tau = 0.5

print(d.A)                                     # [0.818731], exp(-0.1/0.5)
