trapz

Builtin index · Signal processing

trapz(y), trapz(x, y)

Input: y · Output: no output

What it is

Trapezoid-rule integral of the samples y against x (unit spacing when x is omitted), summed with compensated (Neumaier) summation. x may be unevenly spaced but must have the length of y. Like MATLAB, a matrix y is integrated along dimension 1: each column is a signal and the result is a Vec with one integral per column; a vector (or a one-row matrix) gives a number. Fewer than two samples integrate to 0. Error order O(h^2).

Overloads

One call shape — this function is not overloaded.
