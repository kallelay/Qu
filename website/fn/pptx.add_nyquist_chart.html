pptx.add_nyquist_chart

Builtin index · File I/O

result = pptx.add_nyquist_chart(p, i, re, im, [negate=true], [name=], [color=], [title=], [x_title="Z' / Ω"], [y_title="-Z'' / Ω"], [at=], [width=150], [height=110], [lines=false], [markers=], [legend=], [shape_name=])

Input: p, i, re, im, negate, name, color, title, x_title, y_title, at, width, height, lines, markers, legend, shape_name · Output: result

What it is

A Nyquist plot for impedance spectroscopy on slide i: Z' along x, -Z'' up, both axes on the SAME scale with square gridlines, so a semicircle stays round. Give Z' and Z'' as two vectors, or call pptx.add_nyquist_chart(p, i, Z, ...) with one complex vector (its real part against minus its imaginary part). With negate=true (Z'' as measured, negative for a capacitive arc) -Z'' is plotted; negate=false plots im as given. The axis limits follow the data.

Overloads

One call shape — this function is not overloaded.
