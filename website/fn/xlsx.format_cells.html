xlsx.format_cells

Builtin index · File I/O

result = xlsx.format_cells(wb, sheet, range, [bold=], [italic=], [size=], [font=], [color=], [background=], [number_format=], [align=])

Input: wb, sheet, range, bold, italic, size, font, color, background, number_format, align · Output: result

What it is

Formats every cell of range: colours as #rrggbb, number_format in Excel's own codes (0.00, 0.00E+00, yyyy-mm-dd), align left/center/right.

Overloads

One call shape — this function is not overloaded.
