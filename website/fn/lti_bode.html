w vectoroptional vector
Returns a record {w, mag_db, phase_deg}: magnitude in dB and phase in degrees at each frequency. w (optional vector): the frequencies; by default about 50 log-spaced points per decade covering every pole and zero with a decade to spare (continuous) or up to pi rad/sample (discrete). The phase is unwrapped along w, and its starting branch is set from the angles the zeros and poles contribute, so three integrators read -270 degrees rather than +90. It draws nothing: plot the vectors, e.g. semilogx(r.w, r.mag_db). Single-input single-output only.
