lgamma

Builtin index · Core maths

gamma(x)

Input: x · Output: no output

What it is

The gamma function (gamma(n) = (n-1)! for a positive integer n) and its natural log (lgamma(x) = ln|gamma(x)|). x is a real scalar, Vec, or Mat/Signal. Both have a pole at every non-positive integer (0, -1, -2, ...) — evaluating there is an error, not a silent inf/NaN.

One call shape — this function is not overloaded.

How it works

lgamma(x) = ln|gamma(x)| -- same poles as gamma itself (ln of a pole is still a pole, not a large-but-finite number). libm::lgamma_r returns (ln|gamma(x)|, sign); only the magnitude is lgamma's contract here, matching every other language's lgamma.
