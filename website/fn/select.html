select

Builtin index · Collections & strings

result = select(df, "col", ...)

Input: df, "col", ... · Output: result

What it is

df is a Table; each remaining argument is a Str column name.

Overloads

One call shape — this function is not overloaded.

Returns a Table containing only the named columns, in the order given.

Examples

From the documentation, and run by the build -- the output and the figure below are what the engine actually produced. Simplest first.

df = DataFrame(x=[1, 2, 3, 4, 5], y=[10, 20, 30, 40, 50], label="sample")
print(nrow(df))            # 5

print(ncol(df))             # 3

tall = filter(df, df.x > 2)
xy = select(tall, "x", "y")
print(xy)
print(describe(df))
