parse_json

Builtin index · File I/O

result = parse_json(str)

Input: str · Output: result

What it is

jsonify's inverse. str (string) is JSON text — either a jsonify/save-style {"type": ...} envelope, or ordinary JSON from anywhere else (e.g. an HTTP API response), which is mapped in generically.

Overloads

str can be string or Complex.

Returns the exact typed Value that tag names, reconstructed in full, not a generic guess from the JSON's own shape.

Examples

Written for this form and run by the build -- the output below is what the engine actually produced.

env = jsonify(3 + 4j)
back = parse_json(env)
print(env)          # {"type":"complex","re":3.0,"im":4.0}

print(type(back))   # complex

print(back)         # 3 + 4i
output
{"type":"complex","re":3.0,"im":4.0}
