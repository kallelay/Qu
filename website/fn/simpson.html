simpson

Builtin index · Signal processing

simpson(y), simpson(x, y)

Input: y · Output: no output

What it is

Composite Simpson's rule on sampled data, with the same x/matrix conventions as trapz. Intervals are taken in pairs with the three-point formula for an uneven grid (exact for cubics when the number of intervals is even). With an odd number of intervals the last one is integrated with the quadratic through the last three points, so the result is exact for quadratics but not cubics. Two samples fall back to the trapezoid. Repeated x values are an error. Error order O(h^4) for smooth data.

Overloads

One call shape — this function is not overloaded.
