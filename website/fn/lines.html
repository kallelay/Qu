lines

Builtin index · Collections & strings

result = lines(s)

Input: s · Output: result

What it is

s is a Str. Splits on either line ending, with no spurious empty last element when the text ends in a newline.

Overloads

One call shape — this function is not overloaded.

How it works

lines(s) — split into lines, tolerating either line ending, and WITHOUT a spurious empty last line when the text ends in a newline (which it usually does, and which split(s, "\n") gives you).
