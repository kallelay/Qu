minimize

Builtin index · Signal processing

result = minimize(f, x0, [grad=], [max_iter=200], [tol=1e-8])

Input: f, x0, grad, max_iter, tol · Output: result

What it is

f: a string naming a user-defined function f(params) (a length-P vector) returning a scalar; x0: a length-P vector, the starting point; grad (optional string naming a gradient function, else the gradient is numerical/central-differences); max_iter/tol (optional numbers).

Overloads

One call shape — this function is not overloaded.

How it works

minimize(f, x0, [grad=], [max_iter=200], [tol=1e-8]) — L-BFGS, a quasi-Newton ("pseudo-Newton") multivariate minimizer: f takes a single params vector and returns a scalar. By default the gradient is computed numerically (central differences); passing grad="gradfn" (a function params -> gradient vector, same shape as f) uses that exact analytical gradient instead — cheaper (one call instead of 2n) and not subject to finite-difference error. Model kind "minimize", fields params, value, converged.
