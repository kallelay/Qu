sleep

Builtin index · Concurrency

sleep(seconds)

Input: seconds · Output: no output

What it is

seconds (number, fractional values honoured, e.g. 0.5 for half a second). Pauses the calling thread for that long.

Overloads

One call shape — this function is not overloaded.

How it works

sleep(ms) (§ wait until / sleep, scoped 2026-08-26) — a REAL OS sleep (std::thread::sleep), not a simulated- timeline wait like every/after/at's run_for virtual clock. This is the one piece that makes wait until COND ... end until actually usable instead of busy-spinning a CPU core at 100%: wait until is plain sugar for a while loop (see qu-syntax's wait_until_stmt), and a while loop re-checking a condition with no delay between checks has no way to yield the CPU without this. Blocks only the calling thread — doesn't touch pool/run's worker threads, produces no value, and consults no RNG state, so it doesn't interact with seed(n)/order-stable-reduction determinism at all; it's real wall-clock time, which this codebase already accepts as inherently non-reproducible elsewhere (tic/toc).
