bitand

Builtin index · Collections & strings

result = bitand(a, b)

Input: a, b · Output: result

What it is

a and b are numbers holding integer values.

Overloads

One call shape — this function is not overloaded.

CodeInputOutputDescription
result = bitand(a, b)
a numbernot documented yet
b numbernot documented yet
result number
Returns a number: the bitwise AND of a and b as 64-bit integers.

Examples

How it works

Bitwise ops (2026-08-23, Ahmed: "do we have & && | || xor bitxor bitor or bitand and nand nor"). Value has no separate integer type — everything is f64 — so these read each argument as an integer via int_arg (rejecting non-integral input rather than silently truncating it), do the op as i64, and hand back a Num. Deliberately builtins, not new &/|-family operators: and/or already mean logical and/or in Qu, so overloading &/| for bitwise would be ambiguous with no precedent in the grammar; bitand/bitor/bitxor read unambiguously and match MATLAB's own naming for the same idea. | and & themselves are now a clear parse error pointing here (qu-syntax::add_expr) instead of the | runtime error they used to produce.
