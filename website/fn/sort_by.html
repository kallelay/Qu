sort_by

Builtin index · Collections & strings

result = sort_by(df, "col", [descending])

Input: df, "col", descending · Output: result

What it is

df is a Table; "col" is a Str column name; optional descending (bool, default false).

Overloads

One call shape — this function is not overloaded.

pos = filter(df, df.x > 0)
print(pos)

s = sort_by(df, "y")
print(s)
