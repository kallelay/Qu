crest_factor

Builtin index · Core maths

result = crest_factor(x)

Input: x · Output: result

What it is

peak(x) / rms(x), a dimensionless ratio (a sine wave's is sqrt(2) ≈ 1.414) — the same quantity sinad_estimate(bits, crest_factor) takes as its second argument. x is a scalar, Vec, or Mat/Signal, flattened.

Overloads

One call shape — this function is not overloaded.

Returns a scalar Num. Errors on an empty vector or one whose RMS is zero (silence has no crest factor).
