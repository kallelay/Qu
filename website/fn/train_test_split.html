train_test_split

Builtin index · Statistics & ML

result = train_test_split(X, y, [test_size=0.2], [seed=], [shuffle=true])

Input: X, y, test_size, seed, shuffle · Output: result

What it is

Splits an N-row feature matrix X and a length-N target vector y into training and test sets, X and y permuted together by the same random order (unless shuffle=false). test_size is a number in (0, 1) giving the test fraction (default 0.2), and seed= an optional integer.

Overloads

One call shape — this function is not overloaded.

from statistics-ml

Xc = randn(200, 2, seed = 41)
yc = zeros(200)
for i in 0 to 199
    if Xc[i, 0] + Xc[i, 1] > 0
        yc[i] = 1
    end if
end for
s = train_test_split(Xc, yc, test_size = 0.3, seed = 9)

function accuracy(model)
    yhat = model.predict(s.X_test)
    hit = yhat == s.y_test
    return len(yhat[hit]) / len(yhat)
end function

How it works

train_test_split(X, y, [test_size=0.2], [seed=], [shuffle=true]) — scikit-learn's train_test_split: a random row permutation (shuffle=true, the default) split into a leading train fraction and a trailing test fraction, X/y permuted in lockstep so no row's features and label ever separate. An explicit seed= gives a fresh reproducible local RNG stream (two calls with the same seed= produce byte-identical splits); omitted, it advances the interpreter's persistent stream instead — the same fork randn's own doc comment describes, not a new convention. shuffle=false keeps the original row order (see sequential_split for why that's also exposed under its own name). Returns a "split" model handle with .X_train/.X_test/.y_train/.y_test fields.
