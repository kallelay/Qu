multisine

Builtin index · Signal processing

result = multisine(freqs, amps, fs, n, [phases=])

Input: freqs, amps, fs, n, phases · Output: result

What it is

freqs, amps: length-K vectors (Hz, amplitude per tone); fs: number (Hz); n: number (integer sample count); phases (optional length-K vector, radians).

Overloads

One call shape — this function is not overloaded.

How it works

multisine(freqs, amps, fs, n, [phases=]) — sum of cosines at the given frequencies/amplitudes, wiring up qu_core::signal's existing MultisinePlan/synthesize_cpu (the same kernel qu-gpu's batched synthesis parity-tests against, per BOARD.md — previously real but never callable from a Qu script). Defaults to Schroeder's phase formula (phi_k = -k(k-1)*pi/K, 1-indexed tone number k of K total) when phases isn't given — a well-known deterministic choice that keeps crest factor low without the iterative optimization this session's private L-BFGS work targets.

From the note above this builtin in the interpreter, where the reasoning was written down as it was built.
