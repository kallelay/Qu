histogram

Builtin index · Plotting

hist(samples, [bins])

Input: samples, bins · Output: no output

What it is

Bins samples (Vec of numbers) into equal-width buckets and renders as bars; bins (integer, positional or bins= keyword) defaults to ceil(sqrt(n)) for n = len(samples).

Overloads

One call shape — this function is not overloaded.

How it works

hist(samples) / hist(samples, bins) bins raw samples into equal-width buckets and renders as bars -- distinct from bar, which takes already-aggregated (x, height) pairs.
