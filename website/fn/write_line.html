write_line

Builtin index · File I/O

write_line(f, s)

Input: f, s · Output: no output

What it is

Writes s (string) to f (file handle, opened writable/appendable) plus a trailing \n.

Overloads

One call shape — this function is not overloaded.

How it works

write(f, s) (file form, above) — raw string/bytes, no added newline. write_line(f, s) — the same, plus a trailing \n. Writing to a handle opened in "r" mode errors clearly (file_check_writable), never silently no-ops or panics.
