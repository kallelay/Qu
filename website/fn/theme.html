theme

Builtin index · Plotting

theme(name)

Input: name · Output: no output

What it is

Sets the whole-figure visual theme from name (string): one of "default", "publication", "bw", "minimal", "grey", "classic". "publication" also embeds fonts, because a figure asked to be print-ready has to look the same wherever it lands.

Overloads

One call shape — this function is not overloaded.

How it works

theme("minimal") / theme("default") — see plotting::Figure.minimal. Figure-level, like fontfamily/ fontsize/figure_background, not per-panel. Any name other than "minimal" (including a typo) resolves to the default journal-style theme rather than erroring, matching colormap's own "bad name is not fatal" convention. theme("minimal") / theme("publication") / theme("screen"). "publication" is a TARGET, not just a look (see plotting::Figure.publication): the figure is bound for a printed page rather than this monitor. Because that target implies a whole set of choices that would be tedious and easy to get wrong one call at a time, it also sets the two companions a print figure almost always wants -- Latin Modern (the typeface a LaTeX paper is already set in) and the colourblind-safe Okabe-Ito palette. Both remain overridable: call fontfamily(...)/colormap(...) AFTER theme(...) and your choice wins, exactly like fontsize after figure_size.
