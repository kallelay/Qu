lognrnd

Builtin index · Statistics & ML

result = lognrnd(mu, sigma, [rows], [cols], [seed=])

Input: mu, sigma, rows, cols, seed · Output: result

What it is

Random draws from the log-normal distribution. Every parameter is required here (the size follows them); rows/cols and seed= work as for rand, and seed(n) governs unseeded calls.

Overloads

One call shape — this function is not overloaded.
