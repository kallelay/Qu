impz

Builtin index · Signal processing

result = impz(filt, [n])

Input: filt, n · Output: result

What it is

filt: a Model (kind "filter"); n (optional number): without it an FIR's tap count, or for an IIR the samples until the response has run for about 14 time constants of its slowest pole (200000 at most).

Overloads

One call shape — this function is not overloaded.

How it works

impz(filt, [n]) / stepz(filt, [n]) -- the impulse and step response as length-n vectors. Without n: an FIR's own tap count, or an IIR's response until it has decayed (at most 4096).
