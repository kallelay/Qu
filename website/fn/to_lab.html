to_lab

Builtin index · Plotting

result = to_rgb(color)

Input: color · Output: result

What it is

Takes apart any colour the language accepts (color, a string) into that space's own coordinates, returned as a Vec of numbers — to_rgb gives (r,g,b), to_hsl gives (h,s,l), to_lab gives (L,a,b), to_cmyk gives (c,m,y,k). See also to_hsv in the Colour spaces table above, which is the same idea.

Overloads

One call shape — this function is not overloaded.

CodeInputOutputDescription

Returns a Vec of numbers — 3 elements for to_rgb/to_hsl/to_lab, 4 for to_cmyk.

How it works

to_hsv(color) and friends: the same journey back. Take any colour the language accepts -- a name, a hex, an rgb() -- and give its coordinates in that space, so a colour can be picked apart and rebuilt.
