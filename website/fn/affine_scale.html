affine_scale

Builtin index · Images

result = affine_scale(sx, [sy])

Input: sx, sy · Output: result

What it is

Builds a scaling transform for imwarp. sx is a number, the scale factor along x; sy is an optional number, the scale factor along y, defaulting to sx (uniform scale) when omitted — matching MATLAB imresize(img, scale)'s single-factor convention.

Overloads

One call shape — this function is not overloaded.

How it works

affine_scale(sx, [sy]) — uniform scale when sy is omitted (sy = sx), matching MATLAB imresize(img, scale)'s own single-factor convention.
