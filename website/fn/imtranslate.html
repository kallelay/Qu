imtranslate

Builtin index · Images

result = imtranslate(img, dx, dy, [method=], [bbox="crop"], [fill=0])

Input: img, dx, dy, method, bbox, fill · Output: result

What it is

img is an Image; dx/dy are numbers, the horizontal/vertical pixel shift (positive = right/down). method is an optional named string ("nearest"/"bilinear") controlling resampling. bbox is an optional named string, defaulting to "crop" (output stays the same size as the input, matching MATLAB imtranslate's 'OutputView','same') — the opposite default from imwarp/imscale. fill is an optional named number 0–255 (default 0), the byte value used on all 3 channels for pixels that map outside the source. Implemented as imwarp + affine_translate.

Overloads

One call shape — this function is not overloaded.

How it works

imtranslate(img, dx, dy, [fill=0]) — pure translation via imwarp + affine_translate. Defaults to bbox="crop" (the output stays the input's own size, matching MATLAB imtranslate's default 'OutputView','same') rather than imwarp's own "loose" default — a translation's "natural" canvas is the same one it started with, unlike a rotation or scale, which genuinely change the content's footprint.
