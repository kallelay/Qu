linspace

Builtin index · Signal processing

result = linspace([a=0], [b=1], [n=50])

Input: a, b, n · Output: result

What it is

a, b (optional numbers): the inclusive endpoints; n (optional number, integer count).

Overloads

One call shape — this function is not overloaded.

CodeInputOutputDescription

result vector
Returns a length-n real vector, n linearly spaced points from a to b inclusive — the standard companion for building a time or frequency axis to plot alongside a generated/transformed signal.
