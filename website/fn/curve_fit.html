curve_fit

Builtin index · Signal processing

result = curve_fit(model, xdata, ydata, p0, [max_iter=200], [tol=1e-10])

Input: model, xdata, ydata, p0, max_iter, tol · Output: result

What it is

model: a string naming a user-defined function model(x, params) (x a scalar, params a length-P vector) returning a scalar; xdata, ydata: length-N vectors; p0: a length-P vector, the initial parameter guess; max_iter/tol (optional numbers).

Overloads

Nonlinear least-squares curve fitting via Levenberg-Marquardt (the Jacobian is numerical, forward differences): finds params minimizing sum((model(x_i, params) - y_i)^2).

How it works

curve_fit(model, xdata, ydata, p0, [max_iter=200], [tol=1e-10]) — nonlinear least-squares curve fitting via Levenberg-Marquardt: finds params minimizing sum((model(x_i, params) - y_i)^2). model takes a scalar x and a params vector; the Jacobian is computed numerically (forward differences), since Qu has no automatic differentiation. Model kind "curve_fit", fields params, cost (the residual sum of squares at the returned parameters), and converged.
