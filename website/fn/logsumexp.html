logsumexp

Builtin index · Core maths

result = lse(x)

Input: x · Output: result

What it is

Numerically stable log(sum(exp(x))), via the usual max-shift so a large input can't overflow exp. x is a scalar, Vec, or Mat/Signal, flattened.

Overloads

One call shape — this function is not overloaded.

CodeInputOutputDescription
result = lse(x)
x scalar, Vec, Mat, or Signalnot documented yet
result scalar or Num
Returns a scalar Num — -inf for an empty x.

Examples

From the documentation, and run by the build -- the output and the figure below are what the engine actually produced. Simplest first.

crest(x) := max(abs(x)) / rms(x)

xs = [0, 1, 2, 3]
print("hard max = {max(xs)}")
print("logsumexp = {logsumexp(xs):.4f}")       # >= hard max, a proven upper bound

print("smoothmax b=50 = {smoothmax(xs, 50):.4f}")  # -> hard max as beta grows

print("softmax = {softmax(xs)}")                # the gradient of logsumexp

from numerics-dsp

How it works

smooth-max family: logsumexp(x), smoothmax(x[, beta]), softmax(x).
