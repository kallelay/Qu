blur_backdrop

Builtin index · Plotting

blur_backdrop(x0, y0, x1, y1, [radius=])

Input: x0, y0, x1, y1, radius · Output: no output

What it is

Figure-level (not per-panel) depth-of-field effect: (x0,y0)–(x1,y1) (numbers, fractions 0..1 of the whole rendered canvas) name the rectangle that stays sharp; everything else is Gaussian-blurred. radius= (number, blur strength). SVG-native (<feGaussianBlur>); the TikZ export has no filter-primitive equivalent so it degrades to an unblurred render plus an explanatory comment.

Overloads

One call shape — this function is not overloaded.

How it works

blur_backdrop(x0, y0, x1, y1, radius=) — a figure-level (not per-panel) depth-of-field-style effect: (x0,y0)-(x1,y1) are fractions 0..1 of the whole rendered canvas (not panel data coordinates) naming the rectangle that stays sharp; everything else in the figure is Gaussian-blurred behind it. SVG-native via <feGaussianBlur> (see plotting::render_svg); TikZ has no filter-primitive equivalent, so render_tikz degrades to an unblurred render plus a comment noting why, rather than erroring the whole export or silently dropping the request.

From the note above this builtin in the interpreter, where the reasoning was written down as it was built.
