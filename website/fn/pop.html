pop

Builtin index · Collections & strings

result = push(q, x) / pop(q) / peek(q)

Input: q, x · Output: result

What it is

On a fifo handle q: push(q, x) adds x at the back (returns Nothing); pop(q) removes and returns the front element; peek(q) looks at it without removing. pop on an empty FIFO is an error. On a queue() — the job queue — push(q, "fname") enqueues a function you defined instead (a Str naming it, not a value).

Overloads

One call shape — this function is not overloaded.

Examples

From the documentation, and run by the build -- the output and the figure below are what the engine actually produced. Simplest first.

f = fifo(3)
f.push(1)
f.push(2)
f.push(3)
f.push(4)          # evicts 1 -- buffer is now [2, 3, 4]

print(peek(f))       # 2 -- oldest element, still there

print(f.pop())      # 2

print(len(f))        # 2
