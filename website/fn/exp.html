exp

Builtin index · Core maths

result = exp(x)

Input: x · Output: result

What it is

e^x, elementwise. x is a scalar, Vec, or Mat/Signal; returns the same shape with every element exponentiated.

Overloads

One call shape — this function is not overloaded.

CodeInputOutputDescription
result = exp(x)
x scalar, Vec, Mat, or Signalnot documented yet
result —
Returns exactly the same type and shape as x.
