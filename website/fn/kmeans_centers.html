kmeans_centers

Builtin index · Statistics & ML

result = kmeans_centers(X, k, [seed=])

Input: X, k, seed · Output: result

What it is

The same Lloyd's-algorithm run as kmeans on X/k/seed=, returning the (k, D) centroid matrix instead of the labels. Passing the same seed= as a kmeans call on the same X/k reproduces the matching run.

Overloads

One call shape — this function is not overloaded.

Returns a (k, D) Mat, one centroid per row.

Examples

From the documentation, and run by the build -- the output and the figure below are what the engine actually produced. Simplest first.

G = vstack(randn(40, 2, seed = 31) + 4,
           randn(40, 2, seed = 32) - 4,
           randn(40, 2, seed = 33))
labels = kmeans(G, 3, seed = 5)
centers = kmeans_centers(G, 3, seed = 5)
xs = G[:, 0]
ys = G[:, 1]
for k in 0 to 2
    inside = labels == k
    print("cluster {k}: {len(xs[inside])} points")
    scatter(xs[inside], ys[inside], label = "cluster {k}")
end for
scatter(centers[:, 0], centers[:, 1], marker = "x", color = "#0f172a", size = 12, label = "centroids")
legend()
title("kmeans, k = 3")
