pptx.rotate_shape

Builtin index · File I/O

pptx.rotate_shape(p, i, shape, degrees)

Input: p, i, shape, degrees · Output: no output

What it is

Sets the shape's rotation to degrees clockwise (0 or 360 clears it; a negative angle turns it the other way). A placeholder positioned by its layout gets its own position first, so it does not jump. Charts, tables and other graphic frames cannot be rotated in PowerPoint and say so. *Added in v0.4.7*

Overloads

One call shape — this function is not overloaded.
