welch

Builtin index · Signal processing

result = welch(x, fs, [nperseg=min(256,len(x))], [noverlap=nperseg/2], [window="hann"])

Input: x, fs, nperseg, noverlap, window · Output: result

What it is

x: a length-N real vector; fs (number, Hz): sample rate. nperseg (optional number): samples per segment; noverlap (optional number): overlap between segments; window (optional string, e.g. "hann"/"hamming"/"blackman"): window applied to each segment.

Overloads

One call shape — this function is not overloaded.

Returns a length-nperseg/2 + 1 real vector, the one-sided PSD (DC to Nyquist) in SciPy's "density" scaling — Welch's method segments x into overlapping windowed frames and averages their squared-magnitude spectra. Pair with linspace(0, fs/2, length(psd)) for the frequency axis.

Examples

fs = 1000
n = 0:1:1023
t = n / fs
x = sin(2*pi*100*t) + 0.05 * randn(1024, seed=1)

psd_w = welch(x, fs, nperseg=256)
f_w = linspace(0, fs/2, length(psd_w))
peak_w = find_peaks(psd_w, min_height=max(psd_w)*0.5)

How it works

welch(x, fs, [nperseg=], [noverlap=], [window="hann"]) — Welch's method PSD estimate: segments x into overlapping, windowed frames and averages their squared-magnitude spectra (qu_core::transforms::welch, itself stft's own framing scheme generalized to a caller-chosen window). nperseg defaults to min(256, length(x)) (SciPy's own default); noverlap defaults to nperseg/2 (50% overlap, also SciPy's default); window defaults to "hann", matching scipy.signal.welch's own default. Returns the one-sided PSD as a plain Value::Vec (nperseg/2 + 1 bins, DC to Nyquist) in SciPy's "density" scaling (units²/Hz) — reconstruct the matching frequency axis with linspace(0, fs/2, length(psd)), the same convention freqz/group_delay already use. periodogram below is the same code path's one-segment, no-averaging special case.
