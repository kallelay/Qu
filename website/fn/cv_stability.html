cv_stability

Builtin index · Statistics & ML

result = cv_stability(X, y, [n_repeats=10], [cv_folds=5])

Input: X, y, n_repeats, cv_folds · Output: result

What it is

Repeats cross-validation n_repeats times (integer, default 10) with cv_folds folds each (integer, default 5) on an N-row X and length-N y, reshuffling between repeats.

How it works

cv_stability(X, y, [n_repeats=10], [cv_folds=5], [max_depth=3], [seed=], [kind="classification"]) — see cv_stability_scores's own doc comment. Returns the raw per-repeat CV scores; mean(...)/std(...) on the result gives the usual "performance +- variability" summary.
