isbanded

Builtin index · Core maths

isbanded(A, lower, upper)

Input: A, lower, upper · Output: no output

What it is

true when every nonzero of A lies within lower diagonals below and upper diagonals above the main diagonal, so isbanded(A, 0, 0) is isdiag(A) and isbanded(A, 1, 1) asks for tridiagonal. lower and upper are whole numbers >= 0; A may be rectangular. Errors: a missing, negative or non-integer bound.

Overloads

One call shape — this function is not overloaded.
