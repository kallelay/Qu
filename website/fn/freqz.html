freqz

Builtin index · Signal processing

result = freqz(filt, [n=512])

Input: filt, n · Output: result

What it is

filt: a Model (kind "filter"); n (optional number, default 512): number of frequency points.

Overloads

One call shape — this function is not overloaded.

CodeInputOutputDescription
result = freqz(filt, [n=512])
filt Modelfilt: a Model (kind "filter").
n number, optional (default 512)n (optional number, default 512): number of frequency points.
result vector or CVec
Returns a length-n complex vector (CVec), the response H(e^{jω}) at n points from DC to Nyquist inclusive. abs(freqz(filt)) is the magnitude response, angle(freqz(filt)) the phase. Pairs with linspace(0, fs/2, n) for the matching frequency axis.

Examples

From the documentation, and run by the build -- the output and the figure below are what the engine actually produced. Simplest first.

Fs = 2000
fc = 60
lp = butter(4, "low", fc, Fs)
H = freqz(lp, 512)
print(H)
mag_db = 20 * log10(abs(H))
i_fc = round(fc / (Fs / 2) * (length(H) - 1))
i_dc = 0
i_nyq = length(H) - 1
print("Gain at DC: {mag_db[i_dc]:.2f} dB")
print("Gain near cutoff ({fc} Hz): {mag_db[i_fc]:.2f} dB (expect close to -3 dB)")
print("Gain at Nyquist: {mag_db[i_nyq]:.2f} dB")

How it works

freqz(filt, [n=512]) — complex frequency response H(e^{jω}) at n points from DC to Nyquist inclusive (see numeric::filter::freqz's own doc comment for the exact convention). Pairs with linspace(0, fs/2, n) for the matching frequency axis, since Qu has no multi-return to hand both back from one call. abs(freqz(filt)) is the magnitude response, angle(freqz(filt)) the phase. For an FIR filter this is the simpler sum_k b[k]*e^{-jkω} direct evaluation — no denominator at all.
