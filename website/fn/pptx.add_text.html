pptx.add_text

Builtin index · File I/O

pptx.add_text(p, i, text, [x=], [y=], [w=100], [h=20], [size=], [bold=], [italic=], [color=], [font=], [align=])

Input: p, i, text, x, y, w, h, size, bold, italic, color, font, align · Output: no output

What it is

Adds a text box to slide i. Positions are millimetres from the top-left corner or lengths (20 mm); size in points. Newlines start new paragraphs.

Overloads

One call shape — this function is not overloaded.
