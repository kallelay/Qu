quantile_normalize

Builtin index · Statistics & ML

result = quantile_normalize(X)

Input: X · Output: result

What it is

Rank-based scaling of X (vector, matrix column-wise, or table per numeric column): each value is replaced by its rank against its own column, rescaled uniform onto [0, 1].

Overloads

One call shape — this function is not overloaded.

How it works

quantile_normalize(X) — each value replaced by its empirical-CDF rank against its own column, target distribution uniform on [0, 1] (sklearn QuantileTransformer's simpler, no-inverse-erf-needed option — see scaler::ColumnParams:: Quantile's doc comment for why).
