permutation_importance

Builtin index · Statistics & ML

result = permutation_importance(model, X, y, [n_repeats=])

Input: model, X, y, n_repeats · Output: result

What it is

Shuffles one column of an N-row, D-column X at a time and re-scores an already-fitted model Record model against the matching length-N target y, over n_repeats shuffles per column (integer).

Overloads

One call shape — this function is not overloaded.

How it works

permutation_importance(model, X, y, [n_repeats=10], [seed=]) — the standard model-agnostic explainability method (any fitted _model handle with .predict/.score — not just the tree-based kinds ablation_study/rfe/ astar_mrmr are restricted to, since this perturbs the *input*, never touches the model's own internals): shuffle one feature column at a time (breaking its relationship with y while leaving every other column's joint distribution untouched), re-score the already-fitted model, and average the score drop over n_repeats independent shuffles. A large drop means the model actually depends on that feature; ~0 or negative means it doesn't (or the shuffle got lucky). Genuinely single-threaded (each model_predict/model_score call needs &mut Interp, unlike ablation_study/cv_stability/rfe/astar_mrmr's direct-Rust TreeBuilder calls) — but each call is one cheap prediction pass, not a fit, so this doesn't need the same acceleration those do.
