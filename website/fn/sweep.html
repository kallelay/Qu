sweep

Builtin index · Plotting

result = sweep(f0, f1, fs, n, [method=])

Input: f0, f1, fs, n, method · Output: result

What it is

Generates a linear (or, with method="logarithmic", log) frequency sweep from f0 to f1 (numbers, Hz) sampled at rate fs (number, Hz) for n (integer) samples. chirp is the exact same call under a second name — both share one implementation.

Overloads

One call shape — this function is not overloaded.

How it works

chirp(f0, f1, fs, n, [method=]) (alias sweep) — a frequency sweep from f0 to f1 over n samples, reaching f1 exactly at the last sample (t = (n-1)/fs), MATLAB's own chirp convention. method="linear" (default) or "logarithmic"; see chirp_wave's own doc comment for the exact analytic-phase formulas (not a naive per-sample frequency-then-numerically-integrate approximation, which would accumulate phase error over a long sweep).
