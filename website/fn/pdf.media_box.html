pdf.media_box

Builtin index · File I/O

result = pdf.media_box(src, page)

Input: src, page · Output: result

What it is

The page's /MediaBox -- the boundary a PDF prints on, in PDF points (1/72 inch). page is a single page number. Resolves inheritance from an ancestor /Pages node when the page sets none of its own (the common case for a document where every page is the same size), the way a real reader does.

Overloads

One call shape — this function is not overloaded.
