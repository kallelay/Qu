DataFrame

Builtin index · Collections & strings

result = DataFrame(name=values, ...)

Input: name, ... · Output: result

What it is

Each named argument is a column: values is either a numeric Vec / List of Str (a real column) or a scalar number/Str (broadcast to every row). Builds a Table from the named columns, in the order the arguments were written; a scalar/string column broadcasts to the row count set by whichever columns are actual vectors, and vector columns must all agree in length.

Overloads

One call shape — this function is not overloaded.

How it works

table(name=values, ...) / DataFrame(...) — columns come straight from the call's named arguments, in the order they were written (that's why style is an ordered Vec, not a HashMap: table column order is part of a table's identity).
