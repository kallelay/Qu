fillna

Builtin index · Statistics & ML

fillna(x, value)

Input: x, value · Output: no output

What it is

Replaces every NaN (the missing-value marker) in a vector or matrix by value, leaving every other entry, inf included, untouched. For a matrix value is a single number or a vector with one number per column. A Signal keeps its Fs. For time series use fill_missing, which interpolates instead. Errors: a vector x with a vector value, a per-column value of the wrong length, complex input.

Overloads

One call shape — this function is not overloaded.

print("train accuracy: {round(m.score(Xf, yna), 3)}")
