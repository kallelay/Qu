histeq

Builtin index · Images

result = histeq(img) (alias of imequalize)

Input: img · Output: result

What it is

img is an Image of any size, color or grayscale. Global histogram equalization: builds a BT.601-luma cumulative distribution and remaps intensities to spread across the full range. RGB-preserving via luma-ratio remapping — not a grayscale-only fallback.

Overloads

One call shape — this function is not overloaded.

print(eq.width, eq2.width, noisy_g.width, noisy_sp.width)
