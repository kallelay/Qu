docx.add_toc

Builtin index · File I/O

docx.add_toc(doc, [levels=3], [at=], [title=])

Input: doc, levels, at, title · Output: no output

What it is

Inserts a table-of-contents field for heading levels 1 to levels, before body paragraph at (or at the end), optionally under a title paragraph. Qu does not lay out pages, so it does not invent entries: the field is marked dirty and the document asks Word to update fields on open. LibreOffice does not rebuild a TOC when it opens a .docx (so neither does docx.to_pdf): until someone updates it (Tools > Update > Update All), it shows a line saying so. *Added in v0.4.5*

Overloads

One call shape — this function is not overloaded.
