rank

Builtin index · Core maths

result = rank(A, tol=)

Input: A, tol · Output: result

What it is

Numerical rank of A (an r×c Mat or CMat) — the count of singular values clearing the tolerance. tol is an optional scalar, same default and convention as pinv's.

Overloads

One call shape — this function is not overloaded.

How it works

rank(A) — the numerical rank, the same SVD-based tolerance pinv already reports (a singular value counts once it clears eps * max(rows, cols) * largest_singular_value).
