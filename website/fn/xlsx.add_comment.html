xlsx.add_comment

Builtin index · File I/O

xlsx.add_comment(wb, sheet, cell, text, [author="Qu"])

Input: wb, sheet, cell, text, author · Output: no output

What it is

Attaches a note to a cell (the red corner; the text shows on hover). A second note on the same cell replaces the first. Written into the saved file as its own parts (comments + legacy drawing), so the sheet, its charts and everything else are untouched.

Overloads

One call shape — this function is not overloaded.
