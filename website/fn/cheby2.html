cheby2

Builtin index · Signal processing

result = cheby2(order, atten_db, kind, cutoff, fs)

Input: order, atten_db, kind, cutoff, fs · Output: result

What it is

order: number; atten_db: number (dB); kind: string; cutoff: number or length-2 vector (Hz); fs: number (Hz).

Overloads

cutoff can be number or vector.

How it works

cheby2(order, atten_db, kind, cutoff, fs) — designs a digital Chebyshev Type II (inverse Chebyshev) filter: monotonic in the passband, equiripple in the stopband (at least atten_db dB down starting at the stopband edge), flatter passband than Type I at the cost of a wider transition band. Same kind/cutoff/fs conventions as butter; cutoff is the point in the transition band where the attenuation first reaches atten_db (matching MATLAB's/ SciPy's own cheby2(n, Rs, Wn)), the stopband-edge convention (mirroring cheby1's passband-edge one). Model kind "filter", field sos — same shape as butter/ ellip/cheby1, so every generic filter function works on a cheby2 design with no changes at all.
