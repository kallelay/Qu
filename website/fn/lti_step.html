Builtin index · Signal processing

What it is

Returns a record {t, y, x}: the response from rest to a unit step applied at t = 0. t: an end time (a number), giving n evenly spaced samples from 0 for a continuous system or every multiple of dt for a discrete one, or the vector of sample times itself (increasing, not necessarily evenly spaced for a continuous system); input (optional): which input is stepped, for a system with several. y is a vector for one output and a len(t) x outputs matrix otherwise; x is the len(t) x states matrix of states. A continuous response is exact at every sample (matrix exponential, no ODE solver and no tolerance).

Examples

From the documentation, and run by the build -- the output and the figure below are what the engine actually produced. Simplest first.

plant = lti_tf([1], [1, 3, 2, 0])             # 1 / (s (s+1) (s+2))

m = lti_margin(plant)
print("{m.gm} at {m.w_gm} rad/s")             # 6 at 1.414214 rad/s

closed = lti_feedback(lti_series(2, plant))    # gain 2, unity negative feedback

print(lti_is_stable(closed))                   # true

r = lti_step(closed, 20)
print(r.y[len(r.y) - 1])                       # 1.006126

d = lti_c2d(lti_tf([1], [0.5, 1]), 0.1)        # first-order lag, tau = 0.5

print(d.A)                                     # [0.818731], exp(-0.1/0.5)
