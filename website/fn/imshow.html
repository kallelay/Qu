imshow

Builtin index · Images

imshow(img)

Input: img · Output: no output

What it is

img is an Image value (e.g. from load_image/grayscale/any transform below), of any size. Places it inline in the current plot panel as a native SVG <image> element at its own resolution. Takes an actual Image, not a scalar matrix — use imagesc for that.

Overloads

One call shape — this function is not overloaded.

How it works

imshow(img) — places a real Value::Image (actual loaded/ processed RGB pixels, not a colormap-mapped scalar grid — that's imagesc's job) inline in a plot, via a single native SVG <image> element (see plotting::image_ops).
