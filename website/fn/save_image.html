save_image

Builtin index · Images

save_image(path, img)

Input: path, img · Output: no output

What it is

path is a string destination; img is the Image to write. Encodes img and writes it to path, dispatching on the path's own extension: a .png extension writes a real (if uncompressed) PNG; any other extension, or none, writes a BMP.

Overloads

One call shape — this function is not overloaded.

# a symmetric test image would look identical afterwards.

n = 48

for i in 0 to n - 1
    for j in 0 to n - 1
        g[i, j] = 40 + 3 * j
        if i > 10 and i < 22 and j > 6 and j < 30
            g[i, j] = 240
        end if
    end for
end for
save_image("sample.bmp", image_from_matrix(g))

img = load_image("sample.bmp")
gray = grayscale(img)
imshow(gray)

from images

# Three bright discs on a dark field, written out and read back. The blob

# count printed below is then checkable against an image the reader can

# see being built, rather than asserted about a file nobody has.

n = 60
field = zeros(n, n)
centres = [15, 15; 42, 20; 30, 45]
for i in 0 to n - 1
    for j in 0 to n - 1
        for k in 0 to 2
            dy = i - centres[k, 0]
            dx = j - centres[k, 1]
            if dy * dy + dx * dx < 64
                field[i, j] = 230
            end if
        end for
    end for
end for
save_image("cells.bmp", image_from_matrix(field))

img = load_image("cells.bmp")
level = otsu_threshold(img)
mask = threshold(img, level)
clean = bwareaopen(mask, 20)          # drop specks smaller than 20 px

imshow(clean)

labeled = bwlabel(clean)
print(labeled.count)                  # number of detected blobs


stats = regionprops(labeled)
for i = 1 to labeled.count
    r = stats[i - 1]
    print(r.label, r.area, r.centroid_x, r.centroid_y)
end for

How it works

save_image(path, img) — dispatches on the path's extension: .bmp (default, including no/unknown extension, to match this builtin's original BMP-only behavior) uses image::encode_bmp; .png uses the real, spec-correct (if uncompressed) image::encode_png (BACKLOG.md item [25]'s PNG half — see that function's own doc for the hand-rolled DEFLATE-stored- block approach). This is raster-pixel-data export only, NOT savefig's full-figure export -- see save_figure's own .png rejection for that distinction.
