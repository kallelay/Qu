waterfall

Builtin index · Plotting

waterfall(x, Z)

Input: x, Z · Output: no output

What it is

x is a Vec of numbers (shared horizontal axis); Z is a Mat where each row becomes its own line, each successive row offset up-and-right so traces read back-to-front. A 2-D approximation of the stacked-trace look — no true 3-D projection yet.

Overloads

One call shape — this function is not overloaded.

How it works

waterfall(x, Z) -- one line per row of Z, each successive row offset up-and-right so traces read back-to-front. True 3D approximation of the classic stacked-trace look.
