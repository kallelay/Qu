polyval

Builtin index · Statistics & ML

result = polyval(coeffs, x)

Input: coeffs, x · Output: result

What it is

Evaluates a coefficient vector coeffs (as returned by polyfit, highest-degree first) at x, either a single number or a length-N vector, by Horner's method.

Overloads

One call shape — this function is not overloaded.

CodeInputOutputDescription

Returns a number or a length-N vector matching the shape of x.

Examples

From the documentation, and run by the build -- the output and the figure below are what the engine actually produced. Simplest first.

xs = -3 to 3 step 0.25
truth = 0.5 * xs .^ 3 - 2 * xs
noisy = truth + 1.5 * randn(len(xs), seed = 7)
c = polyfit(xs, noisy, 3)
print("polyfit coefficients (highest degree first): {round(c, 3)}")
scatter(xs, noisy, color = "#94a3b8", label = "measured")
plot(xs, polyval(c, xs), color = "#4169e1", width = 2, label = "cubic fit")
legend()
title("polyfit degree 3")
output
polyfit coefficients (highest degree first): [0.475, 0.039, -1.982, -0.056]

How it works

polyval(coeffs, x) -- Horner's method; x may be a scalar or vector. coeffs is highest-degree-first, matching polyfit.
