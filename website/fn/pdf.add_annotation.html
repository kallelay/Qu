pdf.add_annotation

Builtin index · File I/O

result = pdf.add_annotation(src, page, type=, rect=, text=, [color=])

Input: src, page, type, rect, text, color · Output: result

What it is

Adds a simple annotation to a page (page counts from 1). type= (Str) is written verbatim as the PDF /Subtype — this does not validate it against PDF's own list. rect= is [x0, y0, x1, y1]. text= (optional Str) becomes the annotation's /Contents. color= (optional [r, g, b], each 0 to 1) sets the annotation colour. The four text-markup types "Highlight", "Underline", "StrikeOut" and "Squiggly" are drawn from /QuadPoints, which Qu writes from rect= so they actually show (default colours yellow, green, red, red); a Highlight without them exists in the file but renders as nothing. "Text" (a note icon) and "Square" draw as written.

Overloads

One call shape — this function is not overloaded.
