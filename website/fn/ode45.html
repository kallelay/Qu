ode45

Builtin index · Signal processing

ode45(f, tspan, y0, [rtol=1e-6], [atol=1e-9], [max_step=], [t_eval=], [events=], [direction=0], [terminal=false], [max_steps=500000])

Input: f, tspan, y0, rtol, atol, max_step, t_eval, events, direction, terminal, max_steps · Output: no output

What it is

Dormand-Prince 5(4) with adaptive step size and the 4th-order continuous extension, for non-stiff problems. tspan = [t0, tf] (tf < t0 integrates backwards); a tspan with more than two entries means "report at exactly these times" and is the same as t_eval=, which must be strictly monotone and inside the span -- values between steps come from the interpolant, not from extra steps. The error per component is atol + rtol*

Overloads

One call shape — this function is not overloaded.

Examples

From the documentation, and run by the build -- the output and the figure below are what the engine actually produced. Simplest first.

function fall(t, y)
    return [y[1], -9.81]
end function

function ground(t, y)
    return y[0]
end function

t0 = 0
y0 = [5, 0]                      # dropped from 5 m

for k = 1 to 3
    r = ode45("fall", [t0, 100], y0, events="ground", direction=-1, terminal=true, rtol=1e-9)
    t0 = r.t_events[0]
    v = r.y_events[0, 1]
    print("bounce {k} at t = {t0}")   # 1.009638, 2.625058, 3.917394 (analytic: t1 = sqrt(2h/g), then + 2 * 0.8^k * t1)

    y0 = [0, -0.8 * v]           # restitution 0.8

end for
output
bounce 1 at t = 1.009638
bounce 2 at t = 2.625058
bounce 3 at t = 3.917394
