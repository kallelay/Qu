ui_text

Builtin index · Plotting

result = ui_text(label, [default], [id=])

Input: label, default, id · Output: result

What it is

Declares a free-text field, labeled label (string). default (string, positional, default "") and id= (string) as above.

Overloads

One call shape — this function is not overloaded.
