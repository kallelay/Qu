ctranspose

Builtin index · Core maths

result = ctranspose(A)

Input: A · Output: result

What it is

Conjugate transpose (Hermitian): transpose plus elementwise complex conjugation. A is a Vec/Mat/CMat; an r×c input returns a c×r output (real inputs behave exactly like transpose, since conjugation is a no-op on real numbers).

Overloads

One call shape — this function is not overloaded.

CodeInputOutputDescription

Returns a Mat, or a CMat for a complex input.

Examples

From the documentation, and run by the build -- the output and the figure below are what the engine actually produced. Simplest first.

A = [4, 1; 1, 3]
L = chol(A)
print(L * L.ctranspose())   # reproduces A


r = svd(A)
print(r.s)   # singular values
