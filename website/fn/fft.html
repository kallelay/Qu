fft

Builtin index · Signal processing

result = fft(x)

Input: x · Output: result

What it is

x: a length-N real or complex vector.

Overloads

One call shape — this function is not overloaded.

CodeInputOutputDescription
result = fft(x)
x vectornot documented yet
result vector or CVec
Returns a length-N complex vector (CVec), the discrete Fourier transform. abs gives magnitude, angle phase.

How it works

DFT: fft(x) or fft(x, n) (zero-pads/truncates to n samples). fftc is an explicit-complex alias of fft (same function).
