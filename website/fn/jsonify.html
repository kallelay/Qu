jsonify

Builtin index · File I/O

result = jsonify(value)

Input: value · Output: result

What it is

Converts any value (any Value — number, string, Vec, Table, Record, ...) to a JSON string — exactly the save/load on-disk shape (see the link above: a {"type": ..., ...} envelope), just returned as a string instead of written to a file.

Overloads

One call shape — this function is not overloaded.

CodeInputOutputDescription
result = jsonify(value)
value number, string, Vec, Table, or Recordnot documented yet
result string
Returns a string.

How it works

§ data-format conversion builtins (2026-09-01, Ahmed's ask — see BACKLOG.md's "Format conversion builtins" entry). Three formats (JSON/CSV/XML), each with a xify(value) -> str / parse_x(str) -> value primitive pair, plus six pairwise converters that are ONE-LINE compositions of those primitives — not six independent implementations. jsonify/parse_json expose value_to_json/json_to_value (just above/below this very arm — save/save_all/load's own machinery, never previously reachable as a plain string round trip) through serde_json::to_string/from_str; csvify/parse_csv string-based internally (read_csv/write_csv above are themselves thin file-I/O wrappers around exactly these two); mapping (see that module's own doc comment for the full design — the one genuinely new piece here, everything else is "expose what already exists").
