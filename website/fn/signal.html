signal

Builtin index · Plotting

result = signal(x, fs)

Input: x, fs · Output: result

What it is

Tags Vec x (numbers) with sample rate fs (number, Hz), so later calls (like rfft) do not have to be told it again.

Overloads

One call shape — this function is not overloaded.

CodeInputOutputDescription
