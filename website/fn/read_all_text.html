read_all_text

Builtin index · File I/O

result = read_all_text(path)

Input: path · Output: result

What it is

Reads path (string) in full.

Overloads

One call shape — this function is not overloaded.

CodeInputOutputDescription
result = read_all_text(path)
path stringnot documented yet
result string
Returns the whole file's content as one string. For splitting it into lines, open a handle with fopen and loop over read_line; for a file that isn't text, read it as raw bytes instead — read_bin(f, n) on a handle opened in binary mode, or read_array/mmap_read for typed/binary data.

How it works

read_all_text(path) (§ wait until / sleep, scoped 2026-08-26) — a one-shot convenience for the single most common file-I/O idiom, "read this whole text file into a string": exactly read_all(fopen(path, "r")), just without needing a two-call, explicit-handle dance for a case that never needed one (a text-mode fopen reads the whole file into memory immediately — see its own doc comment — and there is no lingering OS handle to close() either way). Implemented directly against std::fs::read + from_utf8_lossy (the exact same two steps fopen("r") and text-mode read_all each perform) rather than literally constructing and discarding a Value::File, so this has no behavior gap from the two-call form — same bytes read, same lossy UTF-8 decoding, same "could not read" error wording — just fewer moving parts for a case with nothing to configure (no mode, no binary option: text is the whole point).
