eps

Builtin index · Core maths

eps(), eps(x)

Input: no input · Output: no output

What it is

Machine epsilon: eps() is 2.220446049250313e-16, the gap between 1 and the next double, and eps(x) is the spacing of doubles at abs(x) (as MATLAB): eps(1) = 2^-52, eps(1e10) = 2^-19, eps(0) is the smallest subnormal 5e-324. x is a number, Vec or Mat, answered elementwise; NaN and infinite elements give NaN. eps is a function, not a bare constant like pi, because eps is one of the most common user variable names (a tolerance), and a bare constant would collide with programs that write eps = 1e-6. Call it with parentheses. Errors: complex or non-numeric x, more than one argument.

One call shape — this function is not overloaded.
