ica_model

Builtin index · Statistics & ML

ica_model(X, k, [max_iter=1000], [tol=1e-6], [seed=0])

Input: X, k, max_iter, tol, seed · Output: no output

What it is

Independent component analysis (FastICA, logcosh contrast, symmetric decorrelation) recovering k sources from the D mixed columns of X. Sources are defined only up to order, sign and scale -- that is the model -- and come back with unit variance. seed= fixes the starting rotation, so results repeat run to run. .transform(Xnew) returns the (M, k) sources; fields unmixing (k x D), mixing (D x k), mean, n_iter. Not converging is an error, not a silently rough answer. Added in v0.4.3.

Overloads

One call shape — this function is not overloaded.
