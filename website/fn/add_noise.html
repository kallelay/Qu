add_noise

Builtin index · Noise

result = add_noise(x, kind, [snr=], [amplitude=], [seed=])

Input: x, kind, snr, amplitude, seed · Output: result

What it is

Adds noise of the named kind (a string — see the kinds table near the top of this chapter) to x, a length-N number vector or an Image (noise is added per-pixel, per-channel). snr (named number, dB) or amplitude (named number, raw units) sets the level — give one or the other, never both; with neither, defaults to 20 dB. seed is a named integer for a reproducible draw, default 1.

Overloads

x can be string, number, vector, or Image; kind can be string, number, vector, or Image.

Examples

Written for this form and run by the build -- the output below is what the engine actually produced.

x = sin(2 * pi * 5 * (0 to 199) / 100)
g = add_noise(x, "gaussian", snr = 6, seed = 1)
untouched = 0
for i in 0 to 199
    if g[i] == x[i]
        untouched = untouched + 1
    end if
end for
print(untouched)   # 0 -- every sample was perturbed a little

Pink noise is worth a second look: it dominates at low frequencies, which is why a slow measurement is harder than a fast one and a long integration is not free.

Works on a vector and on an image alike — every kind is per-sample, so one function covers 1-D and 2-D rather than two that drift apart.
