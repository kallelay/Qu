codec.encode_wav

Builtin index · File I/O

result = codec.encode_wav(x, depth=, [dither=])

Input: x, depth, dither · Output: result

What it is

The same encoder as codec.write_wav, returning the file's bytes as a Vec of whole numbers 0-255 instead of writing them — the exact inverse of what codec.decode_wav accepts, so a stream can be re-encoded and passed on without ever touching disk. Same x, depth and dither arguments, and the same rule about naming dither at depth=16.

Overloads

One call shape — this function is not overloaded.
