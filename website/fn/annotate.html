annotate

Builtin index · Plotting

result = annotate(x, y, text)

Input: x, y, text · Output: result

What it is

Same as text — label text (string) at (x, y) (numbers, data units) — but also draws a marker dot at that point.

Overloads

One call shape — this function is not overloaded.

Returns a handle with the same properties as text.

Examples

From the documentation, and run by the build -- the output and the figure below are what the engine actually produced. Simplest first.

xs = linspace(0, 5, 400)
ys = sin(2 * pi * 1.2 * xs) .* exp(-0.3 * xs)
y_at_3 = sin(2 * pi * 1.2 * 3) * exp(-0.3 * 3)
plot(xs, ys)
vline(3, color="red")
annotate(3, y_at_3, "transient")
zoom_inset(2.8, 3.2, -0.1, 0.1, position="top right", outside=true)
print(y_at_3)
