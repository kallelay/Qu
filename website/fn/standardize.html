standardize

Builtin index · Statistics & ML

result = standardize(X)

Input: X · Output: result

What it is

z-score scaling of X (vector, matrix column-wise, or table per numeric column): (x - mean) / std.

Overloads

X can be Vec, Mat, or matrix.

3 forms. Each carries its own inputs, outputs and worked example — pick the tab for the one you are calling.

A plain Vec is standardized as a whole -- one mean, one std, across every element.

X Matnot documented yet

An N-row, D-column Mat is standardized column by column -- each column gets its own mean and std, independent of the others.

Examples

Written for this form and run by the build -- the output below is what the engine actually produced.

sm = [1.0, 100.0; 2.0, 200.0; 3.0, 300.0]
print("standardize on a matrix, per column: {round(standardize(sm), 3)}")
output
standardize on a matrix, per column: [-1, -1; 0, 0; 1, 1]

A table is standardized per numeric column, exactly like a matrix -- a non-numeric column (a label, say) passes through untouched instead of erroring.
