group_delay

Builtin index · Signal processing

result = group_delay(filt, [n=512])

Input: filt, n · Output: result

What it is

filt: a Model (kind "filter"); n (optional number, default 512).

Overloads

One call shape — this function is not overloaded.

CodeInputOutputDescription

result vector
Returns a length-n real vector, -dφ/dω in samples, same n-point/frequency-axis convention as freqz. For a linear-phase fir1 lowpass this is exactly constant at n_order/2 samples.

Examples

From the documentation, and run by the build -- the output and the figure below are what the engine actually produced. Simplest first.

fs = 1000
ep = ellip(4, 1, 40, "low", 100, fs)
c1 = cheby1(4, 1, "low", 100, fs)
c2 = cheby2(4, 40, "low", 100, fs)
print("ellip stable: {is_stable(ep)}, cheby1 stable: {is_stable(c1)}, cheby2 stable: {is_stable(c2)}")

fir = fir1(6, 100, kind="low", window="hamming", fs=fs)
b = fir.b
a = [1]
n = 0:1:255
t = n / fs
x = sin(2*pi*40*t) + sin(2*pi*300*t)
y  = filter_ba(b, a, x)
y2 = lfilter(b, a, x)               # lfilter is the same builtin under another name

print("filter_ba/lfilter agree: {max(abs(y - y2)) < 1e-12}")

lsq = firls(20, [0, 0.2, 0.3, 1.0], [1, 1, 0, 0])   # low-pass band edges/response

print("firls taps: {length(lsq.b)}")

gd = group_delay(fir, 256)
print("FIR group delay (should be ~order/2=3): {gd[10]}")
print("ellip filter has {length(poles(ep))} poles")

ep.fvtool()   # 2x2 magnitude/phase/group-delay/impulse-response figure

pzplot(ep)    # pole-zero plot with the unit circle and stability verdict

How it works

group_delay(filt, [n=512]) — -dφ/dω in samples, same n points/frequency-axis convention as freqz. For a fir1 lowpass (symmetric/linear-phase by construction) this is exactly constant at n_order/2 samples; computed the same unwrap-then-differentiate way as the IIR case rather than a closed-form shortcut, since that also handles a non-symmetric FIR correctly.
