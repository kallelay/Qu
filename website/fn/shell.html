shell

Builtin index · File I/O

result = shell(command, [style])

Input: command, style · Output: result

What it is

Hands command (a Str) to the OS shell and returns immediately, without waiting — Visual Basic's Shell, which is where the window styles come from too. style (an optional Str, positional or style=) is one of "normal" (the default), "hidden" (also spelled "ghost"), "minimized" or "maximized".

Overloads

One call shape — this function is not overloaded.
