dir_exists

Builtin index · File I/O

result = file_exists(path) / dir_exists(path)

Input: path · Output: result

What it is

Whether path (a Str) exists and is a regular file / a directory. A path that is not there at all is false, not an error — its absence is the answer you asked for.

Overloads

One call shape — this function is not overloaded.
