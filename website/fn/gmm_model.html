gmm_model

Builtin index · Statistics & ML

result = gmm_model(X, k, [seed=], [max_iter=100])

Input: X, k, seed, max_iter · Output: result

What it is

Gaussian mixture model with k components fitted by EM on an N-row, D-column matrix X, warm-started from a k-means run (optional integer seed=, and max_iter capping the EM iterations, default 100).

Overloads

One call shape — this function is not overloaded.

How it works

gmm_model(X, k, [seed=], [max_iter=]) — Gaussian Mixture Model fit via Expectation-Maximization. Warm-started from kmeans_fit's own hard partition (reusing its seed= convention) rather than a separate k-means++/random init, since a k-means solution is already a good starting guess for where the Gaussian components should sit and this avoids keeping a second, independent init scheme in sync. Each EM iteration's total log-likelihood is tracked in .log_likelihood (a real, checkable EM invariant — it never decreases) and the loop stops early once it stops improving, or after max_iter (default 100). .predict (Xnew) is the hard argmax-responsibility cluster assignment; .score(Xnew) is the total log-likelihood of Xnew under the fitted mixture — see gmm_evaluate's own doc comment for both.
