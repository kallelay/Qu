qda_model

Builtin index · Statistics & ML

qda_model(X, y, [reg=0])

Input: X, y, reg · Output: no output

What it is

Quadratic discriminant analysis: like lda_model but each class has its own covariance, so the boundaries are quadratic. A class whose covariance is singular (a constant feature, or fewer rows than features) is an error naming reg=, which shrinks each covariance's eigenvalues towards 1 ((1 - reg) * lambda + reg, reg in [0, 1]). .predict(Xnew) returns labels. Added in v0.4.3.

Overloads

One call shape — this function is not overloaded.
