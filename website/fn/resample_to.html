resample_to

Builtin index · Signal processing

result = resample_to(signal, new_fs)

Input: signal, new_fs · Output: result

What it is

signal: a length-N Signal (must carry a known Fs); new_fs: a number (Hz), the target sample rate.

Overloads

One call shape — this function is not overloaded.

CodeInputOutputDescription
result = resample_to(signal, new_fs)
signal Signalsignal: a length-N Signal (must carry a known Fs).
new_fs numbernew_fs: a number (Hz), the target sample rate.
result Signal or vector
Returns a new Signal at Fs=new_fs, whose length is whatever it takes to span the *same* start/end time as the input (generally not N). Real resampling, not a relabel: evaluates the signal's own piecewise-linear waveform (through its samples at their original instants i/Fs, via the same kernel interp1's "linear" method uses) at the new instants j/new_fs — e.g. a 4-sample, 1 Hz ramp [0,10,20,30] (spanning t=0..3s) resampled to 2 Hz becomes the 7-sample [0,5,10,15,20,25,30], still spanning t=0..3s — never a same-length signal with Fs merely swapped out (which would silently misstate the recorded duration). signal.resample_to(new_fs) also works, via the generic method-chain sugar. Wrap a plain vector first with signal(data, Fs) if it isn't already a Signal.

How it works

resample_to(signal, new_fs) — REAL resampling, not a relabel: evaluates the original signal's implied continuous waveform (piecewise-linear through its own samples at their original sample instants i/Fs) at the new sample instants j/new_fs, via the same linear-interpolation kernel interp1 already uses (interp1_linear) — reused rather than reimplemented. The new signal spans the SAME start/end time as the original (t=0 to t=(n-1)/Fs), just resampled onto a different-density grid — e.g. a 4-sample signal at 1 Hz ([0,10,20,30], spanning t=0..3s) resampled to 2 Hz becomes the 7-sample [0,5,10,15,20,25,30] spanning the same t=0..3s, not a 4-sample signal relabeled to claim 2 Hz (which would silently claim a 1.5s duration for data that was actually recorded over 3s). Functional/pure like every other Qu builtin (no in-place Fs mutation exists to abuse here anyway — expr.field = value doesn't parse).
