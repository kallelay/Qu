palette

Builtin index · Plotting

result = palette(n, [saturation=, value=, start=])

Input: n, saturation · Output: result

What it is

Generates n (integer) categorical colours of equal perceptual weight by walking hue at fixed saturation/value. saturation= (default 0.62) and value= (default 0.78) are numbers 0–1; start= (default 215, degrees) is the first colour's hue.

Overloads

One call shape — this function is not overloaded.

How it works

palette(n) — n colours that carry equal weight, by walking the hue at fixed saturation and value. The thing HSV is for, and the reason a categorical palette generated in RGB always has one colour that shouts.
