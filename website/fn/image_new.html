image_new

Builtin index · Images

result = image_new(width, height, [r=0, g=0, b=0])

Input: width, height, r · Output: result

What it is

Creates a blank solid-color canvas. width and height are positive integers giving the canvas size in pixels. r, g, b are optional named numbers 0–255 giving the fill color's channel values (default 0, i.e. solid black).

Overloads

One call shape — this function is not overloaded.

How it works

image_new(width, height, [r=0, g=0, b=0]) — a blank solid- color canvas; the constructor load_image's round trip otherwise has no Qu-level counterpart for (there's no Image literal syntax, matching zeros/ones filling the same gap for matrices). Lets a script build and test a synthetic image entirely in Qu, with no external file needed.
