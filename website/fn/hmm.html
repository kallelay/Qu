hmm

Builtin index · Statistics & ML

result = hmm(transition, emission, initial)

Input: transition, emission, initial · Output: result

What it is

Builds a discrete hidden Markov model from an (S, S) row-stochastic hidden-state transition matrix transition, an (S, O) row-stochastic emission matrix emission (O the number of observable symbols), and a length-S initial-state distribution initial.

Overloads

One call shape — this function is not overloaded.

How it works

hmm(transition, emission, initial) — a standard discrete Hidden Markov Model: transition is an (n,n) row-stochastic state-transition matrix (same contract as markov_chain's own P), emission is an (n,m) row-stochastic matrix (state i's distribution over the m observable symbols), and initial is the length-n starting state distribution. See hmm_forward/hmm_viterbi's own doc comments for the two algorithms this feeds (.forward(obs) / .viterbi(obs), both callable as methods via the existing recv.f(args) sugar). Baum-Welch (parameter re-estimation from unlabeled observations) is NOT implemented — scoped out to keep forward/ Viterbi correct and hand-verified rather than rushing a third, harder-to-verify algorithm into the same pass.
