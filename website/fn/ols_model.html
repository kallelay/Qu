ols_model

Builtin index · Statistics & ML

result = ols_model(X, y)

Input: X, y · Output: result

What it is

Fits ordinary least squares with an automatic intercept on an N-row, D-column feature matrix X and a length-N target vector y.

Overloads

One call shape — this function is not overloaded.

Examples

From the documentation, and run by the build -- the output and the figure below are what the engine actually produced. Simplest first.

X = [1, 2, 3, 4, 5, 6, 7, 8] as matrix(4, 2)
y = [3.1, 5.2, 7.1, 9.3]

m = ols_model(X, y)          # ordinary least squares, automatic intercept

print("coefficients {m.coef}")
print("intercept    {m.intercept:.4f}")
print("R^2          {m.score(X, y):.4f}")
output

How it works

The model protocol (spec §37.2): a fitted estimator is a Value::Model handle with named read-only fields plus predict/score via method-call sugar. These _model- suffixed constructors sit alongside (not instead of) the pre-existing one-shot ridge/kmeans/pca, since those already have their own tests/docs/notebooks depending on their current return shape. ols_model(X, y) — ordinary least squares with an automatic intercept: X/y are mean-centered, the slope is fit on the centered data, and intercept = mean(y) - colmeans(X)·coef recovers the uncentered line — the standard fit_intercept=True convention, distinct from ridge's own "no intercept, append a ones column yourself" contract.

From the note above this builtin in the interpreter, where the reasoning was written down as it was built.
