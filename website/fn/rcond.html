rcond

Builtin index · Core maths

rcond(A)

Input: A · Output: no output

What it is

Reciprocal condition number of a square matrix in the 1-norm, 1 / (norm(A, 1) * norm(inv(A), 1)), between 0 (singular) and 1 (perfectly conditioned, rcond(eye(n)) = 1), the quantity LAPACK's gecon estimates. Up to 300 rows it is exact: the inverse is formed from an LU factorisation and its 1-norm taken, so the result equals the formula to the rounding of that inverse (which is itself poor when rcond is near eps). Above 300 rows it runs the Hager / Higham 1-norm estimator (a few triangular solves with A and its transpose instead of an O(n^3) inverse), which never overestimates norm(inv(A), 1); on 60 random matrices and two Hilbert matrices the estimate was within a factor of 3 of the exact value (the test suite checks this), so the rcond it returns is at most 3 times too large. A matrix with an exactly zero LU pivot (or all zeros) returns 0; a numerically but not exactly singular one returns a tiny positive number, as LAPACK does. Errors: a non-square, empty or non-finite matrix, complex input.

Overloads

One call shape — this function is not overloaded.
