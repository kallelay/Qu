toeplitz

Builtin index · Core maths

toeplitz(c, [r])

Input: c, r · Output: no output

What it is

Toeplitz matrix with first column c and first row r (real Vecs), a length(c)×length(r) Mat with constant diagonals; without r it is the symmetric Toeplitz matrix of c. If r[0] differs from c[0], c[0] wins. Errors: an empty vector, complex input.

Overloads

One call shape — this function is not overloaded.
