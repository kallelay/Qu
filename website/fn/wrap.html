How it works

wrap(x, [lo=-pi], [hi=pi]) — wraps each value of x into the half-open interval [lo, hi) by modular arithmetic, the standard operation for angle/phase data that has accumulated past a full turn (atan2 output, an integrated angular velocity, a raw X.phase() before unwrapping). Defaults to [-pi, pi), the convention atan2/angle already return in, so wrap(angle(z)) round-trips with no arguments. rem_euclid rather than %: Rust's % can return a negative remainder for a negative x - lo, which is exactly the case (x below lo) this function exists to fix.
