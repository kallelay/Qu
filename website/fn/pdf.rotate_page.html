pdf.rotate_page

Builtin index · File I/O

result = pdf.rotate_page(src, page, degrees)

Input: src, page, degrees · Output: result

What it is

Sets a page's /Rotate -- degrees a viewer turns the page CLOCKWISE before display. degrees is added to whatever rotation the page already has (its own, or inherited), so calling this twice with 90 turns a page 180° total; must be a multiple of 90, refused by name otherwise. Result is normalized into 0..360.

Overloads

One call shape — this function is not overloaded.
