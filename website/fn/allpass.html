allpass

Builtin index · Signal processing

result = allpass(f0, q, fs)

Input: f0, q, fs · Output: result

What it is

f0: number (Hz, between 0 and fs/2); q: number (above 0); fs: number (Hz).

Overloads

One call shape — this function is not overloaded.

Model —kind "filter", field sos, one section
Returns a Model (kind "filter", field sos, one section). A second-order allpass: gain 1 at every frequency, phase falling from 0 to -360 degrees and passing -180 degrees at f0; a higher q makes the transition sharper.
