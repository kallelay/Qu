confusion_matrix

Builtin index · Statistics & ML

confusion_matrix(actual, predicted, [n_classes])

Input: actual, predicted, n_classes · Output: no output

What it is

Draws a confusion-matrix heatmap comparing a length-N vector of true labels actual against a length-N vector of predicted labels predicted, over an optional integer n_classes (inferred from the data if omitted). This is a plotting side effect, not a computed matrix handed back to the caller.

Overloads

One call shape — this function is not overloaded.

How it works

confusion_matrix(actual, predicted, [n_classes]) — integer class labels assumed 0-based; n_classes defaults to the largest label seen, plus one.
