corr

Builtin index · Statistics & ML

result = corr(x, y)

Input: x, y · Output: result

What it is

Pearson correlation between two length-N numeric vectors x and y.

Overloads

One call shape — this function is not overloaded.

CodeInputOutputDescription
result = corr(x, y)
x vectornot documented yet
y vectornot documented yet
result number
Returns one number in [-1, 1]. xcorr is the lag-by-lag version.

Examples

From the documentation, and run by the build -- the output and the figure below are what the engine actually produced. Simplest first.

  r = corr([1,2,3,4,5], [2,1,4,3,5])   # 0.8

from numerics-dsp

N = 200
Fs = 200
t = (0 to N - 1) / Fs
x = sin(2*pi*10*t)
shift = 15
y = zeros(N)
y[shift:N-1] = x[0:N-1-shift]

c = corr(x, x)
print("corr(x, x) = {c}")
c2 = corr(x, y)
print("corr(x, y) (shifted copy) = {c2:.4f}")

r = xcorr(x, y)
print("length(xcorr) = {length(r)} (expect 2N-1 = {2*N-1})")
zero_lag_idx = N - 1
best_idx = where r == max(r)
best_lag = best_idx[0] - zero_lag_idx
print("Best-match lag (samples): {best_lag} (true shift was {shift})")

from tour

a = randn(200, seed = 11)

How it works

corr(x, y) — Pearson correlation coefficient. Distinct from xcorr (a full lag-by-lag correlation *vector*): this is the single zero-lag, normalized-to-[-1,1] scalar summary.
