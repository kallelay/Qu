is_stable

Builtin index · Signal processing

result = is_stable(filt)

Input: filt · Output: result

What it is

filt: a Model (kind "filter").

Overloads

One call shape — this function is not overloaded.

CodeInputOutputDescription
result = is_stable(filt)
filt Modelnot documented yet
result boolean
Returns a boolean, true iff every pole lies strictly inside the unit circle — the standard causal-LTI stability criterion. An FIR filter (poles at the origin) is always stable.

Examples

From the documentation, and run by the build -- the output and the figure below are what the engine actually produced. Simplest first.

fs     = 1000
t      = (0 to 999) / fs
signal = sin(2 * pi * 50 * t) + 0.5 * sin(2 * pi * 220 * t) + 0.1 * randn(1000, seed = 2)
lp = butter(4, "low", 100, fs)             # 4th-order lowpass, 100 Hz cutoff

notch = butter(2, "notch", [45, 55], fs)   # removes 45-55 Hz mains hum


filtered = sosfilt(lp, signal)             # causal, one pass

zero_phase = filtfilt(lp, signal)          # zero-phase, double effective order

print("lp is stable: {is_stable(lp)}, notch is stable: {is_stable(notch)}")

H = freqz(lp, 512)
plot(linspace(0, fs/2, 512), mag2db(abs(H)))
output
lp is stable: true, notch is stable: true
· plot: figure 3 (512 points)

How it works

is_stable(filt) — true iff every pole lies strictly inside the unit circle, the standard causal-LTI stability criterion. An FIR filter (all poles at the origin) is always stable, which falls out of this one general definition automatically rather than needing a special case.
