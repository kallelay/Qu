append

Builtin index · Collections & strings

result = append(collection, value)

Input: collection, value · Output: result

What it is

collection is a Vec or List; value is the element to add.

Overloads

One call shape — this function is not overloaded.

CodeInputOutputDescription
result = append(collection, value)
collection Vec or Listcollection is a Vec or List.
value —value is the element to add.
result Vec or List
Returns a NEW Vec/List with value added at the end.

Examples

From the documentation, and run by the build -- the output and the figure below are what the engine actually produced. Simplest first.

acc = ()
for i = 1 to 6
    acc = append(acc, i * i)
end for
print(acc)          # (1, 4, 9, 16, 25, 36)

print(len(acc))     # 6
output
(1, 4, 9, 16, 25, 36)

How it works

append(collection, value) — returns a NEW list/vector with value added at the end; the natural companion to insert/remove, same immutable-return convention.
