docx.add_image

Builtin index · File I/O

docx.add_image(doc, path, [width=], [height=])

Input: doc, path, width, height · Output: no output

What it is

Appends a PNG, JPEG or GIF as its own paragraph. width/height are millimetres or lengths (6 cm); give one and the other follows the aspect ratio, neither and it is placed at 96 dpi capped to the text width.

Overloads

One call shape — this function is not overloaded.
