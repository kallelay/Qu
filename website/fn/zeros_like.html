zeros_like

Builtin index · Core maths

result = zeros_like(x)

Input: x · Output: result

What it is

A vector or matrix of the same shape as x (a Vec or Mat), filled with one or zero respectively — the shape is read directly from x, so it cannot fall out of step with it.

Overloads

One call shape — this function is not overloaded.

CodeInputOutputDescription

Returns the same type and shape as x.
