write_report

Builtin index · File I/O

write_report(path)

Input: path · Output: no output

What it is

Writes a standalone HTML report to path (string) — every figure, table, and printed line the script has produced up to this point in execution, bundled into one file with nothing linked from outside it.

Overloads

One call shape — this function is not overloaded.

Examples

From the documentation, and run by the build -- the output and the figure below are what the engine actually produced. Simplest first.

x = 1:10
print("sum = " + str(sum(x)))
write_report("summary.html")
print(file_exists("summary.html"))       # true
