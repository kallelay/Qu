seek

Builtin index · File I/O

seek(f, offset, [whence="start"])

Input: f, offset, whence · Output: no output

What it is

Moves f's (file handle, opened readable) read cursor. offset (number, byte count) is the distance to move. whence (string, optional, default "start") is "start", "current", or "end", matching C's fseek — the point offset is measured from.

Overloads

One call shape — this function is not overloaded.
