ridge_model

Builtin index · Statistics & ML

result = ridge_model(X, y, alpha)

Input: X, y, alpha · Output: result

What it is

The same fit as ols_model on an N-row, D-column X and a length-N y, but with L2 regularization strength alpha (a non-negative number) shrinking the coefficients toward zero; ols_model is this at alpha = 0.

Overloads

One call shape — this function is not overloaded.

How it works

ridge_model(X, y, alpha) — ols_model plus L2 regularization on the centered design, the model-protocol sibling of the flat ridge builtin (which has no automatic intercept).
