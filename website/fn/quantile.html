quantile

Builtin index · Core maths

result = quantile(x, q)

Input: x, q · Output: result

What it is

Linear-interpolation quantile (NumPy's default interpolation="linear" method). x is a scalar, Vec, or Mat/Signal (flattened); q is a scalar rank in [0, 1] (0.5 is the median), interpolated between the two nearest order statistics when it doesn't land exactly on one.

Overloads

One call shape — this function is not overloaded.
