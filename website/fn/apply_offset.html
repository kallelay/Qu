apply_offset

Builtin index · Signal processing

apply_offset(s, b)

Input: s, b · Output: no output

What it is

Added in v0.2.4. Adds a constant to every sample (a DC trim, a tare), composed into the calibration record like any other linear step.

Overloads

One call shape — this function is not overloaded.
