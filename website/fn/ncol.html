ncol

Builtin index · Collections & strings

result = ncol(df)

Input: df · Output: result

What it is

df is a Table.

Overloads

One call shape — this function is not overloaded.

CodeInputOutputDescription
result = ncol(df)
df Tablenot documented yet
result number
Returns a number: the column count. df.ncols is property-style sugar for this — see below.

How it works

nrow/ncol answer for anything shape answers for, and they answer it by ASKING shape -- nrow(x) is shape(x)[0] by construction, so the two cannot drift. They used to take a table and nothing else, which made nrow(m) on a matrix -- the obvious spelling -- an error naming tables. The duplication was already flagged in shape_of's own comment, which notes that rows/cols "must return exactly the same values the dedicated nrow/ncol match arms compute": two places computing one answer, kept in step by hand. shape_of returns None for a value with no shape rather than the old silent (0, 0), so these refuse instead of reporting zero rows for a function.

From the note above this builtin in the interpreter, where the reasoning was written down as it was built.
