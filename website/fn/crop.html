crop

Builtin index · Images

result = crop(img, x0, y0, width, height)

Input: img, x0, y0, width, height · Output: result

What it is

img is an Image; x0, y0 are integers giving the top-left pixel coordinate of the sub-rectangle; width/height are positive integers giving its size in pixels. Extracts that sub-rectangle.

Overloads

One call shape — this function is not overloaded.
