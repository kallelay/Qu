conv

Builtin index · Signal processing

result = conv(x, h, [mode="full"])

Input: x, h, mode · Output: result

What it is

x is a length-N vector, h a length-M vector (the kernel/impulse response). mode (optional string) follows MATLAB's conv/NumPy's convolve naming: "full" (default, length N+M-1, every nonzero-overlap sample), "same" (length N, the middle samples aligned with the input), "valid" (length max(N,M)-min(N,M)+1, only where h fully overlaps x).

How it works

conv(x, h, [mode="full"]) — discrete convolution. mode follows MATLAB's conv/NumPy's convolve naming: "full" (default, every nonzero-overlap sample), "same" (the middle length(x) samples, aligned with the input — the usual choice for filtering in place), "valid" (only where h fully overlaps x).
