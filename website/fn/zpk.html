Builtin index · Signal processing

Input: filt · Output: result

What it is

filt: a Model (kind "filter").

Overloads

One call shape — this function is not overloaded.

CodeInputOutputDescription
result = zpk(filt)
filt Modelnot documented yet
result vector
Returns a record {z, p, k}: zeros and poles as complex vectors and the gain, for H(z) = k * prod(z - z_i) / prod(z - p_i). Zero/pole pairs at the origin that cancel are left out. The inverse of filter_from_zpk.
