xlsx.fill_formula

Builtin index · File I/O

result = xlsx.fill_formula(wb, sheet, range, formula)

Input: wb, sheet, range, formula · Output: result

What it is

Stores formula in every cell of range, shifting its relative references from the range's first cell the way Excel's fill-down does ($-anchored parts, string literals and quoted sheet names stay).

Overloads

One call shape — this function is not overloaded.
