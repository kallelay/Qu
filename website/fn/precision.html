precision

Builtin index · Statistics & ML

result = f1(actual, predicted)

Input: actual, predicted · Output: result

What it is

Classification metrics on a length-N vector of true labels actual and a length-N vector of predicted labels predicted, each returning a single number macro-averaged over every class present (the per-class score averaged with equal weight, regardless of how many examples that class has), so the same call works on binary and multi-class labels alike.

Overloads

One call shape — this function is not overloaded.

How it works

precision(actual, predicted) / recall(actual, predicted) / f1(actual, predicted) — macro-averaged (sklearn's own average="macro": compute each metric per class, then take the plain mean across classes) rather than requiring a pos_label=/binary-only convention, so the same three builtins work unchanged whether actual/predicted are a binary 0/1 classification or tree_model/random_forest_ model/knn_model's multi-class kind="classification" output. confusion_matrix (above) renders a heatmap, not a reusable count structure — these three share their own per-class tp/fp/fn tally (classification_prf_macro) instead of depending on it.
