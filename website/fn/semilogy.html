semilogy

Builtin index · Plotting

semilogy(x, y)

Input: x, y · Output: no output

What it is

Plots equal-length numeric Vecs x, y like plot and additionally sets the y-axis to log scale.

Overloads

One call shape — this function is not overloaded.
