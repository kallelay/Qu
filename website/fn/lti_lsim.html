Returns a record {t, y, x}: the response to the input u sampled at times t, starting from state x0. u: a vector with one value per time sample, or a len(t) x inputs matrix for a system with several inputs; t: increasing sample times; x0 (optional vector, also x0=, default zero): the initial state; method: what a continuous system's input does between samples, "foh" (linear, the default) or "zoh" (constant). For a continuous system the samples are the exact solution for that input (augmented matrix exponential), and t need not be evenly spaced. A discrete system is advanced by its difference equation; t must step by its dt and method is not used. y and x as in lti_step.
