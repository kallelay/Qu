ode23

Builtin index · Signal processing

ode23(f, tspan, y0, [rtol=1e-6], [atol=1e-9], [max_step=], [t_eval=], [events=], [terminal=false], [max_steps=500000])

Input: f, tspan, y0, rtol, atol, max_step, t_eval, events, terminal, max_steps · Output: no output

What it is

Bogacki-Shampine 3(2), the cheaper low-order pair: better than ode45 at loose tolerances or when f is not smooth. Same arguments, result record and events as ode45; t_eval values come from a cubic Hermite interpolant.

Overloads

One call shape — this function is not overloaded.
