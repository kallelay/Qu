kmeans

Builtin index · Statistics & ML

result = kmeans(X, k, [seed=])

Input: X, k, seed · Output: result

What it is

Lloyd's algorithm on an N-row, D-column data matrix X, partitioning it into the integer number of clusters k, starting from randomly chosen initial centroids (an optional integer seed= fixes the draw).

Overloads

One call shape — this function is not overloaded.

Returns a length-N vector of integer cluster labels in 0..k-1, one per row of X.

Examples

From the documentation, and run by the build -- the output and the figure below are what the engine actually produced. Simplest first.

G = vstack(randn(40, 2, seed = 31) + 4,
           randn(40, 2, seed = 32) - 4,
           randn(40, 2, seed = 33))
labels = kmeans(G, 3, seed = 5)
centers = kmeans_centers(G, 3, seed = 5)
xs = G[:, 0]
ys = G[:, 1]
for k in 0 to 2
    inside = labels == k
    print("cluster {k}: {len(xs[inside])} points")
    scatter(xs[inside], ys[inside], label = "cluster {k}")
end for
scatter(centers[:, 0], centers[:, 1], marker = "x", color = "#0f172a", size = 12, label = "centroids")
legend()
title("kmeans, k = 3")

How it works

kmeans(X, k, seed=0) — Lloyd's algorithm with random (not k-means++) initial centroids, for a simple, deterministic first cut; returns just the cluster label per row (0..k-1) — kmeans_centers reruns the same deterministic computation (same seed => same result) to hand back the centroid matrix, since Qu has no tuple/multi-return value to carry both back from one call, and cheaply recomputing beats inventing one.

From the note above this builtin in the interpreter, where the reasoning was written down as it was built.
