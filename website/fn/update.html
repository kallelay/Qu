update

Builtin index · Statistics & ML

result = state.update(...)

Input: ... · Output: result

What it is

Estimation-family only: the measurement-update half of a filter, called on a state Record state with filter-specific arguments (an observation matrix/function, a measurement vector, and a noise covariance, see the Estimation section below).

Overloads

One call shape — this function is not overloaded.

CodeInputOutputDescription
result = state.update(...)
... Record, matrix, or vector, repeatablenot documented yet
result Record
Returns a new filter state Record; nothing is mutated in place.

How it works

update(state, ...) — callable as state.update(...). The estimation-theory family's measurement update; see estimation_update's own doc comment for the full contract. No non-estimation model currently has an update operation, so this dispatches on kind unconditionally rather than falling back to anything else.

From the note above this builtin in the interpreter, where the reasoning was written down as it was built.
