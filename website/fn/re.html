re

Builtin index · Core maths

result = re(x)

Input: x · Output: result

What it is

Real component of a Complex/CVec/CMat (identity — x passed through unchanged — when x is already real). x is a scalar, Vec, or Mat (real or complex).

Overloads

x can be scalar, Vec, Mat, or Complex.
