load

Builtin index · File I/O

load(path)

Input: path · Output: no output

What it is

Restores every variable a save/save_all call wrote. path (string) is the file to read.

Overloads

One call shape — this function is not overloaded.

How it works

load(path) — restore every variable a save/save_all call wrote, under the same names, into the top-level workspace (overwriting any existing variable of the same name, the same "load replaces" semantics MATLAB's own load has).
