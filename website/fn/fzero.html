fzero

Builtin index · Signal processing

result = fzero(f, a, b, [tol=1e-10], [max_iter=100])

Input: f, a, b, tol, max_iter · Output: result

What it is

f: a string naming a user-defined function of one number, returning a number; a, b: numbers, the bracket endpoints where f changes sign; tol/max_iter (optional numbers).

Overloads

One call shape — this function is not overloaded.

Returns a single number, the root. Brent's method: robust root finding given a bracket [a,b], no derivative needed.
