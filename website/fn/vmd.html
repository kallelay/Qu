vmd

Builtin index · Signal processing

result = vmd(x, k, [alpha=2000])

Input: x, k, alpha · Output: result

What it is

x: a length-N real vector; k (number, integer): the exact number of modes to extract; alpha (optional number): bandwidth-penalty strength. Variational Mode Decomposition: decomposes x into exactly k band-limited modes by minimizing each mode's bandwidth around its own center frequency, solved by ADMM (not sifting, unlike emd).

Overloads

How it works

vmd(x, k, [alpha=2000]) — Variational Mode Decomposition: decomposes x into exactly k band-limited modes by minimizing each mode's bandwidth around its own center frequency, solved by ADMM (not sifting, unlike emd). Model kind "vmd", fields modes (a matrix, one mode per row) and center_freqs (each mode's converged center frequency, normalized to cycles/sample — 0.5 is Nyquist).
