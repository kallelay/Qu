docx.page_setup

Builtin index · File I/O

docx.page_setup(doc, [section=], [size=], [orientation=], [margins=], [top=], [bottom=], [left=], [right=])

Input: doc, section, size, orientation, margins, top, bottom, left, right · Output: no output

What it is

Changes page size ("A4", "A3", "A5", "B5", "Letter", "Legal", or [width, height]), orientation ("portrait"/"landscape", which swaps width and height) and margins (millimetres or lengths; margins sets all four, the others override it) -- of section section (0-based), or of every section when omitted. *Added in v0.4.5*

Overloads

One call shape — this function is not overloaded.
