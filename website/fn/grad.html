grad

Builtin index · REPL & diagnostics

grad(loss, wrt=X) or grad(loss, X, Y, ...)

Input: loss, wrt · Output: no output

What it is

Takes loss — a tracked scalar that is the result of a computation built from tracked inputs — plus either a keyword argument wrt=X (one tracked tensor X) or one or more positional tracked tensors X, Y, .... Runs the backprop walk over the tape. The keyword form wrt=X returns a single gradient value with the same shape as X (a number for a scalar X, a matrix for a matrix X); the positional form grad(loss, X, Y, ...) returns a List of such gradients, one per argument, in the same order (positional rather than wrt=[X, Y], because Qu's [...] bracket literal is numeric-matrix syntax and would silently flatten a list of tensors down to plain numbers, losing the node identity grad needs).

Overloads

2 forms. Each carries its own inputs, outputs and worked example — pick the tab for the one you are calling.

How it works

grad(loss, wrt=X) / grad(loss, wrt=[X, ...]) — see Interp::eval_grad's own doc comment for the backprop walk. grad(loss, wrt=X) differentiates against one tensor; grad(loss, X, Y, ...) (multiple *positional* tensors after loss) differentiates against all of them at once, returning a Value::List of gradients in the same order — the positional form rather than wrt=[X, Y] because Qu's [...] bracket literal is numeric-matrix syntax (see block_to_value) and would silently flatten a list of Tensors down to their plain numbers, losing exactly the node identity grad needs.

From the note above this builtin in the interpreter, where the reasoning was written down as it was built.
