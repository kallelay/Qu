least_squares

Builtin index · Core maths

result = least_squares("f", x0, lower=, upper=, max_iter=200, tol=1e-10)

Input: "f", x0, lower, upper, max_iter, tol · Output: result

What it is

Nonlinear least squares on a residual function you named, via Levenberg-Marquardt. "f" is a Str naming an already-defined function that takes a length-p parameter Vec and returns a residual Vec; x0 is the length-p initial guess Vec. lower=/upper= are optional length-p Vecs of box bounds (enforced by clamping every trial point before it is evaluated, rather than by penalty); max_iter= (default 200) caps the iteration count, tol= (default 1e-10) sets the convergence tolerance.

Overloads

One call shape — this function is not overloaded.

Examples

From the documentation, and run by the build -- the output and the figure below are what the engine actually produced. Simplest first.

bounded = least_squares("resid", [1.0, 1.0], lower = [0.0, 0.01])
print("bounded tau {bounded.params[1]:.4f}")
output
bounded tau 0.3502

from from-zero

tau   = 0.35
decay = 2.5 * exp(0 - t / tau) + 0.02 * randn(1000, seed = 2)

function resid(p)
    return p[0] * exp(0 - t / p[1]) - decay
end function

fit = least_squares("resid", [1.0, 1.0])
print("amplitude {fit.params[0]:.4f} (true 2.5)")
print("tau       {fit.params[1]:.4f} (true {tau})")
output
amplitude 2.4990 (true 2.5)
tau       0.3502 (true 0.35)

How it works

least_squares(f, x0, [lower=], [upper=], [max_iter=], [tol=]) — nonlinear least squares on a RESIDUAL function. f(p) returns the vector to be driven toward zero, not a scalar and not a model evaluated against data. That is the contract curve_fit does not have and the one every fit in this lab needs: a weighting, a Kramers-Kronig penalty or a regularization term is just more entries in the residual. lower=/upper= are box bounds, enforced by clamping every trial point into the box before it is evaluated -- a negative capacitance evaluated once can put NaN through the whole residual, so the bound has to hold at evaluation time, not just at the solution.
