upper

Builtin index · Collections & strings

result = upper(s)

Input: s · Output: result

What it is

s is a Str. Unicode-aware uppercase conversion.

Overloads

One call shape — this function is not overloaded.

CodeInputOutputDescription
result = upper(s)
s Strnot documented yet
result Str
Returns a Str the same length (in characters).

Examples

From the documentation, and run by the build -- the output and the figure below are what the engine actually produced. Simplest first.

s = "  Measurement Lane  "
print("[{trim(s)}]")              # [Measurement Lane]

print(upper(trim(s)))             # MEASUREMENT LANE

print(contains(s, "Lane"))        # true

print(replace(s, "Lane", "Window"))
