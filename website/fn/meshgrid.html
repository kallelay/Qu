meshgrid

Builtin index · Core maths

result = meshgrid(x, y)

Input: x, y · Output: result

What it is

The two coordinate matrices a surface or contour needs, from two axis vectors x (length nx) and y (length ny).

Overloads

One call shape — this function is not overloaded.

CodeInputOutputDescription
result = meshgrid(x, y)
x vectornot documented yet
y vectornot documented yet
result Record, Mat, or vector
Returns a Record with fields x and y, each an ny×nx Mat: .x repeats the x vector down every row, .y repeats the y vector across every column, so (.x[j,i], .y[j,i]) is the grid point for x[i], y[j].

How it works

meshgrid(x, y) -- the two coordinate matrices MATLAB and NumPy build before evaluating a field over a grid. Returned as a record with .x and .y rather than as two values, because Qu has no multi-return destructuring; it is the same shape eig already uses for its two outputs. Both matrices are y.len() rows by x.len() columns, which is meshgrid's convention and not ndgrid's transpose.
