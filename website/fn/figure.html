figure

Builtin index · Plotting

figure()

Input: no input · Output: no output

What it is

Clears/resets the whole figure (all panels), starting a fresh one. Takes no arguments. Must be called with parentheses — bare figure (no parens) is not a recognized command verb.

Overloads

One call shape — this function is not overloaded.

How it works

Starts a genuinely new, separate figure -- unlike the bare clear/clear figure *command* (exec_clear_command's [] | ["figure"] arm), which discards the current figure's content outright, figure() finalizes it into self.figure_history first (if it actually has content -- two back-to-back figure() calls with nothing plotted between them shouldn't record an empty figure) so it can still be recovered later for reports. See figure_history's field doc comment.
