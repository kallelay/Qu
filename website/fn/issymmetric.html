issymmetric

Builtin index · Core maths

issymmetric(A, [tol])

Input: A, tol · Output: no output

What it is

true when A equals its transpose. With the default tol = 0 the comparison is exact (every A(i,j) == A(j,i)); with tol > 0 it is true when the largest abs(A(i,j) - A(j,i)) is at most tol times the largest abs(A(i,j)). A non-square matrix is not symmetric (false, not an error), and a matrix with a NaN is not symmetric. Errors: a negative or non-numeric tol, non-numeric or complex A.

One call shape — this function is not overloaded.
