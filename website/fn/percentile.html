percentile

Builtin index · Core maths

result = percentile(x, p)

Input: x, p · Output: result

What it is

Same computation as quantile, with p on a 0..100 scale instead of 0..1 (p=50 is the median). x is a scalar, Vec, or Mat/Signal; p must lie in [0, 100] or the call errors.

Overloads

One call shape — this function is not overloaded.

How it works

percentile(x, p) — quantile with p on a 0-100 scale instead of 0-1, the more familiar spelling for the same thing.
