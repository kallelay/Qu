xlabel

Builtin index · Plotting

xlabel(text, [align=])

Input: text, align · Output: no output

What it is

Labels the current panel's x-axis with text (string). align= (string, one of "left"/"center"/"right", default "center") sets the label's horizontal alignment. While xxaxis top is active, labels the *top* axis instead of the bottom one.

Overloads

One call shape — this function is not overloaded.

How it works

While xxaxis top/yyaxis right is active, xlabel/ylabel label THAT side (xlabel2/ylabel2) instead of the primary bottom/left one — matches MATLAB's yyaxis + ylabel idiom. align= accepts "left"/"center"/"right" for title/xlabel, and additionally "bottom"/"top" for ylabel's rotated text (see plotting::parse_align); an unrecognized word is ignored, leaving the default alignment in place.
