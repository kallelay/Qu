random_walk

Builtin index · Statistics & ML

result = random_walk(n_steps, [drift=0], [volatility=1], [seed=])

Input: n_steps, drift, volatility, seed · Output: result

What it is

Generates a discretized Wiener-process path: n_steps (a positive integer) increments, each drawn ~ Normal(drift, volatility), cumulatively summed, with an optional integer seed=.

Overloads

One call shape — this function is not overloaded.

How it works

random_walk(n_steps, [drift=0], [volatility=1], [seed=]) — a discretized Wiener-process-style path: x[0] = 0, x[i] = x[i-1] + drift + volatility * randn(). Reuses the same Rng (.normal()) and seed= convention as randn/kmeans for deterministic reproducibility.
