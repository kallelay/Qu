What the language has

AreaWhat is in it
NumericsReal and complex scalars, vectors and matrices. FFT, filter design and application, resampling, windows, spectral estimates.
Linear algebraLU, QR, SVD, Cholesky, eigen, pseudo-inverse, least squares, condition number — on real and complex matrices. nnls and bounded nonlinear least_squares.
PlottingSVG, PDF with embedded subset fonts, TikZ. Maths in labels, twin axes with independent scales, contours, error bars, colorbars, 37 marker glyphs.
DataMATLAB .mat, CSV with provenance headers, raw binary arrays and structs, images, tables.
Statistics & MLSVM, random forests, gradient boosting, k-NN, PCA, GMM, MLPs, cross-validation, scalers, metrics.
SystemsParallel pmap and pools, GPU matmul, serial and TCP I/O, watches, sandboxing.

How the documentation is kept true

Two mechanisms, both mechanical, because prose about code drifts.

Generated

The index comes from the source

tools/gen_builtin_index.qu reads the interpreter's own name table, so the reference cannot claim a function that does not exist, or omit one that does.

Executed

Every example is run

tools/check_docs.sh extracts each code block and runs it, cumulatively per page, and reports how far a reader gets before it breaks.
