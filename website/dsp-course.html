Why this course is different

Most DSP courses split the theory from the tool: derive the transform on a whiteboard, then go implement it in a different language with a different set of bugs. Here there is one language for both halves. When a lesson says a stopband should be down 40 dB, the code block underneath measures it, and if the real number is 38 dB the lesson tells you where the other 2 went.

Every example in this course is executed before it is published, the same way the rest of the Qu book is: tools/check_docs.sh extracts each code block and runs it, so a snippet that does not work is a build failure, not something a reader finds out the hard way.
