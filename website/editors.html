Get Qu Studio

Editor plugins

Each lives in editors/ in the repository. All three give syntax highlighting for .qu; the VS Code one also knows the builtin names.

EditorPathInstall
VS Codeeditors/vscode-qu Copy the folder into ~/.vscode/extensions/ and restart.
Sublime Texteditors/sublime-qu Copy into Packages/User — Preferences → Browse Packages.
Notepad++editors/notepadpp-qu Language → User Defined Language → Import, then pick the XML.

Any editor at all. Qu files are plain text and the interpreter is one binary. qu run script.qu from a terminal is a complete workflow, and errors carry the line number.
