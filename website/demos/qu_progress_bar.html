qu_progress_bar

a tqdm-style progress indicator for a long loop.

catalog/qu_progress_bar.qu

`progress(i, n)` -- called once per iteration, `i` 0-based and less than `n` -- draws a bar, percent, rate and ETA, and redraws in place (carriage return, not a new line each time). Deliberately a plain builtin next to `tic`/`toc`, not new loop syntax: `for i = 0 to n - 1` is the ordinary Qu idiom, and this is the ordinary way to watch it.

How it works

A loop with real (if artificial) work per iteration, so the bar has

something to measure. sleep() stands in for the actual computation -- swap it for whatever the loop is really doing.

n = 40
total = 0.0
for i = 0 to n - 1
    total = total + sqrt(i + 1.0)
    sleep(50)   # milliseconds, not seconds -- sleep() takes ms
    progress(i, n)
end for
print("done: sum of sqrt(1..{n}) = {total:.4f}")

Calling it from the wrong range is a common off-by-one -- shown here

as the error it actually produces, not silently accepted.

try
    progress(n, n)
catch e
    print("expected error calling progress(n, n) instead of progress(n - 1, n): {e.message}")
end
